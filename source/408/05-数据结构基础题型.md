<question>
6\. (2022) 下列程序段的时间复杂度是 (&emsp;)。

~~~c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
~~~

<details>
<summary>核对原始代码图片</summary>

<img src="./05-数据结构基础题型.assets/1-2022.png" style="zoom: 60%;" />

</details>

<options :options="['A. O(log<sub>2</sub>n)', 'B. O(n<sup>1/2</sup>)', 'C. O(n)', 'D. O(n<sup>2</sup>)']" />

::: analysis
答案：C。设最后一个外层取值为 $2^m<n$，内层执行总次数为 $2^{m+1}-1$，因此时间为 $\Theta(n)$。当 $n$ 为 2 的幂时总次数是 $n-1$，并非恒等于 $n$。
:::
</question>

<question>
7\. (2025) 下列程序段的时间复杂度是 (&emsp;)。

~~~c
int count = 0, i, j;
for (i = 1; i * i <= n; i++)
    for (j = 1; j <= i; j++)
        count++;
~~~

<details>
<summary>核对原始代码图片</summary>

<img src="./05-数据结构基础题型.assets/1-2025.png" style="zoom: 60%;" />

</details>

<options :options="['A. O(log<sub>2</sub>n)', 'B. O(n<sup>1/2</sup>)', 'C. O(n)', 'D. O(n<sup>2</sup>)']" />

::: analysis
答案：C。外层执行 $k=\lfloor\sqrt n\rfloor$ 轮，内层总次数为 $k(k+1)/2$，因此时间为 $\Theta(n)$。外层轮数为平方根级；增长阶为 $n$ 不代表次数精确等于 $n$。
:::
</question>

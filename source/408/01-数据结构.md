### 树和二叉树 {.ignore-header}

<!-- unit-id:u-01-cb6d110cc8a9 -->
|     性质     | 内容                                                         |
| :----------: | ------------------------------------------------------------ |
|   树的性质   | • <emp>结点总数 = 总度数+1 = 分支数+1</emp>。N = n<sub>0</sub>+n<sub>1</sub>+...+n<sub>n</sub> = 0·n<sub>0</sub>+1·n<sub>1</sub>+...+n·n<sub>n</sub>+1<br/>• 树的度为k，结点数为n，则树的最大高度为 n-k+1 |
| 二叉树的性质 | • 二叉树第<mono>i</mono>层结点数最多为 <num>2<sup>i-1</sup></num>，结点总数最多为 <num>2<sup>h</sup>-1</num><br/>• 任意二叉树中，<emp>n<sub>0</sub>=n<sub>2</sub>+1<br/></emp>• 完全二叉树中，n<sub>1</sub>=0或1，n为偶数则 n<sub>1</sub>=1，n为奇数则 n<sub>1</sub>=0<br/>• 完全二叉树中，n个节点，所占高度为 h=⌈log<sub>2</sub>(n+1)⌉ <br/>• 按相同左右子树顺序进行先序、中序、后序遍历时，叶结点的相对顺序不变；层序遍历不适用 |
| 二叉树的遍历 | • 先序遍历：先访问根，再访问左树，最后访问右树<br/>• 中序遍历：先访问左树，再访问根，最后访问右树<br/>• 后序遍历：先访问左树，再访问右树，最后访问根 |
:::

- 并查集本质是一个森林，逻辑上用树表示集合，物理上用数组存储。

<!-- unit-id:s-01-a8f1e3390852 -->
### 图的概念

<!-- unit-id:u-01-8a5da0f176fb -->
:::

<!-- unit-id:u-01-555aa578667d -->
::: info 一般概念
- 顶点集合不可为空，边集可为空。
- 边有方向的图叫有向图，边无方向的图叫无向图。
- 一条边的两个顶点互为邻接点。
- 无向图中边记作$\small (V_i，V_j)$，有向图中记作$\small <V_i,V_j>$称弧，以及弧头弧尾。
- 一个顶点到另一个顶点所经序列叫路径，边的条数即路径长度。
- 无重复结点的路径叫简单路径，首尾相同的路径叫回路或环。回路不是简单路径。
:::

<!-- unit-id:u-01-b520f43c6d5d -->
| 重要概念                | 含义                                                         |
| ----------------------- | ------------------------------------------------------------ |
| 完全图                  | 所有顶点相邻接。有向完全图有<emp>$\small n(n-1)$</emp>个边，无向完全图有<emp>$\frac{n(n-1)}{2}$</emp>个边。 |
| 顶点的度                | 顶点连接的边数。有向图度数=入度+出度，<emp>总度数/2=边数</emp>。 |
| 连通图<br/>连通分量     | 无向图中，两点有路径称两点连通，若所有顶点均连通，称该图为连通图。<br/>无向图中的极大连通子图。 |
| 强连通图<br/>强连通分量 | 有向图中，任意顶点间均有两个方向的路径，称该图为强连通图。<br/>有向图中的极大连通子图。 |
| 生成树<br/>最小生成树   | 连通图的极小连通子图（用最少的边连接所有顶点）。<br/>所有生成树中，边权值之和最小的树，称最小生成树。 |

<!-- unit-id:u-01-e67f97304956 -->
::: tip
- 若$\small G=(V,E),G'=(V',E')$且$\small V'∈V,E'∈E$，则$\small G'$为$\small G$的子图。
- 子图必须要求$\small G'=(V',E')$，因为$\small V'$和$\small E'$不一定能组合成图。
- 树是特殊的图，当图为连通图且无回路，则该图可视为树。
- 完全图是特殊的连通图。
:::

<!-- unit-id:s-01-f625d100ccca -->
#### 最小生成树

<!-- unit-id:u-01-abbe069e508e -->
:::

<!-- unit-id:u-01-3eed04ade846 -->
::: info 最小生成树的性质
- $n$ 个顶点的连通图的生成树有 $n$ 个点和 $n-1$ 条边。
- 生成树是边最少的连通图，一个连通图可以有多个生成树。
- 若存在权值相同的边，则最小生成树**可能**不唯一；若最小生成树不唯一，则一定存在权值相同的边。
- 最小生成树的边权值之和是所有生成树中最小的。
:::

<!-- unit-id:u-01-1a72bd800758 -->
|                最小生成树算法             | 内容                                                         |
| :--------------------------------------: | ------------------------------------------------------------ |
| Kruskal算法<br/>(与点数无关，适合稀疏图) | • 每次都找最小权值的边，<br/>• 检查是否构成回路，<br/>• 若构成回路，则放弃该边，重新选择。<blockquote style="margin: 5px 0px;">先放入n个顶点，排序所有边，按序选择权值最小边，并确保无环。</blockquote> |
|  Prim算法<br/>(与边数无关，适合稠密图)   | • 从任意顶点开始，<br/>• 每次选择连接已选顶点集合与未选顶点集合的最小权边。<blockquote style="margin: 5px 0px;">每次都找一个已选点和一个未选点，所构成的权值最小边，故天然避开回路。</blockquote> |

<!-- unit-id:s-01-4eb97aaa7f6d -->
#### 关键路径

<!-- unit-id:u-01-129fd544daa6 -->
:::

<!-- unit-id:u-01-ae96ae372a09 -->
::: info 概念
- AOE网即边活动网，边表示活动，点称事件表示活动始末状态。
- AOE网是**有向无环图**，活动存在先后关系。
- ve：事件最早开始时间、vl：事件最晚开始时间、e：活动最早开始时间、l：活动最晚开始时间。
:::

<!-- unit-id:u-01-d5bfaee338f9 -->
关键路径是耗时最多的路径（不唯一）。最早开始时间=最晚开始时间的活动为关键活动，所构成路径即关键路径。

<!-- unit-id:u-01-be7a1c1cd26c -->
::: tip 性质
- 关键路径并不唯一，关键路径是权值之和最大的那条路径。
- 增加关键路径上的任意活动的持续时间，一定会延长工期。
- 减少关键路径上的任意活动的持续时间，不一定会缩短工期。
- 若只有一条关键路径，则一定会缩短工期。若有多条关键路径，则另外的关键路径仍在支撑工期长度。
:::

<!-- unit-id:u-01-6b51d431df5d -->
<img src="./01-数据结构.assets/关键路径.png" style="zoom: 40%;" />

<!-- unit-id:u-01-7f2209b29d9f -->
|        关键路径         | 内容                                                         |
| :---------------------: | ------------------------------------------------------------ |
| 求事件最早开始时间$ve$  | • 先将所有事件的 $ve$ 设为 0<br/>• 从源点开始，拓扑序找入度为0的点，更新所有出边的邻接点的 $ve$（更新成最大值） |
| 求事件最晚开始时间 $vl$ | • 先将所有事件的 $vl$ 设为整个工程的 $ve$<br/>• 从汇点开始，逆拓扑序找出度为0的点，更新所有入边的邻接点的 $vl$（更新成最小值） |

<!-- unit-id:u-01-04cf7f4acaa1 -->
> $ve$ 要最大保证前面的活干完，$vl$ 要最小保证后面的活干完。

<!-- unit-id:u-01-37dd2c0a61c9 -->
|    关键路径（续表）    | 内容                                 |
| :--------------------: | ------------------------------------ |
| 求活动最早开始时间 $e$ | 出发点的最早开始时间 $ve$            |
| 求活动最晚开始时间 $l$ | 指向点的最晚开始时间 $vl$ - 活动耗时 |

### 线性查找

<!-- unit-id:u-01-05de7dffca32 -->
:::

<!-- unit-id:u-01-7b597ac736e3 -->
::: info 概念
- 哨兵位：在序列开头放入待查找元素，从后往前遍历查找的过程中不必判断循环越界。
- 平均查找长度ASL：查找集合每个元素所需要的平均比较次数（总次数/元素个数）
:::

<!-- unit-id:u-01-1cc9666eba4d -->
| 线性查找 | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 顺序查找 | $\small ASL=\frac{n(n+1)}{2}\frac{1}{n}=\frac{1+n}{2}≈\frac{n}{2}$ |
| 折半查找 | 查找成功的次数是判定树中结点的层数，查找失败的次数是判定树中“失败”的父结点的层数。<br/>$\small ASL_{成功}=\frac{\sum{成功点的层高}}{n}\;ASL_{失败}=\frac{\sum{失败位置父结点的层高}}{失败位置个数}$<br/>折半查找判定树的形态：<br/>• 当结点个数为奇数时，左子树和右子树结点个数相等；<br/>• 当结点个数为偶数时，右子树比左子树多一个结点（左少右多）。<blockquote style="margin: 5px 0px; padding-left: 10px;">这个结论对子树依然成立，因此可推断判定树的构造形态。</blockquote>折半查找判定树本质是二叉排序树，且是接近完美的二叉排序树。 |
| 分块查找 | ① 将序列分块，块内无序，块间有序。使用索引表记录每块最大关键字和起始地址。<br/>② 将待查找元素和块最大关键字比较，再在对应块中顺序查找。<br/>• 最佳情况是令$\small s=\sqrt{n}$<br/>• 设索引表长 b，每块长度为s，$\small{ASL=} \frac{1+b}{2}+\frac{1+s}{2}$ |

### 内部排序

<!-- unit-id:u-01-56815e3f714d -->
| 排序                                              | 时间复杂度   | 空间复杂度           | 稳定性            | 描述                                                        |
| ------------------------------------------------ | ------------ | -------------------- | ----------------- | ----------------------------------------------------------- |
| [直接插排](/docs/DS/6-八大排序#_1-1-直接插入排序) | $O(n^2)$     | $O(1)$               | 稳定              | 新元素插入前面的有序序列                                    |

| [堆排](/docs/DS/6-八大排序#_2-2-堆排序)           | $O(nlogn)$   | $O(1)$               | <emp>不稳定</emp> | 向下建[堆](/docs/DS/4-二叉树#_3-堆)，删除堆顶最大值放到末尾 |

| 基数排序                                          | $O(n+r)$     | $O(r)$               | 稳定              | 从低到高逐位排序                                            |

<!-- unit-id:u-01-9abbc11240d1 -->
> 稳定性口诀：**选**艾**希**，**堆**攻**速**

<!-- unit-id:u-01-4f377c8778ad -->
::: info 特点
- 插排、希排、冒排最好情况是完全有序，最坏情况是完全逆序。
- 快排最好情况是每次都选到中位数，递归树形态完美，最坏情况是完全有序。
- 归并操作最好情况是一个序列遍历完毕一个不动，最坏情况是两个序列的都遍历完毕。
---
- 冒排、选排、堆排一趟可以确定一个数，快排可以确定多个数，插排、希排、归并、基数不能。
---
- 二叉排序树最好情况是完全二叉树、而堆一定是一个完全二叉树。
- 堆从根到叶的任意路径都是有序序列，二叉排序树不行。
---
- 排序趟数和序列的初始状态有关：冒排，快排。
- 比较次数和序列的初始状态有关：插排，希排，快排，归排，冒排。无关：选排，堆排。
- 移动次数和序列的初始状态有关：插排，希排，冒排，快排，~~堆排~~。无关：选排，归排。
:::

## 第一章 绪论

<div class="study-unit" id="u-01-34330ba3e975">

**数据结构**研究数据的逻辑关系、存储方式及操作。

</div>

<div class="study-unit" id="u-01-39c5856267d7">

逻辑结构分集合、线性结构、树和图；

</div>

<div class="study-unit" id="u-01-da447889e07c">

存储结构分顺序、链式、索引和散列。

</div>

<div class="study-unit" id="u-01-d4c95c9fd293">

数据元素是基本单位，数据项是元素的组成部分；

</div>

<div class="study-unit" id="u-01-b44099427467">

抽象数据类型 ADT（Abstract Data Type） 描述数据及操作，不规定具体实现。

</div>

<div class="study-unit" id="u-01-dc03070975a0">

**时间复杂度**看基本操作次数随 n 的增长阶：顺序执行取相加后的最高阶，嵌套循环按实际次数求和，不能只数循环层数。

</div>

<div class="study-unit" id="u-01-102739491e9a">

$i*=2$ 为 $O(\log  n)$，i*i<n 为 $O(\sqrt{n})$，j<i 的双循环执行 $n(n-1)/2$ 次，为 $O(n^{2})$。

</div>

<div class="study-unit" id="u-01-2ddd7743bdd7">

递归结合递推式分析；

</div>

<div class="study-unit" id="u-01-b9d6dbee2e46">

朴素斐波那契递归时间为指数级。

</div>

<div class="study-unit" id="u-01-c67a9f7e8f76">

**空间复杂度**只计辅助空间，也计递归栈。原地迭代常为 $O(1)$，递归深度 n 通常需要 $O(n)$ 栈空间；同层先后执行的调用可复用空间，不把全部调用次数算为空间。

</div>

<div class="study-unit" id="u-01-explain-d9ea22c62d">

例：i 从 1 开始每轮翻倍，到 n 前约经历 log₂n 轮，所以是 $O(\log  n)$；若内层依次执行 1、2、4、8…次，总次数是几何和、仍为 $O(n)$。

</div>

<div class="study-unit" id="u-01-72442ebef69f">

分析嵌套循环要先求每轮次数，再求总和，不能把所有双循环都判为 $O(n^{2})$。

</div>

### 算法的基本概念

<div class="study-unit" id="u-01-outline-56b515e583">

算法是为解决问题而规定的有限操作步骤，通常具有输入、输出、有穷性、确定性和可行性；

</div>

<div class="study-unit" id="u-01-7eab07dbd027">

输入可为零个，输出至少一个。

</div>

<div class="study-unit" id="u-01-ab8ce72555f3">

有穷性要求有限步骤内结束，确定性要求每一步含义明确，可行性要求操作能实际完成。

</div>

<div class="study-unit" id="u-01-486300506aa0">

设计时同时考虑正确性、可读性、健壮性及时间／空间效率。

</div>

## 第二章 线性表

<div class="study-unit" id="u-01-concise-2">

线性表是 n 个同类型元素的有限序列。除首尾外，每个元素有唯一直接前驱和后继。位序通常从 1 开始，数组下标通常从 0 开始，计算位置前先统一约定。

</div>

<span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="s-4"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="p-17"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="p-18"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="u-01-0b4c527afd16"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="u-01-5e7e5e0612a3"></span>
<a id="s-01-c12986cc5db7"></a>

### 顺序表

<div class="study-unit" id="u-01-df072b35a3f8">

顺序表把元素放在连续空间，按位访问 $O(1)$，按值顺序查找 $O(n)$。容量与当前长度不同；动态数组扩容可能需要新空间并搬移全部元素。

</div>

<div class="study-unit" id="u-01-f9ae965fe5ef">

| 操作 | 执行过程（位序从 1 开始） | 移动次数 / 复杂度 |
| --- | --- | --- |
| 在位置 i 插入 | 从后往前，把 i～n 位各后移一位，再写新元素 | $n-i+1$；等概率平均 n/2；$O(n)$ |
| 删除位置 i | 取出元素，把 $i+1\sim n$ 位各前移一位 | $n-i$；等概率平均 $\frac{n-1}{2}$；$O(n)$ |

</div>

<div class="study-unit" id="u-01-79cd52b7856e">

“有序表”描述关键字顺序，“顺序表”描述存储方式，顺序表不一定有序。

</div>

<div class="study-unit" id="u-01-explain-dfb1b6c508">

例：在 [3,5,8] 的第 2 位插入 4，要先把 8 后移，再把 5 后移，最后填入 4，得到 [3,4,5,8]。从后向前移动才能保留原数据；删除时从前向后补空位即可。

</div>

<span class="legacy-anchor" data-target="s-01-aa7868153914" id="s-5"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-22"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-23"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-24"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-25"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-26"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-27"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-28"></span>
<a id="s-01-aa7868153914"></a>

### 链表

<div class="study-unit" id="u-01-f52d612fce88">

链表用指针连接结点，不要求空间连续，不能随机存取。

</div>

<div class="study-unit" id="u-01-972b4f680784">

头指针指向链表的第一个结点：有头结点时指向头结点，没有时指向首元结点。

</div>

<div class="study-unit" id="u-01-1d8bddb9a774">

头结点是可选的辅助结点，不存有效元素；首元结点才是第一个存有效数据的结点。

</div>

<div class="study-unit" id="u-01-fa8782237360">

**单链表**：查找或定位前驱 $O(n)$；已知前驱后插删 $O(1)$。头插形成输入序列的逆序，带尾指针尾插能 $O(n)$ 建表；删尾需找前驱，即使有尾指针通常仍 $O(n)$。

</div>

<div class="study-unit" id="u-01-76279a64c3e7">

~~~c
// 在 p 后插入 s：先保存原后继，不能颠倒顺序
s->next = p->next;
p->next = s;
// 删除 p 的后继：先检查 q 非空
q = p->next;
if (q != NULL) {
    p->next = q->next;
    free(q);
}
~~~

</div>

<div class="study-unit" id="u-01-5ca57e48eea1">

**双链表**：有 prior、next；已知目标结点时插删 $O(1)$，按位或按值定位仍 $O(n)$。插入需同时更新四条双向链接；删除更新前后结点链接，空表、首尾边界另处理。

</div>

<div class="study-unit" id="u-01-37afc59ce2c4">

**循环链表**：尾部链接到表头。带尾指针的循环单链表，头插、头删、尾插 $O(1)$，尾删 $O(n)$；循环双链表的首尾插删均 $O(1)$。复杂度需区分有无头结点、尾指针。

</div>

<div class="study-unit" id="u-01-b10157f300d0">

**静态链表**：用数组下标作游标模拟 next，逻辑顺序不由数组位置决定。容量通常预先固定，空闲和结束标志按实现约定。

</div>

<div class="study-unit" id="u-01-explain-6e0e63d681">

链表插删只改相邻结点的指针，不必搬动后面的元素；

</div>

<div class="study-unit" id="u-01-713fde8e3899">

但先找到目标位置，仍可能沿链走 $O(n)$ 次。

</div>

<div class="study-unit" id="u-01-5b8d41d62bd8">

双链表在非空相邻结点 p、q 之间插入 s，要让 s 的前后指针指向 p、q，再让 p 的 next、q 的 prior 指向 s，四条链接都要接好。

</div>

<a id="s-01-outline-cb076ef2a0"></a>

### 线性表的应用

<div class="study-unit" id="u-01-outline-1d7b521aac">

常见应用按操作选择结构：顺序表适合按位访问，链表适合在已知位置附近频繁插删。

</div>

<div class="study-unit" id="u-01-e18d77c0a5e6">

两个有序表合并时，用两个指针比较当前元素、依次取较小者，最后接上未用完的部分，总时间 $O(m+n)$；链表可重新链接原结点，顺序表通常需要结果数组。

</div>

<div class="study-unit" id="u-01-90186701ad1a">

单链表原地逆置用 pre、cur、next：先保存 cur 的后继，再令 cur.next 指向 pre，最后一起向前移动，时间 $O(n)$、辅助空间 $O(1)$。

</div>

<div class="study-unit" id="u-01-cbbceafd7c81">

有序表去重只需比较相邻元素；无序表不能直接套这一规则，须另行查重或先排序。

</div>

<div class="study-unit" id="u-01-steps-cb076ef2a0">

**有序表合并的操作顺序**

</div>

<div class="study-unit" id="u-01-a549477e0dd8">

1. 两个指针分别指向两表首元素，建立空结果表。
2. 比较当前元素 → 取较小者加入结果 → 只移动取出元素所在表的指针。
3. 某表用尽 → 把另一表剩余部分依次接到结果后面。

</div>

<div class="study-unit" id="u-01-4b5d15329fad">

**单链表逆置的操作顺序**：保存当前结点的原后继 → 当前结点指向前驱 → 前驱移到当前结点 → 当前结点移到原后继；反复执行，直到当前结点为空，最后更新头指针。

</div>

## 第三章 栈、队列和矩阵

<span class="legacy-anchor" data-target="s-01-5cfaad7421e0" id="s-7"></span><span class="legacy-anchor" data-target="s-01-5cfaad7421e0" id="p-35"></span><span class="legacy-anchor" data-target="s-01-5cfaad7421e0" id="u-01-6480090999e5"></span>
<a id="s-01-5cfaad7421e0"></a>

### 卡特兰数

<div class="study-unit" id="u-01-6636c1440ac1">

固定 n 个不同元素的入栈顺序时，合法出栈序列数为 $C_n=\frac{1}{n+1}\binom{2n}{n}$，也是 n 结点的不同二叉树形态数。不是 n!，并非任意排列都可由栈得到。

</div>

<div class="study-unit" id="u-01-explain-2373d1bfd2">

例：按 1、2、3 入栈，合法出栈序列有 123、132、213、231、321，共 $C_{3}=5$ 种；312 不合法，因为先弹出 3 后，2 仍压在 1 上面，不能直接弹出 1。

</div>

<span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="s-8"></span><span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="p-36"></span><span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="p-37"></span><span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="u-01-8bdec8ed0f78"></span>
<a id="s-01-41aa2da47ebc"></a>

### 栈

<div class="study-unit" id="u-01-c1ded955f426">

栈只允许栈顶插删，后进先出 LIFO（Last In, First Out），入栈出栈 $O(1)$。顺序栈先判满 / 空；链栈通常在单链表表头操作，不受固定数组容量限制，但仍受可用内存限制。

</div>

<div class="study-unit" id="u-01-e528d571b553">

| 应用 | 执行过程 | 易错处 |
| --- | --- | --- |
| 括号匹配 | 1. 左括号入栈<br>2. 右括号与栈顶匹配并弹栈<br>3. 结束时检查空栈 | 右括号遇空栈、类型不匹配或最后非空均失败 |
| 中缀转后缀 | 1. 操作数直接输出<br>2. 左括号入栈<br>3. 运算符弹出栈顶更高优先级者后入栈<br>4. 右括号弹至左括号<br>5. 最后清栈 | 左结合遇同优先级也先弹；括号不输出 |
| 后缀求值 | 1. 操作数入栈<br>2. 遇运算符先弹右操作数，再弹左操作数，计算结果入栈 | 减、除的操作数顺序不能反 |

</div>

<div class="study-unit" id="u-01-0b37d912940e">

例：$(a+b)*c+d-(e+g)*h$ → $ab+c*d+eg+h*-$。递归调用用栈保存返回地址与局部状态。

</div>

<span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="s-9"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-45"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-46"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-47"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-48"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-49"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-50"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-51"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-52"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="u-01-6b86b273ff34"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="u-01-4d75af40c65b"></span>
<a id="s-01-f5c92ad7c76d"></a>

### 队列

<div class="study-unit" id="u-01-f34bc7b0d703">

队列尾部入、头部出，先进先出 FIFO（First In, First Out）。普通顺序队列可能出现尾部用尽而头部仍空闲的“假溢出”，循环队列用取模复用空间。

</div>

<div class="study-unit" id="u-01-2316f1aa2c46">

**循环队列约定**：数组容量 M，front 指队头，rear 指下一入队位置，牺牲一个单元。

</div>

<div class="study-unit" id="u-01-5fbbccad472a">

| 操作 / 状态 | 规则 |
| --- | --- |
| 空 | $\mathrm{front} == \mathrm{rear}$ |
| 满 | $(\mathrm{rear}+1)\%M == \mathrm{front}$ |
| 入队 | 先写 A[rear]，再令 $\mathrm{rear}=(\mathrm{rear}+1)\%M$ |
| 出队 | 先取 A[front]，再令 $\mathrm{front}=(\mathrm{front}+1)\%M$ |
| 元素个数 | $(\mathrm{rear}-\mathrm{front}+M)\%M$；最多 $M-1$ |

</div>

<div class="study-unit" id="u-01-293da8d35465">

用 size 或 tag 判满空可用满 M 个位置，公式随实现改变。

</div>

<div class="study-unit" id="u-01-9b1e96d0fdb3">

链队列有首尾指针时入出队 $O(1)$，删最后一个有效结点需同步更新 rear。

</div>

<div class="study-unit" id="u-01-76f71e4ce3c1">

双端队列两端可插删，输入 / 输出受限双端队列分别限制一端插入 / 删除。

</div>

<div class="study-unit" id="u-01-explain-de346c6b41">

例：$M=5$，$\mathrm{front}=3$、$\mathrm{rear}=1$，当前元素在下标 3、4、0，共 $(1-3+5)\%5=3$ 个。

</div>

<div class="study-unit" id="u-01-6dc822343abf">

再入队一个后 $\mathrm{rear}=2$，已满足 $(\mathrm{rear}+1)\%5=\mathrm{front}$，队满；留出的一个空槽正是用来区分“满”和“空”。

</div>

### 矩阵

<div class="study-unit" id="u-01-df6a0d24a356">

**数组地址**：首地址 a，元素宽 L，n 行 m 列，下标从 0 开始。行优先 $LOC(i,j)=a+(im+j)L$；列优先 $a+(jn+i)L$。下标从 1 起时先减 1。

</div>

<div class="study-unit" id="u-01-f8eddfd77e76">

| 矩阵压缩（i,j 从 1 起，压缩下标 k 从 0 起） | 规则 / 数量 |
| --- | --- |
| 对称矩阵，按行存下三角 | $i\ge j$：$k=i(i-1)/2+j-1$；i<j 交换 i,j；$n(n+1)/2$ 个 |
| 三角矩阵 | 有效三角照存，另一半公共常数另占一个位置；$n(n+1)/2+1$ 个 |
| 三对角矩阵，按行 | 有效位置满足 $abs(i-j)\le 1$，$k=2i+j-3$；$3n-2$ 个 |
| 稀疏矩阵 | 三元组记录行、列、值，通常按行、同一行按列排序；十字链表同时链接同行和同列非零元 |

</div>

<div class="study-unit" id="u-01-762c34a38897">

压缩地址为 $a+kL$。数组可随机存取；三元组压缩后一般不能按原坐标直接 $O(1)$ 定位。

</div>

<div class="study-unit" id="u-01-explain-9a2094e589">

三角压缩公式中的 $i(i-1)/2$，数的是第 i 行前已有多少个元素，$j-1$ 再数这一行内前面的元素。

</div>

<div class="study-unit" id="u-01-69f411aa5879">

例如存下三角的 A[3,2]：前两行有 $1+2=3$ 个，本行前面还有 1 个，所以压缩下标为 4。

</div>

<div class="study-unit" id="u-01-outline-c85cfd1a4a">

多维数组按确定次序连续存放。

</div>

<div class="study-unit" id="u-01-7b1ad92ba55a">

行优先让最右下标变化最快：尺寸 d₁×d₂×d₃、下标从 0 起时，$LOC(i,j,k)=a+((i\cdot d_{2}+j)\cdot d_{3}+k)L$；

</div>

<div class="study-unit" id="u-01-8631db0001c3">

列优先让最左下标变化最快，$LOC(i,j,k)=a+(i+d_{1}(j+d_{2}k))L$。

</div>

<div class="study-unit" id="u-01-ba9a96e44b1e">

非零下界先减去各维下界，再计算偏移。

</div>

## 第四章 串

<div class="study-unit" id="u-01-6341aea2521e">

串是字符的有限序列；子串必须连续，子序列不要求连续。空串长度为 0，空格串含空格字符、长度不为 0。模式匹配是在主串中找模式串。

</div>

<div class="study-unit" id="u-01-8e7822a415c7">

**朴素匹配**：从候选起点依次比较；失配则主串候选起点后移一位，模式从头再比。最坏 $O(nm)$。

</div>

<div class="study-unit" id="u-01-f12aade81dc3">

**KMP（Knuth–Morris–Pratt 模式匹配算法）**：失配时主串 i 不回退，模式 j 按 next[j] 跳转；

</div>

<div class="study-unit" id="u-01-2fb16d3940f9">

匹配则 i、j 同时前进。

</div>

<div class="study-unit" id="u-01-a5f99f84e35a">

求 $\mathrm{next} O(m)$，匹配 $O(n)$，总 $O(n+m)$。

</div>

<div class="study-unit" id="u-01-ef739e8bb4a4">

next 记录已匹配前缀还能复用多少。

</div>

<div class="study-unit" id="u-01-a409731f9410">

**1 起始下标约定**：$\mathrm{next}[1]=0$；$j=0$ 时 i、j 同时加 1；j>1 时 next[j] 为 $P[1..j-1]$ 最长相等真前后缀长度加 1。

</div>

<div class="study-unit" id="u-01-738072ecbd3a">

$P=ababaa$，next 为 0,1,1,2,3,4。

</div>

<div class="study-unit" id="u-01-206828dfdd8d">

**nextval**：若 $P[j]==P[\mathrm{next}[j]]$，同字符再次比较必败，令 $\mathrm{nextval}[j]=\mathrm{nextval}[\mathrm{next}[j]]$；

</div>

<div class="study-unit" id="u-01-567e9273c01e">

否则取 next[j]，$\mathrm{nextval}[1]=0$。

</div>

<div class="study-unit" id="u-01-535b473322e4">

上例为 0,1,0,1,0,4。

</div>

<div class="study-unit" id="u-01-26acd564f589">

若题目用 0 起始和 −1 哨兵，按其约定计算。

</div>

<div class="study-unit" id="u-01-explain-dc8cf1977b">

next[j] 给出失配后模式串下一次比较的位置，不是主串的新起点。

</div>

<div class="study-unit" id="u-01-7c7790cb00d4">

例：$P=ababaa$，在第 5 位失配时，已经匹配的 abab 有相同前后缀 ab，因此把 j 跳到 $\mathrm{next}[5]=3$，复用这两个字符，主串 i 留在原处；

</div>

<div class="study-unit" id="u-01-26f843fd6c92">

nextval 进一步跳过必然再次失败的同字符比较。

</div>

<div class="study-unit" id="u-01-steps-9c4cd7dfdd">

**KMP 匹配，按这四步模拟**

</div>

<div class="study-unit" id="u-01-82039aad572b">

1. 主串指针 $i$ 和模式串指针 $j$ 从起始位置开始。
2. 字符匹配 → 两个指针同时后移；模式全部匹配 → 报告匹配位置。
3. 字符失配 → 主串 $i$ 不回退，只令 $j=\mathrm{next}[j]$，用已经匹配的前后缀继续比较。
4. 采用 1 起始、0 哨兵约定时，若 $j=0$ → 两指针同时加 1；主串用尽仍没完整匹配 → 查找失败。

</div>

<div class="study-unit" id="u-01-6f7a9c96e982">

求 next 时，针对当前位置之前的模式前缀，寻找最长相等真前后缀 → 长度加 1 得到下一比较位置；具体数组按题设下标约定填写。

</div>

## 第五章 树

<span class="legacy-anchor" data-target="s-01-6827de620ce0" id="s-13"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-83"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-84"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-85"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-86"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="u-01-da988fa69296"></span>
<a id="s-01-6827de620ce0"></a>

### 树和二叉树

<div class="study-unit" id="u-01-cb6d110cc8a9">

二叉树每个结点最多两个孩子，左子树与右子树有区别；

</div>

<div class="study-unit" id="u-01-72dc54128262">

它可以是空树，不能简单等同于“度不超过2的普通树”。

</div>

<div class="study-unit" id="u-01-41c83c35c83a">

树中除根外每结点有一个双亲；

</div>

<div class="study-unit" id="u-01-fb3c5ca5a855">

结点的度是孩子数，树的度是最大结点度。

</div>

<div class="study-unit" id="u-01-d8369f2edc9e">

**树的结点计数**：$\text{结点数}=\text{所有结点度数之和}+1$，n 结点树有 $n-1$ 条边。

</div>

<div class="study-unit" id="u-01-8b038d6c9e2b">

度 $k\ge 1$ 的 n 结点树最大高度为 $n-k+1$。

</div>

<div class="study-unit" id="u-01-fcc5b5bcb426">

| 二叉树性质（根在第 1 层） | 结论 |
| --- | --- |
| 第 i 层最多结点数 | $2^{i-1}$ |
| 高 h 最多结点数 | $2^{h}-1$ |
| 度 0、1、2 的结点数 | $n_{0}=n_{2}+1$ |
| 完全二叉树 | 从上到下、从左到右无缺口；n₁为 0 或 1，n 偶数时为 1 |
| 完全二叉树高 | $\lfloor \log_{2}n\rfloor +1=\lceil \log_{2}(n+1)\rceil$ |
| 完全二叉树顺序编号 | i 的孩子 2i、$2i+1$，双亲 $\lfloor \frac{i}{2}\rfloor$（编号存在时） |

</div>

<div class="study-unit" id="u-01-b058ade70e2a">

先序 根左右；

</div>

<div class="study-unit" id="u-01-b767d244f5f6">

中序 左根右；

</div>

<div class="study-unit" id="u-01-b9966bbc2e78">

后序 左右根；

</div>

<div class="study-unit" id="u-01-763b5d561663">

层序用队列。

</div>

<div class="study-unit" id="u-01-9a2b07099ea8">

递归遍历 $O(n)$，栈空间 $O(h)$；

</div>

<div class="study-unit" id="u-01-8cbb74307e1d">

层序空间最坏 $O(n)$。

</div>

<div class="study-unit" id="u-01-042a89f6f27b">

结点值互异时先序+中序或后序+中序可唯一确定树，先序+后序一般不能。

</div>

<div class="study-unit" id="u-01-dc7653bf059f">

先 / 中 / 后序叶结点相对顺序相同，层序不适用。

</div>

<div class="study-unit" id="u-01-c546af216819">

链式二叉树 n 个结点共有 2n 个孩子指针，$n-1$ 非空、$n+1$ 空；顺序存储适合完全二叉树，一般二叉树可能浪费空间。

</div>

<span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="s-14"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="p-105"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="p-106"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="u-01-4b227777d4dd"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="u-01-1e0182162f87"></span>
<a id="s-01-b80a716d4abc"></a>

### 树和森林

<div class="study-unit" id="u-01-772f8e6d6776">

树常用双亲表示法、孩子表示法、孩子兄弟表示法。**孩子兄弟法**：左指针指第一个孩子，右指针指下一个兄弟；据此转换树、森林与二叉树。

</div>

<div class="study-unit" id="u-01-723a950778b1">

树转二叉树：保留到第一个孩子的左链接，孩子用右链接串成兄弟链。森林转换：先转换各树，再用右链接串起各根；反向转换时左链恢复孩子、右链恢复兄弟。

</div>

<div class="study-unit" id="u-01-a99039b14e16">

有序树先根遍历对应二叉树先序，后根对应中序；森林先序对应二叉树先序，森林中序对应二叉树中序。遍历需约定孩子次序，不能说树“不区分子结点顺序”。

</div>

### 线索二叉树

<div class="study-unit" id="u-01-5736f31b7c61">

线索二叉树把空孩子指针改为指向某遍历序列的前驱 / 后继。$ltag=0$ 为左孩子，$ltag=1$ 为前驱线索；rtag 同理。指针非空不等于它是孩子，必须看 tag。

</div>

<div class="study-unit" id="u-01-5d7113dde630">

中序找后继：$rtag=1$ 直接取右线索；$rtag=0$ 进入右子树再沿左孩子走到最左结点。前驱对称处理，中序遍历不需递归栈。

</div>

<div class="study-unit" id="u-01-fef5e2419023">

先序线索通常不能直接求任意结点的前驱；后序线索通常不能直接求任意结点的后继，因为可能需要双亲。线索化次序须与所求前后继次序一致。

</div>

<div class="study-unit" id="u-01-explain-79f27a92f2">

例：某结点的右指针非空，若 $rtag=1$，它直接指向中序后继；若 $rtag=0$，它只是右孩子，后继应去右子树中继续找最左结点。tag 决定这根指针是“孩子链接”还是“遍历捷径”。

</div>

<div class="study-unit" id="u-01-outline-476d0ec96c">

中序线索化用 pre 记录刚访问的结点：

</div>

<div class="study-unit" id="u-01-9f2cded139eb">

1. 按“左子树。
2. 当前结点。
3. 右子树”遍历；当前结点没有左孩子时，将左指针设为 pre、ltag 设为 1；pre 存在且没有右孩子时，把 pre 的右指针设为当前结点、rtag 设为 1；随后更新 pre。

</div>

<div class="study-unit" id="u-01-d25326e0eb28">

遍历结束处理最后一个结点的空右指针；无头结点时线索指向空，有头结点时依约定连接头结点。真实孩子链接必须保留，递归时只沿孩子链接，不能沿新增线索再次递归。

</div>

### 哈夫曼树

<div class="study-unit" id="u-01-534e82bf26df">

哈夫曼树使叶结点的 **带权路径长度 WPL（Weighted Path Length）$=\sum w_{i}l_{i}$ 最小**，lᵢ 是根到叶的边数。

</div>

<div class="study-unit" id="u-01-adab34a8f9db">

构造：每次取两个最小权根合并，父权为两者之和；把新根放回集合，重复到一棵树。

</div>

<div class="study-unit" id="u-01-628c3d0836e4">

n 叶结点产生 $n-1$ 内部结点，共 $2n-1$，只含度 0 和 2。通常较大权较浅；同权选取或左右安排不同，树和编码可能不唯一，但最优 WPL 相同。

</div>

<div class="study-unit" id="u-01-e684f605d11a">

哈夫曼编码：左边 0、右边 1，根到叶的路径为编码；不存在某编码是另一编码前缀，故可即时译码。平均码长$=WPL/\sum w_{i}$，不等于 WPL。

</div>

<div class="study-unit" id="u-01-explain-77bc0a063a">

例：权值 1、2、4，先合并 1 和 2 得 3，再合并 3 和 4 得 7；三个叶的深度为 2、2、1，$WPL=1\times 2+2\times 2+4\times 1=10$，也等于每次合并产生的父权 $3+7$。

</div>

<div class="study-unit" id="u-01-steps-ecd334dddd">

**构造与编码步骤**

</div>

<div class="study-unit" id="u-01-a823da60d879">

1. 每个带权叶结点先看作一棵独立树。
2. 取根权最小的两棵树 → 建立共同父结点，父权为两者之和。
3. 将新树放回集合 → 重复选两棵、合并，直到只剩一棵树。
4. 左右分支分别标 0、1 → 从根走到各叶，路径上的位串就是该叶编码。

</div>

### 堆及其应用

<div class="study-unit" id="u-01-outline-c26d081574">

堆是满足局部大小关系的完全二叉树：大根堆父结点不小于孩子，小根堆父结点不大于孩子。它只保证根为极值，不保证左右子树之间整体有序。数组从 1 编号时，i 的孩子为 2i、$2i+1$。

</div>

<div class="study-unit" id="u-01-239c57ad13c9">

插入把新元素放末尾，再与父结点比较、向上调整；删除堆顶把末元素移到根，再选合适孩子向下调整，均为 $O(\log  n)$，查看堆顶 $O(1)$。

</div>

<div class="study-unit" id="u-01-e71aeea27cb9">

自底向上建堆 $O(n)$，可用于优先队列、堆排序和反复选择极值。

</div>

<div class="study-unit" id="u-01-steps-661538b761">

**以大根堆为例，分清三种操作**

</div>

<div class="study-unit" id="u-01-93e7332ae4e5">

1. **插入**：放在数组末尾 → 与父结点比较 → 比父大就交换并继续向上，直到根或不再违反堆序。
2. **删堆顶**：保存根 → 末元素补到根并缩短堆 → 与较大孩子比较、必要时交换，逐层向下。
3. **建堆**：从最后一个非叶结点开始 → 各做一次向下调整 → 倒序处理到根。小根堆反转大小比较方向。

</div>

<a id="s-01-outline-union-find"></a>

### 并查集及其应用

<div class="study-unit" id="u-01-4bbd5545ee46">

**并查集**维护互不相交的集合，每棵双亲树表示一个集合，数组保存双亲下标；根常用负数记录集合大小，初始各为 −1。

</div>

<div class="study-unit" id="u-01-e2fce4831141">

Find 沿双亲找根，两元素根相同即在同一集合。Union 先找根，不同才合并，常把小树接到大树并更新大小；路径压缩把查找路径直接挂到根，可降低树高，用于 Kruskal 判环。

</div>

<div class="study-unit" id="u-01-explain-2f9a24e9ff">

并查集只关心“是否属于同一组”。

</div>

<div class="study-unit" id="u-01-dae61f61790f">

例如已有集合 {A,B} 和 {C}，Union(B,C) 会把两棵树的根连接起来，使三者归为一组；Kruskal 选边时，若两个端点 Find 得到同一根，说明已有路径连接它们，再加该边就会成环。

</div>

<div class="study-unit" id="u-01-steps-d912a162d1">

**Find 与 Union 的执行顺序**

</div>

<div class="study-unit" id="u-01-79b7cec06b85">

1. Find 从当前元素沿双亲链接向上找，直到根；做路径压缩时，将沿途结点直接连到根。
2. Union 先分别 Find 两个元素 → 根相同，不必合并；根不同，按大小或秩连接两根。
3. 更新新根记录的大小或秩。判断图中的一条边是否成环：两端同根 → 已有连通路径，加边会成环。

</div>

## 第六章 图

<span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="s-18"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="p-131"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="p-132"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-555aa578667d"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-b520f43c6d5d"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-e67f97304956"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-789cdb7f2d16"></span>
<a id="s-01-a8f1e3390852"></a>

### 图的概念

<div class="study-unit" id="u-01-8a5da0f176fb">

图 $G=(V,E)$ 顶点集非空，边集可为空。无向边记 (u,v)，有向 u→v 的 u 为弧尾、v 为弧头。路径长度通常是边数，带权路径长度为边权和；简单路径不重复顶点，回路首尾相同。

</div>

<div class="study-unit" id="u-01-b6242ea4bca0">

| 性质 | 结论 |
| --- | --- |
| 无向度数和 | 2e |
| 有向入度和 / 出度和 | 各为 e |
| 简单无向完全图边数 | $n\frac{n-1}{2}$ |
| 简单有向完全图弧数 | $n(n-1)$ |
| n 点无向连通图 | 至少 $n-1$ 条边；边数 $> (n-1)(n-2)/2$ 时一定连通 |
| 子图 | V′⊆V、E′⊆E，且边端点必须在 V′ 中 |

</div>

<div class="study-unit" id="u-01-d23a7fde90fe">

无向图的极大连通子图称连通分量；有向图两两双向可达的极大子图称强连通分量。“极大”是不能再扩展，不是顶点数最多。无向图连通且无环时是树；生成树包含全部顶点和 $n-1$ 条边。

</div>

<span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="s-19"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="p-149"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="p-150"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="p-151"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="p-152"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="p-153"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="p-154"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="u-01-e7f6c011776e"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="u-01-556cd9933530"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="u-01-1bc37d8d9254"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="u-01-7902699be42c"></span><span class="legacy-anchor" data-target="s-01-ce6ac417ead5" id="u-01-e49dd93baf40"></span>

### 存储结构

<div class="study-unit" id="u-01-71286e3669a0">

| 存储 | 怎么存 / 场景 | 代价 |
| --- | --- | --- |
| 邻接矩阵 | $n\times n$ 数组记录边；无向矩阵对称，适合稠密图 | $O(n^{2})$ 空间，$O(1)$ 判边；出度看行、入度看列 |
| 邻接表 | 每顶点接邻接链，适合稀疏图 | $O(n+e)$ 空间，无向边存两份、有向边存一份 |
| 十字链表 | 有向弧结点同时挂在弧尾出边链、弧头入边链 | 便于查入出边、删弧 |
| 邻接多重表 | 无向边只设一个结点，分别挂在两端点边链 | 便于删边，避免边的双份存储 |

</div>

<div class="study-unit" id="u-01-f9b09b56a985">

### 图的基本操作

<div class="study-unit" id="u-01-outline-fbe6f5aa4b">

图的基本操作包括增删顶点、增删边、判断邻接、求邻接点以及读取／修改边权。

</div>

<div class="study-unit" id="u-01-d340f6d049f8">

无向图添加边 (u,v) 时，邻接矩阵需同时改 A[u][v] 与 A[v][u]，邻接表通常在两端各加一项；

</div>

<div class="study-unit" id="u-01-3ea3bce08389">

有向图只按 u→v 的方向登记。

</div>

<div class="study-unit" id="u-01-e3ff4b37f268">

删除顶点还必须删除所有关联边，不能只移走顶点记录。

</div>

<span class="legacy-anchor" data-target="s-01-02ad10a1f27f" id="s-20"></span><span class="legacy-anchor" data-target="s-01-02ad10a1f27f" id="p-161"></span><span class="legacy-anchor" data-target="s-01-02ad10a1f27f" id="p-162"></span><span class="legacy-anchor" data-target="s-01-02ad10a1f27f" id="u-01-af2265f07f09"></span>
<a id="s-01-02ad10a1f27f"></a>

### 图的遍历

<div class="study-unit" id="u-01-33e5f592d1cd">

**DFS（深度优先搜索，Depth-First Search）**：访问起点→选一个未访问邻接点递归深入→无邻接点可走时回退；用递归栈或显式栈，产生深度优先生成树 / 森林。

</div>

<div class="study-unit" id="u-01-9460721ccefe">

**BFS（广度优先搜索，Breadth-First Search）**：起点标记并入队→出队一个点→将其未访问邻接点标记并入队→重复至队空。

</div>

<div class="study-unit" id="u-01-3e7698d57b67">

入队就标记，避免重复入队；可求无权图最少边数路径。

</div>

<div class="study-unit" id="u-01-c9ac15c36a68">

非连通图需对尚未访问点再次启动。

</div>

<div class="study-unit" id="u-01-1754084da588">

两算法邻接矩阵 $O(n^{2})$，邻接表 $O(n+e)$，辅助空间最坏 $O(n)$。

</div>

<div class="study-unit" id="u-01-e201a8f56b12">

DFS 检测有向环需区分“已完成”和“当前递归路径中”；无向判环须排除返回双亲的边，不能见 visited 就判环。

</div>

<div class="study-unit" id="u-01-steps-37ff7d241c">

**DFS：一条路走到底，再回退**

</div>

<div class="study-unit" id="u-01-710f39f72fc0">

1. 访问起点并标记。
2. 选择一个未访问的邻接点 → 对它递归执行 DFS。
3. 当前点没有未访问邻接点 → 返回上一层，继续检查其他邻接点。

</div>

<div class="study-unit" id="u-01-f3db35e23d08">

**BFS：用队列一层层扩展**

</div>

<div class="study-unit" id="u-01-9d37671d80cc">

1. 起点标记为已访问 → 入队。
2. 队首出队 → 依次检查它的邻接点。
3. 未访问邻接点先标记、再入队 → 重复到队空；非连通图对剩余未访问点重新启动。

</div>

<span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="s-21"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="u-01-49b9d295de17"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="u-01-4fc82b26aecb"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="u-01-8cb6d927fa6d"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="s-01-a1abef19fd89"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="u-01-a3d09b5c5f46"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="u-01-959bda0e579c"></span><span class="legacy-anchor" data-target="s-01-6f6745dcebfc" id="u-01-e70910d084a0"></span>

### 图的应用

<span class="legacy-anchor" data-target="s-01-f625d100ccca" id="s-22"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="p-169"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="p-170"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-3eed04ade846"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-1a72bd800758"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-2c624232cdd2"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-92f508c20f8c"></span>

#### 最小生成树

<div class="study-unit" id="u-01-abbe069e508e">

最小生成树 MST（Minimum Spanning Tree） 针对**带权无向连通图**，含 n 点、$n-1$ 边且总权最小；非连通图只能求最小生成森林。

</div>

<div class="study-unit" id="u-01-29035c6700a2">

| 算法 | 执行过程 | 特点 |
| --- | --- | --- |
| Prim | 1. 任取一点建立集合 S<br>2. 选连接 S 与外部的最小权边，加入新点并更新候选边<br>3. 重复到选完所有点 | 每次加一个点，朴素 $O(n^{2})$，适合稠密图 |
| Kruskal | 1. 边按权递增排序<br>2. 逐条取边，若两端分属不同集合则加入并合并，否则丢弃<br>3. 选够 $n-1$ 边结束 | 每次加一条不成环边；$O(e \log  e)$，适合稀疏图 |

</div>

<div class="study-unit" id="u-01-75cfac59893e">

所有边权互异时 MST 唯一；有相同边权仅“可能”不唯一。MST 总权最小，不保证某源点到其他点的路径最短。

</div>

#### 最短路径

<div class="study-unit" id="u-01-explain-1e5b3dca2c">

dist[v] 表示当前找到的“源点到 v 的最好距离”，w(u,v) 是 u→v 的边权；

</div>

<div class="study-unit" id="u-01-98ff2618cb32">

“松弛”就是发现经过 u 更短时，改小 dist[v] 并记录前驱。

</div>

<div class="study-unit" id="u-01-66314e74e4d0">

例：A→B 为 2、A→C 为 7、B→C 为 1，先确定 B 后把到 C 的距离从 7 改成 3，路径成为 A→B→C。

</div>

<div class="study-unit" id="u-01-01b5a67c54d5">

Floyd 的 d[i][j] 同样表示 i 到 j 的距离，只是逐轮允许更多中间点。

</div>

<div class="study-unit" id="u-01-2e4749daa15d">

| 算法 | 执行过程 | 条件 / 复杂度 |
| --- | --- | --- |
| BFS | 源点按层扩展，首次到达层数即距离 | 无权或等权图，邻接表 $O(n+e)$ |
| Dijkstra | 1. dist 初始为源点直达距离<br>2. 每轮确定未确定点中 dist 最小的 u，用 dist[u]+w(u,v) 松弛邻接点 | 非负权，朴素 $O(n^{2})$；负权边不能直接用 |
| Floyd | 1. 初始矩阵为边权、主对角线 0<br>2. 依次允许 k 为中间点，$d[i][j]=\min (d[i][j],d[i][k]+d[k][j])$ | 任意两点最短路，$O(n^{3})$；可有负权边，有限最短路不能经过负权环 |

</div>

<div class="study-unit" id="u-01-a60f3b151d6a">

Dijkstra 比的是“源点→u→v”的累计距离，不是当前点最短出边。Floyd 的 k 在最外层循环。不可达记 ∞，运算时避免把 ∞ 当普通数溢出。

</div>

<div class="study-unit" id="u-01-steps-319482c6b0">

**Dijkstra：每轮“确定一个最近点 → 更新它的邻居”**

</div>

<div class="study-unit" id="u-01-85dfb58a4cc5">

1. 源点距离为 0，其余先设为无穷；把源点直达边作为初始候选距离。
2. 从尚未确定的顶点中选 $\mathrm{dist}$ 最小者 $u$，确定其最短距离；若最小值仍为无穷，剩余顶点不可达。
3. 遍历 $u$ 的邻接点，用 $\mathrm{dist}(u)+w(u,v)$ 与原 $\mathrm{dist}(v)$ 比较 → 更小才更新距离和前驱。
4. 回到第 2 步，直到完成。前提：边权非负。

</div>

<div class="study-unit" id="u-01-89e304c65eb1">

**Floyd：逐轮增加一个可用中间点**

</div>

<div class="study-unit" id="u-01-1a0aea70051c">

1. 对角线为 0，有边填边权，无边填无穷。
2. 固定中间点 $k$，枚举全部起点 $i$、终点 $j$。
3. 比较“直接的当前最好距离”与“经 $k$ 的距离” → 取较小者；$k$ 必须放在最外层循环。

</div>

#### 拓扑排序

<div class="study-unit" id="u-01-7480a92e94e9">

拓扑序要求每条 u→v 的 u 在 v 前面；存在拓扑序当且仅当图为 DAG（有向无环图，Directed Acyclic Graph）。

</div>

<div class="study-unit" id="u-01-1110ae6c167c">

1. **统计入度**：计算每个顶点的入度，把所有入度为 0 的顶点放入队列或栈。
2. **输出一个顶点**：取出一个入度为 0 的顶点，加入拓扑序列。
3. **删除它的影响**：遍历它的出边，将各邻接点的入度减 1；新变为 0 的顶点加入队列或栈。
4. **重复直到容器为空**：输出 $n$ 个顶点 → 存在拓扑序；不足 $n$ 个 → 图中有环。

</div>

<div class="study-unit" id="u-01-2088ecaa814c">

多个入度为 0 的顶点可任选，所以拓扑序可能不唯一。使用邻接表时，时间复杂度为 $O(n+e)$。

</div>

</details>

<span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="s-26"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="p-191"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="p-192"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-ae96ae372a09"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-d5bfaee338f9"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-be7a1c1cd26c"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-6b51d431df5d"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-7f2209b29d9f"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-04cf7f4acaa1"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-37dd2c0a61c9"></span><span class="legacy-anchor" data-target="s-01-4eb97aaa7f6d" id="u-01-3fdba35f04dc"></span>
<a id="s-01-4eb97aaa7f6d"></a>

#### 关键路径

<div class="study-unit" id="u-01-129fd544daa6">

AOE 网（边表示活动的网，Activity On Edge）以点表示事件、带权边表示活动和时长，要求无环。**关键路径为源到汇最长耗时路径**，长度决定最短工期，可能多条。

</div>

<div class="study-unit" id="u-01-8a0e3d2bd4f0">

**先认清符号。** $w(u,v)$ 是活动 $u\to v$ 的时长；$ve(v)$、$vl(v)$ 分别表示事件 $v$ 的最早、最迟发生时间，$e(u,v)$、$l(u,v)$ 表示活动的最早、最迟开始时间。

</div>

<div class="study-unit" id="u-01-238ae162d062">

**总流程**：拓扑排序 → 正推最早时间 → 逆推最迟时间 → 求活动时间差 → 连出关键路径。

</div>

<div class="study-unit" id="u-01-a1604926d452">

1. **正推 $ve$：所有前驱都完成，事件才能发生，因此取最大值。** 源点的 $ve=0$，按拓扑顺序计算其余事件：

</div>

<div class="study-unit" id="u-01-c239085d9e1e">

$$ve(v)=\max_{u\to v}\{ve(u)+w(u,v)\}$$

</div>

<div class="study-unit" id="u-01-96052ef6c25f">

2. **确定工期，再逆推 $vl$。** 工期 $T$ 等于汇点的最早发生时间；多个汇点时取它们的最大值，并将各汇点的最迟时间初始化为 $T$。按逆拓扑顺序计算；为了不耽误任何后续活动，取最小值：

</div>

<div class="study-unit" id="u-01-6dafc349f811">

$$vl(u)=\min_{u\to v}\{vl(v)-w(u,v)\}$$

</div>

<div class="study-unit" id="u-01-2195d95411a1">

3. **把事件时间换成活动开始时间。** 对每条活动 $u\to v$：

</div>

<div class="study-unit" id="u-01-9be8c77b460b">

$$e(u,v)=ve(u),\qquad l(u,v)=vl(v)-w(u,v)$$

</div>

<div class="study-unit" id="u-01-4d9d8c879993">

最早开始看起点；最迟开始用终点的最迟发生时间减去活动时长。

</div>

<div class="study-unit" id="u-01-c091ab9d9e5b">

4. **找关键活动，再连路径。** 计算时间余量 $l(u,v)-e(u,v)$；余量为 0 的是关键活动，将它们按连接关系连成源到汇的关键路径，可能不止一条。

</div>

<div class="study-unit" id="u-01-7d5f998b2478">

**记忆线索**：最早时间“正推取大” → 最迟时间“逆推取小” → 活动“最早看起点，最迟看终点减时长”。

</div>

<div class="study-unit" id="u-01-4d280fcf374d">

增加关键活动时长会延长工期；只缩短某一关键路径上的活动未必缩短工期，其他关键路径仍可能限制。缩短幅度较大时可能产生新关键路径，需重新计算。

</div>

<div class="study-unit" id="u-01-explain-e4c7c53928">

**算例：把四步连起来。** 活动为 $A\to B:2$、$A\to C:4$、$B\to D:3$、$C\to D:2$。

</div>

<div class="study-unit" id="u-01-068e9106525c">

| 顺序 | A | B | C | D |
| --- | --- | --- | --- | --- |
| 正推 $ve$ | 0 | 2 | 4 | $\max(2+3,4+2)=6$ |
| 逆推 $vl$ | $\min(3-2,4-4)=0$ | 3 | 4 | 6 |

</div>

<div class="study-unit" id="u-01-aec3a10558b2">

工期为 6；$A\to C$ 与 $C\to D$ 的时间余量均为 0 → 关键路径为 **$A\to C\to D$**。

</div>

<div class="study-unit" id="u-01-cb408e317b06">

再看单条活动：若时长为 3、起点 $ve=4$、终点 $vl=10$，则最早开始为 4、最迟开始为 $10-3=7$ → 可以推迟 3 个时间单位，所以它不是关键活动。

</div>

## 第七章 查找

<span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="s-28"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="p-199"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="p-200"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="u-01-7b597ac736e3"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="u-01-1cc9666eba4d"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="u-01-8527a891e224"></span>
<a id="s-01-2dd94635b6d1"></a>

### 线性查找

<div class="study-unit" id="u-01-05de7dffca32">

**平均查找长度 ASL（Average Search Length）**：$\mathrm{ASL}=\sum_i p_iC_i$，Cᵢ 比较次数，pᵢ 概率；等概率才是总次数除以对象数，成功与失败分别统计。

</div>

<div class="study-unit" id="u-01-a98be6531d19">

| 算法 | 执行过程 | 条件 / 结果 |
| --- | --- | --- |
| 顺序查找 | 逐个比较，哨兵可省越界判断 | 无需有序；等概率成功 $\mathrm{ASL}=\frac{n+1}{2}$；失败 n 或 $n+1$ 次，是否计哨兵看题设 |
| 折半查找 | 有序表取 mid，比较后保留可能的一半，直到命中或区间空 | 需有序和随机存取；$O(\log  n)$，链表一般不适合 |
| 分块查找 | 索引记录各块最大值和起点，先定位块再块内顺序查 | 块间有序、块内可无序；等长块、两层顺序查时 $\mathrm{ASL}=\frac{b+1}{2}+\frac{s+1}{2}$，$b\cdot s=n$，$s\approx \sqrt{n}$ 最优 |

</div>

<div class="study-unit" id="u-01-32efc773f40f">

折半成功次数为结点层数，失败次数为对应空区间双亲的层数，失败区间有 $n+1$ 个。mid 向下取整时偶数规模左少右多，向上取整则相反。

</div>

<div class="study-unit" id="u-01-explain-3096b8b291">

计算 ASL 可以先画查找判定树：找到根上的元素比较 1 次，下一层比较 2 次，依此类推。

</div>

<div class="study-unit" id="u-01-5d48de0d3b8a">

例：[10,20,30] 折半查找先比较 20，成功查 20、10、30 分别需 1、2、2 次，等概率成功 $\mathrm{ASL}=\frac{5}{3}$；

</div>

<div class="study-unit" id="u-01-6f48c153ea39">

失败则分别沿四个空区间的查找路径计数。

</div>

<div class="study-unit" id="u-01-steps-3149d10151">

**折半查找的四步**

</div>

<div class="study-unit" id="u-01-b8bb54da7154">

1. 初始化有效区间 $[low,high]$。
2. 若 $low>high$ → 查找失败；否则取中间位置 $mid$。
3. 与中间元素比较 → 相等则成功；目标更小则令 $high=mid-1$；目标更大则令 $low=mid+1$。
4. 回到第 2 步。前提：顺序存储的有序表，取整规则按题设。

</div>

### 树形查找

<span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="s-30"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="p-208"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="p-209"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="u-01-a8b8bf7af058"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="u-01-dc122c3f9ff5"></span>
<a id="s-01-d1a32948b17f"></a>

#### 二叉搜索树

<div class="study-unit" id="u-01-222b203af27b">

BST（二叉搜索树 / 二叉排序树，Binary Search Tree）左子树小于根、右子树大于根，各子树也满足；中序结果递增，重复值按题设。

</div>

<div class="study-unit" id="u-01-fcef4cbbf835">

查找小走左、大走右，直到相等或空。插入沿查找路径到空位置，成为新叶。删除：叶直接删；仅一子树用孩子顶替；有两子树，用中序前驱或后继替换，再删除原前驱 / 后继结点。

</div>

<div class="study-unit" id="u-01-837cf9881897">

$O(h)$；平衡时 $O(\log  n)$，退化为链时 $O(n)$，不是所有 BST 都保证对数复杂度。

</div>

<span class="legacy-anchor" data-target="s-01-659f23556a6c" id="s-31"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-214"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-215"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-216"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-217"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-218"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-219"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-220"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="u-01-42f563b4c80f"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="u-01-0268a12fde0e"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="u-01-4c08838d5a32"></span>
<a id="s-01-659f23556a6c"></a>

#### 平衡二叉树

<div class="study-unit" id="u-01-8c04631fe99d">

AVL 平衡二叉树是任意结点左右子树高度差$\le 1$ 的 BST，平衡因子通常为左高−右高。插删先按 BST 操作，再沿祖先调整；查找 $O(\log  n)$。

</div>

<div class="study-unit" id="u-01-833b33d09c10">

| 类型 | 最小失衡子树的调整 |
| --- | --- |
| LL（左—左型） | 失衡根右旋 |
| RR（右—右型） | 失衡根左旋 |
| LR（左—右型） | 先左旋左孩子，再右旋失衡根 |
| RL（右—左型） | 先右旋右孩子，再左旋失衡根 |

</div>

<div class="study-unit" id="u-01-db99f9bb8cc9">

插入通常调整最低失衡祖先即可；删除可能使更高祖先继续失衡。最少结点 $N(h)=N(h-1)+N(h-2)+1$，$N(0)=0$、$N(1)=1$，可反求最大高度。

</div>

<div class="study-unit" id="u-01-explain-4b3c2c19ac">

判断 LL/LR 等类型，要从最低失衡祖先看哪一侧更高，再看该侧孩子哪一侧更高。

</div>

<div class="study-unit" id="u-01-aaba1e4dd080">

例：依次插入 3、2、1，3 的左—左侧过高，对 3 右旋后变成 2 为根、1 和 3 为左右孩子；旋转只改局部链接，仍保持中序递增。

</div>

<span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="s-32"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="p-224"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="u-01-6087e3abbf7d"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="u-01-a6e9e8c7eda6"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="u-01-c8a575353396"></span>
<a id="s-01-4c390d9c1380"></a>

#### 红黑树

<div class="study-unit" id="u-01-78fb81f6e71f">

红黑树是带颜色约束的 BST：根与 NIL（空叶结点）均为黑色；红点的孩子都黑；任一点到各 NIL 叶路径上的黑点数相同；每点红或黑。NIL 叶不是数据结点。

</div>

<div class="study-unit" id="u-01-ff0399e975bf">

最长路径$\le$最短路径两倍；n 内部点高度$\le 2\log_{2}(n+1)$，查找插删 $O(\log  n)$，不要求每个点左右高度差$\le 1$。

</div>

<div class="study-unit" id="u-01-61e1b15d3641">

插入先按 BST 并染红；父黑结束；父红时，叔红则父叔染黑、祖父染红向上处理；叔黑则旋转变色消除连续红，最后根染黑。删除若减少黑高需调整，不能按普通 BST 删除后直接结束。

</div>

<div class="study-unit" id="u-01-explain-3202d714ee">

插入调整中，“叔”是父结点的兄弟，空叔按黑色算。

</div>

<div class="study-unit" id="u-01-2979eb287794">

父红、叔黑时，若新结点—父—祖父呈折线，先旋转父转成直线；再旋转祖父，把新子树根染黑、原祖父染红。

</div>

<div class="study-unit" id="u-01-88cd6332864b">

父红、叔红则父和叔先染黑、祖父染红，再把祖父当作新的检查点向上处理，最后保证整树根黑。

</div>

<span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="s-33"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="p-225"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="p-226"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="u-01-1d3fefe39b7b"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="u-01-0983c05a4f4f"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="u-01-2ad2d45364e8"></span>
<a id="s-01-525cdc72d72d"></a>

#### B树

<div class="study-unit" id="u-01-e629fa6598d7">

m 阶 B 树是多路平衡搜索树，所有叶同层；非空结点的关键字升序，k 个孩子对应 $k-1$ 个关键字，孩子划分关键字范围。

</div>

<div class="study-unit" id="u-01-03e487830c88">

每结点至多 m 个孩子、$m-1$ 个关键字；非根内部结点至少 $\lceil \frac{m}{2}\rceil$ 个孩子、$\lceil \frac{m}{2}\rceil -1$ 个关键字；非叶根至少 2 个孩子。教材“叶”常指不含关键字的外部失败结点，先统一高度约定。

</div>

<div class="study-unit" id="u-01-65d5badb924f">

查找先结点内比较，再进对应孩子。

</div>

<div class="study-unit" id="u-01-237a03142612">

插入在最底层非空结点，溢出则分裂、中央关键字上移，双亲也溢出则继续。

</div>

<div class="study-unit" id="u-01-479a0c05f261">

删除内部关键字可换前驱 / 后继后再删；

</div>

<div class="study-unit" id="u-01-1edba9bffb94">

不足则向有余量兄弟借并改双亲，否则与兄弟及双亲分隔关键字合并，可能向上继续。

</div>

<div class="study-unit" id="u-01-a624e5acd449">

磁盘访问次数取决于树高。

</div>

<div class="study-unit" id="u-01-08c624a7a522">

高度 h 只计含关键字层、$m\ge 3$，$q=\lceil \frac{m}{2}\rceil$，n 个关键字满足 $2q^{h-1}-1\le n\le m^{h}-1$；据此求最小 / 最大高度，外部失败叶不计入 h。

</div>

<div class="study-unit" id="u-01-explain-1bc8fba62b">

“m 阶”限制的是最大孩子数。

</div>

<div class="study-unit" id="u-01-a40e9745bd40">

例：3 阶 B 树一个结点最多有 2 个关键字；若插入后某结点暂为 [10,20,30]，把中央 20 上移，左右留下 [10]、[30]。

</div>

<div class="study-unit" id="u-01-680924d5d1e6">

若它原本就是根，就建立以 20 为关键字的新根，树高增加一层。

</div>

<div class="study-unit" id="u-01-explain-a6992e4e68">

向兄弟“借”关键字要经过双亲：把双亲中分隔这两棵子树的关键字下放到不足结点，再用兄弟的边界关键字补回双亲；非叶还要迁移相应孩子。

</div>

<div class="study-unit" id="u-01-341a0b18037c">

兄弟也没有余量时，才把两结点和双亲分隔关键字合并，双亲因此可能继续不足。

</div>

#### B+树

<div class="study-unit" id="u-01-b17ef6d19c7a">

B+ 树的记录全在叶层，叶通常按关键字链接；非叶仅作索引，查记录必须到叶。适合范围查询与顺序扫描。

</div>

<div class="study-unit" id="u-01-4df0044533a5">

408 常用 m 阶约定中每结点最多 m 个关键字 / 非叶孩子；

</div>

<div class="study-unit" id="u-01-06e60774129b">

除根外关键字至少 $\lceil \frac{m}{2}\rceil$ 个，非叶根至少 2 个孩子、根叶可更少。

</div>

<div class="study-unit" id="u-01-87cf6901c37a">

非叶有 k 孩子时有 k 索引关键字（B 树是 $k-1$），常取孩子子树最大关键字；

</div>

<div class="study-unit" id="u-01-e9a6b42030b7">

采用其他阶数定义时按题设。

</div>

<div class="study-unit" id="u-01-2d1ec9bb680f">

上层索引会在叶层重复，非叶索引不代替叶层记录。

</div>

<div class="study-unit" id="u-01-f12783b94a0b">

相比 B 树，扇出通常更大、层数较少，范围检索方便，单点路径较稳定；不能在非叶发现相同索引就结束记录查找。

</div>

<div class="study-unit" id="u-01-explain-4c4a4dd341">

范围查询 [20,50] 时，先沿索引找到 20 应在的叶结点，再沿叶层链接读取后续记录，直到超过 50。上层只帮你定位入口，所以即使在上层看到关键字 20，仍要到叶层取得记录。

</div>

### 散列查找

<div class="study-unit" id="u-01-463a5a66fde0">

散列表用 H(key) 定位。装填因子 $\alpha=\frac{\text{记录数}}{\text{表长}}$，越大通常冲突越多；不同关键字得到相同地址称冲突，同义词不等于重复关键字。

</div>

<div class="study-unit" id="u-01-d2f7ecf66f4c">

| 处理 | 执行 / 考点 |
| --- | --- |
| 线性探测 | H、$H+1$、$H+2$…取模，可能聚集；直到命中或从未用过的空槽 |
| 平方探测 / 双散列 | 按题设增量探测；是否覆盖全表依参数，不能假定必访每槽 |
| 拉链 | 同散列地址记录放同一链表，插删方便，需额外指针 |

</div>

<div class="study-unit" id="u-01-5601658f9b6c">

除留余数 $H(key)=key \bmod  p$，p 常取不超过表长的合适素数。开放定址删除留“已删除”标志，直接置空可能截断查找链。

</div>

<div class="study-unit" id="u-01-0716167bb9a1">

成功 ASL：从每个关键字初始地址模拟到命中求平均。失败 ASL：从各可能初始地址探测到真空槽，计入空槽检查，按初始地址概率平均；分母是初始散列地址的可能取值数，不一定为表长。

</div>

<div class="study-unit" id="u-01-explain-8b58001d05">

例：表长 7，$H(k)=k \bmod  7$，插入 10、17 时，10 放在槽 3，17 冲突后放槽 4。

</div>

<div class="study-unit" id="u-01-d9dd8f09fc96">

查 17 要检查槽 3、4，共 2 次；若删除 10，槽 3 应留“已删除”标志，否则查 17 会在槽 3 误判失败。

</div>

## 第八章 排序

<span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="s-37"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-244"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-245"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-246"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-247"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-248"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-249"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-250"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-251"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-252"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-253"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-254"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-255"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-256"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="u-01-9abbc11240d1"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="u-01-4f377c8778ad"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="u-01-b48ba6821b46"></span>
<a id="s-01-e2d3b81989aa"></a>

### 内部排序

<div class="study-unit" id="u-01-56815e3f714d">

稳定排序保持相等关键字记录的原相对顺序；“一趟确定最终位置”不同于“局部有序”。

</div>

<div class="study-unit" id="u-01-25b480c8fe30">

| 算法 | 一趟怎么执行 | 时间：最好 / 平均 / 最坏 | 辅助空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 直接插入 | 下一元素插入有序前缀，比它大者后移 | $n / n^{2} / n^{2}$ | $O(1)$ | 是 |
| 折半插入 | 折半找插入点，再移动元素；相等插在已有相等者后 | 比较 $O(n \log  n)$，移动最坏 $O(n^{2})$ | $O(1)$ | 是 |
| 希尔 | 按增量分组插排，逐步减小增量至 1 | 依增量序列，不固定为 $n^{1}.3$ | $O(1)$ | 否 |
| 冒泡 | 邻接逆序交换，一趟极值归位，无交换提前结束 | $n / n^{2} / n^{2}$ | $O(1)$ | 是 |
| 快排 | 枢轴划分两侧，递归子区间 | $n \log  n / n \log  n / n^{2}$ | 栈平均 $O(\log  n)$、最坏 $O(n)$ | 否 |
| 选择 | 未排序区选最小，与该区首位交换 | $n^{2} / n^{2} / n^{2}$ | $O(1)$ | 否 |
| 堆 | 升序大根堆，堆顶与末项换，缩小堆、向下调整 | n log n / n log n / n log n | $O(1)$ | 否 |
| 二路归并 | 两有序段用双指针取较小者，合并为新段 | n log n / n log n / n log n | $O(n)$ | 是 |
| 基数 LSD（最低位优先，Least Significant Digit） | 从低位到高位，按桶稳定分配、收集 | $O(d(n+r))$，d 位数、r 基数 | 链式桶常 $O(r)$，数组可 $O(n+r)$ | 是 |

</div>

<div class="study-unit" id="u-01-efb2703d2ba9">

表内 n 等简写表示 $O(\cdot )$。堆是完全二叉树，升序用大根堆，父$\ge$孩子；自最后非叶向上建堆 $O(n)$，逐个插入建堆通常 $O(n \log  n)$。

</div>

<div class="study-unit" id="u-01-16e8b2d816f3">

冒泡、选择、堆一趟至少固定一元素；常用枢轴归位快排固定枢轴。插入只保证前缀有序，归并只保证段内有序，不表示最终位置。

</div>

<div class="study-unit" id="u-01-1a3ba63dc705">

插入、提前终止冒泡已有序时最好；快排关键看划分是否均衡，首 / 尾枢轴遇有序才易最坏，不是所有快排有序就最坏。比较排序最坏下界 Ω(n log n)，基数不属于比较排序。

</div>

<div class="study-unit" id="u-01-explain-ba0a77104d">

“稳定”看相同关键字的记录是否换了先后：2甲、1、2乙 排序后若为 1、2甲、2乙 就保持稳定。

</div>

<div class="study-unit" id="u-01-12cad8a6c8e3">

快排的一趟是围绕枢轴划分左右区间，不是把整个区间排好；归并的一趟则把若干有序小段合成更大的有序段。

</div>

<div class="study-unit" id="u-01-steps-0dfb0dbd4b">

**手算排序，按一趟的动作记录**

</div>

<div class="study-unit" id="u-01-e50f4a0e1eb0">

| 算法 | 一趟如何执行 → 何时继续 |
| --- | --- |
| 直接插入 | 暂存待插元素 → 向前比较并后移较大元素 → 填入空位 → 取下一元素 |
| 折半插入 | 在已排好部分折半确定位置 → 后移元素 → 插入；折半省比较，不省移动 |
| 起泡 | 相邻逆序就交换 → 一趟把一个极值送到末端 → 缩短未排序范围 |
| 简单选择 | 扫描未排序区找最小者 → 与该区首元素交换 → 区间起点后移 |
| 希尔 | 按增量分组 → 各组插入排序 → 缩小增量，最后必须为 1 |
| 快速 | 选枢轴 → 一趟划分使其两侧分别满足大小关系 → 递归处理两侧 |
| 堆排序 | 建大根堆 → 根与末元素交换 → 缩短堆、向下调整 → 重复 |
| 二路归并 | 相邻有序段两两合并 → 段长翻倍 → 重复到只剩一段 |
| LSD 基数 | 从最低位起稳定分配到桶 → 按桶序收集 → 处理更高一位 |

</div>

<div class="study-unit" id="u-01-319750d5c14a">

每趟都应标出已确定的元素或有序段；复杂度与稳定性仍按上面的对照表及条件判断。

</div>

<span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="s-38"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-270"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-271"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-272"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-273"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-286"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-287"></span>
<a id="s-01-b63777b18aa0"></a>

### 外部排序

<div class="study-unit" id="u-01-1cca7812c604">

外部排序用于数据大于内存，重点减少磁盘 I/O

</div>

<div class="study-unit" id="u-01-dc3d6a04af8e">

1. 分批读入、内排序形成初始段。
2. 多路归并逐趟合并至一段。

</div>

<div class="study-unit" id="u-01-a25c82a2d3dd">

r 个初始段，k 路归并趟数约 $\lceil \log_{k}r\rceil$；每趟通常读、写全体记录。增大 k 可减趟数，但需 k 输入缓冲及输出缓冲；败者树选最小段头，更新 $O(\log  k)$。

</div>

<div class="study-unit" id="u-01-2122da15da93">

置换选择：维护工作区，输出可参加本段的最小记录；新读记录小于刚输出关键字则冻结到下一段；全冻结时结束本段并解冻。初始段平均可长于工作区，不保证总是恰两倍。

</div>

<div class="study-unit" id="u-01-cb615efae309">

最佳归并树：不同长度段用 k 叉哈夫曼树减少加权读写量；$(r-1) \bmod  (k-1)\ne 0$ 时补权 0 虚段。

</div>

<div class="study-unit" id="u-01-explain-4c1b0f7de5">

例：8 个初始有序段做二路归并，段数依次 8→4→2→1，共 3 趟；四路归并则 8→2→1，共 2 趟。败者树只维护每个输入段当前最小的“段头”，输出一个段头后，仅更新该段的新段头。

</div>

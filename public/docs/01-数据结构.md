# 数据结构

<span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="s-2"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="p-2"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="p-3"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="p-4"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="p-5"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="u-01-02e7670add04"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="u-01-198ee8a7b84d"></span><span class="legacy-anchor" data-target="s-01-42697ee76bb7" id="u-01-893c04b13fbc"></span>

## 第一章 绪论

<div class="study-unit" id="u-01-34330ba3e975">

**数据结构**研究数据的逻辑关系、存储方式及操作。逻辑结构分集合、线性结构、树和图；存储结构分顺序、链式、索引和散列。数据元素是基本单位，数据项是元素的组成部分；抽象数据类型 ADT（Abstract Data Type） 描述数据及操作，不规定具体实现。

</div>

<div class="study-unit" id="u-01-dc03070975a0">

**时间复杂度**看基本操作次数随 n 的增长阶：顺序执行取相加后的最高阶，嵌套循环按实际次数求和，不能只数循环层数。i*=2 为 O(log n)，i*i<n 为 O(√n)，j<i 的双循环执行 n(n−1)/2 次，为 O(n²)。递归结合递推式分析；朴素斐波那契递归时间为指数级。

</div>

<div class="study-unit" id="u-01-c67a9f7e8f76">

**空间复杂度**只计辅助空间，也计递归栈。原地迭代常为 O(1)，递归深度 n 通常需要 O(n) 栈空间；同层先后执行的调用可复用空间，不把全部调用次数算为空间。

</div>

<div class="study-unit" id="u-01-explain-d9ea22c62d">

例：i 从 1 开始每轮翻倍，到 n 前约经历 log₂n 轮，所以是 O(log n)；若内层依次执行 1、2、4、8…次，总次数是几何和、仍为 O(n)。分析嵌套循环要先求每轮次数，再求总和，不能把所有双循环都判为 O(n²)。

</div>

<span class="legacy-anchor" data-target="s-01-b0f3777d88e5" id="s-3"></span><span class="legacy-anchor" data-target="s-01-b0f3777d88e5" id="p-16"></span>
<a id="s-01-b0f3777d88e5"></a>

## 第二章 线性表

<div class="study-unit" id="u-01-concise-2">

线性表是 n 个同类型元素的有限序列。除首尾外，每个元素有唯一直接前驱和后继。位序通常从 1 开始，数组下标通常从 0 开始，计算位置前先统一约定。

</div>

<span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="s-4"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="p-17"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="p-18"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="u-01-0b4c527afd16"></span><span class="legacy-anchor" data-target="s-01-c12986cc5db7" id="u-01-5e7e5e0612a3"></span>
<a id="s-01-c12986cc5db7"></a>

### 顺序表

<div class="study-unit" id="u-01-df072b35a3f8">

顺序表把元素放在连续空间，按位访问 O(1)，按值顺序查找 O(n)。容量与当前长度不同；动态数组扩容可能需要新空间并搬移全部元素。

</div>

<div class="study-unit" id="u-01-f9ae965fe5ef">

| 操作 | 执行过程（位序从 1 开始） | 移动次数 / 复杂度 |
| --- | --- | --- |
| 在位置 i 插入 | 从后往前，把 i～n 位各后移一位，再写新元素 | n−i+1；等概率平均 n/2；O(n) |
| 删除位置 i | 取出元素，把 i+1～n 位各前移一位 | n−i；等概率平均 (n−1)/2；O(n) |

</div>

<div class="study-unit" id="u-01-79cd52b7856e">

“有序表”描述关键字顺序，“顺序表”描述存储方式，顺序表不一定有序。

</div>

<div class="study-unit" id="u-01-explain-dfb1b6c508">

例：在 [3,5,8] 的第 2 位插入 4，要先把 8 后移，再把 5 后移，最后填入 4，得到 [3,4,5,8]。从后向前移动才能保留原数据；删除时从前向后补空位即可。

</div>

<span class="legacy-anchor" data-target="s-01-aa7868153914" id="s-5"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-22"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-23"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-24"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-25"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-26"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-27"></span><span class="legacy-anchor" data-target="s-01-aa7868153914" id="p-28"></span>
<a id="s-01-aa7868153914"></a>

### 链表

<div class="study-unit" id="u-01-f52d612fce88">

链表用指针连接结点，不要求空间连续，不能随机存取。头指针指向链表的第一个结点：有头结点时指向头结点，没有时指向首元结点。头结点是可选的辅助结点，不存有效元素；首元结点才是第一个存有效数据的结点。

</div>

<div class="study-unit" id="u-01-fa8782237360">

**单链表**：查找或定位前驱 O(n)；已知前驱后插删 O(1)。头插形成输入序列的逆序，带尾指针尾插能 O(n) 建表；删尾需找前驱，即使有尾指针通常仍 O(n)。

</div>

<div class="study-unit" id="u-01-76279a64c3e7">

~~~c
// 在 p 后插入 s：先保存原后继，不能颠倒顺序
s->next = p->next;
p->next = s;
// 删除 p 的后继：先检查 q 非空
q = p->next;
if (q != NULL) {
    p->next = q->next;
    free(q);
}
~~~

</div>

<div class="study-unit" id="u-01-5ca57e48eea1">

**双链表**：有 prior、next；已知目标结点时插删 O(1)，按位或按值定位仍 O(n)。插入需同时更新四条双向链接；删除更新前后结点链接，空表、首尾边界另处理。

</div>

<div class="study-unit" id="u-01-37afc59ce2c4">

**循环链表**：尾部链接到表头。带尾指针的循环单链表，头插、头删、尾插 O(1)，尾删 O(n)；循环双链表的首尾插删均 O(1)。复杂度需区分有无头结点、尾指针。

</div>

<div class="study-unit" id="u-01-b10157f300d0">

**静态链表**：用数组下标作游标模拟 next，逻辑顺序不由数组位置决定。容量通常预先固定，空闲和结束标志按实现约定。

</div>

<div class="study-unit" id="u-01-explain-6e0e63d681">

链表插删只改相邻结点的指针，不必搬动后面的元素；但先找到目标位置，仍可能沿链走 O(n) 次。双链表在非空相邻结点 p、q 之间插入 s，要让 s 的前后指针指向 p、q，再让 p 的 next、q 的 prior 指向 s，四条链接都要接好。

</div>

## 第三章 栈、队列和矩阵

<span class="legacy-anchor" data-target="s-01-5cfaad7421e0" id="s-7"></span><span class="legacy-anchor" data-target="s-01-5cfaad7421e0" id="p-35"></span><span class="legacy-anchor" data-target="s-01-5cfaad7421e0" id="u-01-6480090999e5"></span>
<a id="s-01-5cfaad7421e0"></a>

### 卡特兰数

<div class="study-unit" id="u-01-6636c1440ac1">

固定 n 个不同元素的入栈顺序时，合法出栈序列数为 $C_n=\frac{1}{n+1}\binom{2n}{n}$，也是 n 结点的不同二叉树形态数。不是 n!，并非任意排列都可由栈得到。

</div>

<div class="study-unit" id="u-01-explain-2373d1bfd2">

例：按 1、2、3 入栈，合法出栈序列有 123、132、213、231、321，共 C₃=5 种；312 不合法，因为先弹出 3 后，2 仍压在 1 上面，不能直接弹出 1。

</div>

<span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="s-8"></span><span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="p-36"></span><span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="p-37"></span><span class="legacy-anchor" data-target="s-01-41aa2da47ebc" id="u-01-8bdec8ed0f78"></span>
<a id="s-01-41aa2da47ebc"></a>

### 栈

<div class="study-unit" id="u-01-c1ded955f426">

栈只允许栈顶插删，后进先出 LIFO（Last In, First Out），入栈出栈 O(1)。顺序栈先判满 / 空；链栈通常在单链表表头操作，不受固定数组容量限制，但仍受可用内存限制。

</div>

<div class="study-unit" id="u-01-e528d571b553">

| 应用 | 执行过程 | 易错处 |
| --- | --- | --- |
| 括号匹配 | 左括号入栈；右括号与栈顶匹配并弹栈；结束时检查空栈 | 右括号遇空栈、类型不匹配或最后非空均失败 |
| 中缀转后缀 | 操作数直接输出；左括号入栈；运算符弹出栈顶更高优先级者后入栈；右括号弹至左括号；最后清栈 | 左结合遇同优先级也先弹；括号不输出 |
| 后缀求值 | 操作数入栈；遇运算符先弹右操作数，再弹左操作数，计算结果入栈 | 减、除的操作数顺序不能反 |

</div>

<div class="study-unit" id="u-01-0b37d912940e">

例：(a+b)*c+d−(e+g)*h → ab+c*d+eg+h*−。递归调用用栈保存返回地址与局部状态。

</div>

<span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="s-9"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-45"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-46"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-47"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-48"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-49"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-50"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-51"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="p-52"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="u-01-6b86b273ff34"></span><span class="legacy-anchor" data-target="s-01-f5c92ad7c76d" id="u-01-4d75af40c65b"></span>
<a id="s-01-f5c92ad7c76d"></a>

### 队列

<div class="study-unit" id="u-01-f34bc7b0d703">

队列尾部入、头部出，先进先出 FIFO（First In, First Out）。普通顺序队列可能出现尾部用尽而头部仍空闲的“假溢出”，循环队列用取模复用空间。

</div>

<div class="study-unit" id="u-01-2316f1aa2c46">

**循环队列约定**：数组容量 M，front 指队头，rear 指下一入队位置，牺牲一个单元。

</div>

<div class="study-unit" id="u-01-5fbbccad472a">

| 操作 / 状态 | 规则 |
| --- | --- |
| 空 | front == rear |
| 满 | (rear+1)%M == front |
| 入队 | 先写 A[rear]，再令 rear=(rear+1)%M |
| 出队 | 先取 A[front]，再令 front=(front+1)%M |
| 元素个数 | (rear−front+M)%M；最多 M−1 |

</div>

<div class="study-unit" id="u-01-293da8d35465">

用 size 或 tag 判满空可用满 M 个位置，公式随实现改变。链队列有首尾指针时入出队 O(1)，删最后一个有效结点需同步更新 rear。双端队列两端可插删，输入 / 输出受限双端队列分别限制一端插入 / 删除。

</div>

<div class="study-unit" id="u-01-explain-de346c6b41">

例：M=5，front=3、rear=1，当前元素在下标 3、4、0，共 (1−3+5)%5=3 个。再入队一个后 rear=2，已满足 (rear+1)%5=front，队满；留出的一个空槽正是用来区分“满”和“空”。

</div>

### 矩阵

<div class="study-unit" id="u-01-df6a0d24a356">

**数组地址**：首地址 a，元素宽 L，n 行 m 列，下标从 0 开始。行优先 LOC(i,j)=a+(im+j)L；列优先 a+(jn+i)L。下标从 1 起时先减 1。

</div>

<div class="study-unit" id="u-01-f8eddfd77e76">

| 矩阵压缩（i,j 从 1 起，压缩下标 k 从 0 起） | 规则 / 数量 |
| --- | --- |
| 对称矩阵，按行存下三角 | i≥j：k=i(i−1)/2+j−1；i<j 交换 i,j；n(n+1)/2 个 |
| 三角矩阵 | 有效三角照存，另一半公共常数另占一个位置；n(n+1)/2+1 个 |
| 三对角矩阵，按行 | 有效位置满足 abs(i−j)≤1，k=2i+j−3；3n−2 个 |
| 稀疏矩阵 | 三元组记录行、列、值，通常按行、同一行按列排序；十字链表同时链接同行和同列非零元 |

</div>

<div class="study-unit" id="u-01-762c34a38897">

压缩地址为 a+kL。数组可随机存取；三元组压缩后一般不能按原坐标直接 O(1) 定位。

</div>

<div class="study-unit" id="u-01-explain-9a2094e589">

三角压缩公式中的 i(i−1)/2，数的是第 i 行前已有多少个元素，j−1 再数这一行内前面的元素。例如存下三角的 A[3,2]：前两行有 1+2=3 个，本行前面还有 1 个，所以压缩下标为 4。

</div>

## 第四章 串

<div class="study-unit" id="u-01-6341aea2521e">

串是字符的有限序列；子串必须连续，子序列不要求连续。空串长度为 0，空格串含空格字符、长度不为 0。顺序串可定长或堆分配变长，链式串可一结点存一个或多个字符；模式匹配是在主串中找模式串。

</div>

<div class="study-unit" id="u-01-8e7822a415c7">

**朴素匹配**：从候选起点依次比较；失配则主串候选起点后移一位，模式从头再比。最坏 O(nm)。

</div>

<div class="study-unit" id="u-01-f12aade81dc3">

**KMP（Knuth–Morris–Pratt 模式匹配算法）**：失配时主串 i 不回退，模式 j 按 next[j] 跳转；匹配则 i、j 同时前进。求 next O(m)，匹配 O(n)，总 O(n+m)。next 记录已匹配前缀还能复用多少。

</div>

<div class="study-unit" id="u-01-a409731f9410">

**1 起始下标约定**：next[1]=0；j=0 时 i、j 同时加 1；j>1 时 next[j] 为 P[1..j−1] 最长相等真前后缀长度加 1。P=ababaa，next 为 0,1,1,2,3,4。

</div>

<div class="study-unit" id="u-01-206828dfdd8d">

**nextval**：若 P[j]==P[next[j]]，同字符再次比较必败，令 nextval[j]=nextval[next[j]]；否则取 next[j]，nextval[1]=0。上例为 0,1,0,1,0,4。若题目用 0 起始和 −1 哨兵，按其约定计算。

</div>

<div class="study-unit" id="u-01-explain-dc8cf1977b">

next[j] 给出失配后模式串下一次比较的位置，不是主串的新起点。例：P=ababaa，在第 5 位失配时，已经匹配的 abab 有相同前后缀 ab，因此把 j 跳到 next[5]=3，复用这两个字符，主串 i 留在原处；nextval 进一步跳过必然再次失败的同字符比较。

</div>

## 第五章 树

<span class="legacy-anchor" data-target="s-01-6827de620ce0" id="s-13"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-83"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-84"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-85"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="p-86"></span><span class="legacy-anchor" data-target="s-01-6827de620ce0" id="u-01-da988fa69296"></span>
<a id="s-01-6827de620ce0"></a>

### 树和二叉树

<div class="study-unit" id="u-01-cb6d110cc8a9">

树中除根外每结点有一个双亲；结点的度是孩子数，树的度是最大结点度。**结点数 = 所有结点度数之和 + 1**，n 结点树有 n−1 条边。度 k≥1 的 n 结点树最大高度为 n−k+1。

</div>

<div class="study-unit" id="u-01-fcc5b5bcb426">

| 二叉树性质（根在第 1 层） | 结论 |
| --- | --- |
| 第 i 层最多结点数 | 2^(i−1) |
| 高 h 最多结点数 | 2^h−1 |
| 度 0、1、2 的结点数 | n₀=n₂+1 |
| 完全二叉树 | 从上到下、从左到右无缺口；n₁为 0 或 1，n 偶数时为 1 |
| 完全二叉树高 | ⌊log₂n⌋+1=⌈log₂(n+1)⌉ |
| 完全二叉树顺序编号 | i 的孩子 2i、2i+1，双亲 ⌊i/2⌋（编号存在时） |

</div>

<div class="study-unit" id="u-01-b058ade70e2a">

先序 根左右；中序 左根右；后序 左右根；层序用队列。递归遍历 O(n)，栈空间 O(h)；层序空间最坏 O(n)。结点值互异时先序+中序或后序+中序可唯一确定树，先序+后序一般不能。先 / 中 / 后序叶结点相对顺序相同，层序不适用。

</div>

<div class="study-unit" id="u-01-c546af216819">

链式二叉树 n 个结点共有 2n 个孩子指针，n−1 非空、n+1 空；顺序存储适合完全二叉树，一般二叉树可能浪费空间。

</div>

<span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="s-14"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="p-105"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="p-106"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="u-01-4b227777d4dd"></span><span class="legacy-anchor" data-target="s-01-b80a716d4abc" id="u-01-1e0182162f87"></span>

### 树和森林

<div class="study-unit" id="u-01-772f8e6d6776">

树常用双亲表示法、孩子表示法、孩子兄弟表示法。**孩子兄弟法**：左指针指第一个孩子，右指针指下一个兄弟；据此转换树、森林与二叉树。

</div>

<div class="study-unit" id="u-01-723a950778b1">

树转二叉树：保留到第一个孩子的左链接，孩子用右链接串成兄弟链。森林转换：先转换各树，再用右链接串起各根；反向转换时左链恢复孩子、右链恢复兄弟。

</div>

<div class="study-unit" id="u-01-a99039b14e16">

有序树先根遍历对应二叉树先序，后根对应中序；森林先序对应二叉树先序，森林中序对应二叉树中序。遍历需约定孩子次序，不能说树“不区分子结点顺序”。

</div>

### 线索二叉树

<div class="study-unit" id="u-01-5736f31b7c61">

线索二叉树把空孩子指针改为指向某遍历序列的前驱 / 后继。ltag=0 为左孩子，ltag=1 为前驱线索；rtag 同理。指针非空不等于它是孩子，必须看 tag。

</div>

<div class="study-unit" id="u-01-5d7113dde630">

中序找后继：rtag=1 直接取右线索；rtag=0 进入右子树再沿左孩子走到最左结点。前驱对称处理，中序遍历不需递归栈。

</div>

<div class="study-unit" id="u-01-fef5e2419023">

先序线索通常不能直接求任意结点的前驱；后序线索通常不能直接求任意结点的后继，因为可能需要双亲。线索化次序须与所求前后继次序一致。

</div>

<div class="study-unit" id="u-01-explain-79f27a92f2">

例：某结点的右指针非空，若 rtag=1，它直接指向中序后继；若 rtag=0，它只是右孩子，后继应去右子树中继续找最左结点。tag 决定这根指针是“孩子链接”还是“遍历捷径”。

</div>

### 哈夫曼树

<div class="study-unit" id="u-01-534e82bf26df">

哈夫曼树使叶结点的 **带权路径长度 WPL（Weighted Path Length）=Σwᵢlᵢ 最小**，lᵢ 是根到叶的边数。构造：每次取两个最小权根合并，父权为两者之和；把新根放回集合，重复到一棵树。

</div>

<div class="study-unit" id="u-01-628c3d0836e4">

n 叶结点产生 n−1 内部结点，共 2n−1，只含度 0 和 2。通常较大权较浅；同权选取或左右安排不同，树和编码可能不唯一，但最优 WPL 相同。

</div>

<div class="study-unit" id="u-01-e684f605d11a">

哈夫曼编码：左边 0、右边 1，根到叶的路径为编码；不存在某编码是另一编码前缀，故可即时译码。平均码长=WPL/Σwᵢ，不等于 WPL。

</div>

<div class="study-unit" id="u-01-explain-77bc0a063a">

例：权值 1、2、4，先合并 1 和 2 得 3，再合并 3 和 4 得 7；三个叶的深度为 2、2、1，WPL=1×2+2×2+4×1=10，也等于每次合并产生的父权 3+7。

</div>

## 第六章 图

<div class="study-unit" id="u-01-4bbd5545ee46">

**并查集**维护互不相交的集合，每棵双亲树表示一个集合，数组保存双亲下标；根常用负数记录集合大小，初始各为 −1。

</div>

<div class="study-unit" id="u-01-e2fce4831141">

Find 沿双亲找根，两元素根相同即在同一集合。Union 先找根，不同才合并，常把小树接到大树并更新大小；路径压缩把查找路径直接挂到根，可降低树高，用于 Kruskal 判环。

</div>

<div class="study-unit" id="u-01-explain-2f9a24e9ff">

并查集只关心“是否属于同一组”。例如已有集合 {A,B} 和 {C}，Union(B,C) 会把两棵树的根连接起来，使三者归为一组；Kruskal 选边时，若两个端点 Find 得到同一根，说明已有路径连接它们，再加该边就会成环。

</div>

<span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="s-18"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="p-131"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="p-132"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-555aa578667d"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-b520f43c6d5d"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-e67f97304956"></span><span class="legacy-anchor" data-target="s-01-a8f1e3390852" id="u-01-789cdb7f2d16"></span>
<a id="s-01-a8f1e3390852"></a>

### 图的概念

<div class="study-unit" id="u-01-8a5da0f176fb">

图 G=(V,E) 顶点集非空，边集可为空。无向边记 (u,v)，有向 u→v 的 u 为弧尾、v 为弧头。路径长度通常是边数，带权路径长度为边权和；简单路径不重复顶点，回路首尾相同。

</div>

<div class="study-unit" id="u-01-b6242ea4bca0">

| 性质 | 结论 |
| --- | --- |
| 无向度数和 | 2e |
| 有向入度和 / 出度和 | 各为 e |
| 简单无向完全图边数 | n(n−1)/2 |
| 简单有向完全图弧数 | n(n−1) |
| n 点无向连通图 | 至少 n−1 条边；边数 > (n−1)(n−2)/2 时一定连通 |
| 子图 | V′⊆V、E′⊆E，且边端点必须在 V′ 中 |

</div>

<div class="study-unit" id="u-01-d23a7fde90fe">

无向图的极大连通子图称连通分量；有向图两两双向可达的极大子图称强连通分量。“极大”是不能再扩展，不是顶点数最多。无向图连通且无环时是树；生成树包含全部顶点和 n−1 条边。

</div>

### 存储结构

<div class="study-unit" id="u-01-71286e3669a0">

| 存储 | 怎么存 / 场景 | 代价 |
| --- | --- | --- |
| 邻接矩阵 | n×n 数组记录边；无向矩阵对称，适合稠密图 | O(n²) 空间，O(1) 判边；出度看行、入度看列 |
| 邻接表 | 每顶点接邻接链，适合稀疏图 | O(n+e) 空间，无向边存两份、有向边存一份 |
| 十字链表 | 有向弧结点同时挂在弧尾出边链、弧头入边链 | 便于查入出边、删弧 |
| 邻接多重表 | 无向边只设一个结点，分别挂在两端点边链 | 便于删边，避免边的双份存储 |

</div>

<div class="study-unit" id="u-01-f9b09b56a985">

邻接表次序可不同，遍历序列可不同；给定顶点次序后，邻接矩阵固定。邻接表求某点入度通常扫描全部表 O(n+e)，不能只看它的出边链。

</div>

### 图的遍历

<div class="study-unit" id="u-01-33e5f592d1cd">

**DFS（深度优先搜索，Depth-First Search）**：访问起点→选一个未访问邻接点递归深入→无邻接点可走时回退；用递归栈或显式栈，产生深度优先生成树 / 森林。

</div>

<div class="study-unit" id="u-01-9460721ccefe">

**BFS（广度优先搜索，Breadth-First Search）**：起点标记并入队→出队一个点→将其未访问邻接点标记并入队→重复至队空。入队就标记，避免重复入队；可求无权图最少边数路径。

</div>

<div class="study-unit" id="u-01-c9ac15c36a68">

非连通图需对尚未访问点再次启动。两算法邻接矩阵 O(n²)，邻接表 O(n+e)，辅助空间最坏 O(n)。DFS 检测有向环需区分“已完成”和“当前递归路径中”；无向判环须排除返回双亲的边，不能见 visited 就判环。

</div>

<span class="legacy-anchor" data-target="s-01-f625d100ccca" id="s-22"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="p-169"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="p-170"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-3eed04ade846"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-1a72bd800758"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-2c624232cdd2"></span><span class="legacy-anchor" data-target="s-01-f625d100ccca" id="u-01-92f508c20f8c"></span>

#### 最小生成树

<div class="study-unit" id="u-01-abbe069e508e">

最小生成树 MST（Minimum Spanning Tree） 针对**带权无向连通图**，含 n 点、n−1 边且总权最小；非连通图只能求最小生成森林。

</div>

<div class="study-unit" id="u-01-29035c6700a2">

| 算法 | 执行过程 | 特点 |
| --- | --- | --- |
| Prim | 任取一点建立集合 S；选连接 S 与外部的最小权边，加入新点并更新候选边；重复到选完所有点 | 每次加一个点，朴素 O(n²)，适合稠密图 |
| Kruskal | 边按权递增排序；逐条取边，若两端分属不同集合则加入并合并，否则丢弃；选够 n−1 边结束 | 每次加一条不成环边；O(e log e)，适合稀疏图 |

</div>

<div class="study-unit" id="u-01-75cfac59893e">

所有边权互异时 MST 唯一；有相同边权仅“可能”不唯一。MST 总权最小，不保证某源点到其他点的路径最短。

</div>

#### 最短路径

<div class="study-unit" id="u-01-explain-1e5b3dca2c">

dist[v] 表示当前找到的“源点到 v 的最好距离”，w(u,v) 是 u→v 的边权；“松弛”就是发现经过 u 更短时，改小 dist[v] 并记录前驱。例：A→B 为 2、A→C 为 7、B→C 为 1，先确定 B 后把到 C 的距离从 7 改成 3，路径成为 A→B→C。Floyd 的 d[i][j] 同样表示 i 到 j 的距离，只是逐轮允许更多中间点。

</div>

<div class="study-unit" id="u-01-2e4749daa15d">

| 算法 | 执行过程 | 条件 / 复杂度 |
| --- | --- | --- |
| BFS | 源点按层扩展，首次到达层数即距离 | 无权或等权图，邻接表 O(n+e) |
| Dijkstra | dist 初始为源点直达距离；每轮确定未确定点中 dist 最小的 u，用 dist[u]+w(u,v) 松弛邻接点 | 非负权，朴素 O(n²)；负权边不能直接用 |
| Floyd | 初始矩阵为边权、主对角线 0；依次允许 k 为中间点，d[i][j]=min(d[i][j],d[i][k]+d[k][j]) | 任意两点最短路，O(n³)；可有负权边，有限最短路不能经过负权环 |

</div>

<div class="study-unit" id="u-01-a60f3b151d6a">

Dijkstra 比的是“源点→u→v”的累计距离，不是当前点最短出边。Floyd 的 k 在最外层循环。不可达记 ∞，运算时避免把 ∞ 当普通数溢出。

</div>

#### 拓扑排序

<div class="study-unit" id="u-01-7480a92e94e9">

拓扑序要求每条 u→v 的 u 在 v 前面；存在拓扑序当且仅当图为 DAG（有向无环图，Directed Acyclic Graph）。

</div>

<div class="study-unit" id="u-01-1110ae6c167c">

#### 关键路径

<div class="study-unit" id="u-01-129fd544daa6">

AOE 网（边表示活动的网，Activity On Edge）以点表示事件、带权边表示活动和时长，要求无环。**关键路径为源到汇最长耗时路径**，长度决定最短工期，可能多条。

</div>

<div class="study-unit" id="u-01-8a0e3d2bd4f0">

执行：① 拓扑序求 ve[v]=max(ve[u]+w(u,v))，源为 0；② 汇的 vl 取工期，逆拓扑序求 vl[u]=min(vl[v]−w(u,v))；③ 活动 u→v 的 e=ve[u]，l=vl[v]−w；④ e=l 的活动为关键活动，沿其连成关键路径。

</div>

<div class="study-unit" id="u-01-4d280fcf374d">

增加关键活动时长会延长工期；只缩短某一关键路径上的活动未必缩短工期，其他关键路径仍可能限制。缩短幅度较大时可能产生新关键路径，需重新计算。

</div>

<div class="study-unit" id="u-01-explain-e4c7c53928">

ve 是“事件最早能发生的时间”，vl 是“不拖延总工期时事件最迟能发生的时间”；活动的 e、l 则分别是最早、最迟开始时间。例如某活动时长 3，起点 ve=4、终点 vl=10，则 e=4、l=7，可推迟 3 个时间单位；只有 l−e=0 才是关键活动。

</div>

## 第七章 查找

<span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="s-28"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="p-199"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="p-200"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="u-01-7b597ac736e3"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="u-01-1cc9666eba4d"></span><span class="legacy-anchor" data-target="s-01-2dd94635b6d1" id="u-01-8527a891e224"></span>
<a id="s-01-2dd94635b6d1"></a>

### 线性查找

<div class="study-unit" id="u-01-05de7dffca32">

**平均查找长度 ASL（Average Search Length）=ΣpᵢCᵢ**，Cᵢ 比较次数，pᵢ 概率；等概率才是总次数除以对象数，成功与失败分别统计。

</div>

<div class="study-unit" id="u-01-a98be6531d19">

| 算法 | 执行过程 | 条件 / 结果 |
| --- | --- | --- |
| 顺序查找 | 逐个比较，哨兵可省越界判断 | 无需有序；等概率成功 ASL=(n+1)/2；失败 n 或 n+1 次，是否计哨兵看题设 |
| 折半查找 | 有序表取 mid，比较后保留可能的一半，直到命中或区间空 | 需有序和随机存取；O(log n)，链表一般不适合 |
| 分块查找 | 索引记录各块最大值和起点，先定位块再块内顺序查 | 块间有序、块内可无序；等长块、两层顺序查时 ASL=(b+1)/2+(s+1)/2，b·s=n，s≈√n 最优 |

</div>

<div class="study-unit" id="u-01-32efc773f40f">

折半成功次数为结点层数，失败次数为对应空区间双亲的层数，失败区间有 n+1 个。mid 向下取整时偶数规模左少右多，向上取整则相反。

</div>

<div class="study-unit" id="u-01-explain-3096b8b291">

计算 ASL 可以先画查找判定树：找到根上的元素比较 1 次，下一层比较 2 次，依此类推。例：[10,20,30] 折半查找先比较 20，成功查 20、10、30 分别需 1、2、2 次，等概率成功 ASL=5/3；失败则分别沿四个空区间的查找路径计数。

</div>

### 树形查找

<span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="s-30"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="p-208"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="p-209"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="u-01-a8b8bf7af058"></span><span class="legacy-anchor" data-target="s-01-d1a32948b17f" id="u-01-dc122c3f9ff5"></span>
<a id="s-01-d1a32948b17f"></a>

#### 二叉搜索树

<div class="study-unit" id="u-01-222b203af27b">

BST（二叉搜索树 / 二叉排序树，Binary Search Tree）左子树小于根、右子树大于根，各子树也满足；中序结果递增，重复值按题设。

</div>

<div class="study-unit" id="u-01-fcef4cbbf835">

查找小走左、大走右，直到相等或空。插入沿查找路径到空位置，成为新叶。删除：叶直接删；仅一子树用孩子顶替；有两子树，用中序前驱或后继替换，再删除原前驱 / 后继结点。

</div>

<div class="study-unit" id="u-01-837cf9881897">

O(h)；平衡时 O(log n)，退化为链时 O(n)，不是所有 BST 都保证对数复杂度。

</div>

<span class="legacy-anchor" data-target="s-01-659f23556a6c" id="s-31"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-214"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-215"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-216"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-217"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-218"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-219"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="p-220"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="u-01-42f563b4c80f"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="u-01-0268a12fde0e"></span><span class="legacy-anchor" data-target="s-01-659f23556a6c" id="u-01-4c08838d5a32"></span>
<a id="s-01-659f23556a6c"></a>

#### 平衡二叉树

<div class="study-unit" id="u-01-8c04631fe99d">

AVL 平衡二叉树是任意结点左右子树高度差≤1 的 BST，平衡因子通常为左高−右高。插删先按 BST 操作，再沿祖先调整；查找 O(log n)。

</div>

<div class="study-unit" id="u-01-833b33d09c10">

| 类型 | 最小失衡子树的调整 |
| --- | --- |
| LL（左—左型） | 失衡根右旋 |
| RR（右—右型） | 失衡根左旋 |
| LR（左—右型） | 先左旋左孩子，再右旋失衡根 |
| RL（右—左型） | 先右旋右孩子，再左旋失衡根 |

</div>

<div class="study-unit" id="u-01-db99f9bb8cc9">

插入通常调整最低失衡祖先即可；删除可能使更高祖先继续失衡。最少结点 N(h)=N(h−1)+N(h−2)+1，N(0)=0、N(1)=1，可反求最大高度。

</div>

<div class="study-unit" id="u-01-explain-4b3c2c19ac">

判断 LL/LR 等类型，要从最低失衡祖先看哪一侧更高，再看该侧孩子哪一侧更高。例：依次插入 3、2、1，3 的左—左侧过高，对 3 右旋后变成 2 为根、1 和 3 为左右孩子；旋转只改局部链接，仍保持中序递增。

</div>

<span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="s-32"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="p-224"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="u-01-6087e3abbf7d"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="u-01-a6e9e8c7eda6"></span><span class="legacy-anchor" data-target="s-01-4c390d9c1380" id="u-01-c8a575353396"></span>
<a id="s-01-4c390d9c1380"></a>

#### 红黑树

<div class="study-unit" id="u-01-78fb81f6e71f">

红黑树是带颜色约束的 BST：根与 NIL（空叶结点）均为黑色；红点的孩子都黑；任一点到各 NIL 叶路径上的黑点数相同；每点红或黑。NIL 叶不是数据结点。

</div>

<div class="study-unit" id="u-01-ff0399e975bf">

最长路径≤最短路径两倍；n 内部点高度≤2log₂(n+1)，查找插删 O(log n)，不要求每个点左右高度差≤1。

</div>

<div class="study-unit" id="u-01-61e1b15d3641">

插入先按 BST 并染红；父黑结束；父红时，叔红则父叔染黑、祖父染红向上处理；叔黑则旋转变色消除连续红，最后根染黑。删除若减少黑高需调整，不能按普通 BST 删除后直接结束。

</div>

<div class="study-unit" id="u-01-explain-3202d714ee">

插入调整中，“叔”是父结点的兄弟，空叔按黑色算。父红、叔黑时，若新结点—父—祖父呈折线，先旋转父转成直线；再旋转祖父，把新子树根染黑、原祖父染红。父红、叔红则父和叔先染黑、祖父染红，再把祖父当作新的检查点向上处理，最后保证整树根黑。

</div>

<span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="s-33"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="p-225"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="p-226"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="u-01-1d3fefe39b7b"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="u-01-0983c05a4f4f"></span><span class="legacy-anchor" data-target="s-01-525cdc72d72d" id="u-01-2ad2d45364e8"></span>
<a id="s-01-525cdc72d72d"></a>

#### B树

<div class="study-unit" id="u-01-e629fa6598d7">

m 阶 B 树是多路平衡搜索树，所有叶同层；非空结点的关键字升序，k 个孩子对应 k−1 个关键字，孩子划分关键字范围。

</div>

<div class="study-unit" id="u-01-03e487830c88">

每结点至多 m 个孩子、m−1 个关键字；非根内部结点至少 ⌈m/2⌉ 个孩子、⌈m/2⌉−1 个关键字；非叶根至少 2 个孩子。教材“叶”常指不含关键字的外部失败结点，先统一高度约定。

</div>

<div class="study-unit" id="u-01-65d5badb924f">

查找先结点内比较，再进对应孩子。插入在最底层非空结点，溢出则分裂、中央关键字上移，双亲也溢出则继续。删除内部关键字可换前驱 / 后继后再删；不足则向有余量兄弟借并改双亲，否则与兄弟及双亲分隔关键字合并，可能向上继续。磁盘访问次数取决于树高。

</div>

<div class="study-unit" id="u-01-08c624a7a522">

高度 h 只计含关键字层、m≥3，q=⌈m/2⌉，n 个关键字满足 2q^(h−1)−1≤n≤m^h−1；据此求最小 / 最大高度，外部失败叶不计入 h。

</div>

<div class="study-unit" id="u-01-explain-1bc8fba62b">

“m 阶”限制的是最大孩子数。例：3 阶 B 树一个结点最多有 2 个关键字；若插入后某结点暂为 [10,20,30]，把中央 20 上移，左右留下 [10]、[30]。若它原本就是根，就建立以 20 为关键字的新根，树高增加一层。

</div>

<div class="study-unit" id="u-01-explain-a6992e4e68">

向兄弟“借”关键字要经过双亲：把双亲中分隔这两棵子树的关键字下放到不足结点，再用兄弟的边界关键字补回双亲；非叶还要迁移相应孩子。兄弟也没有余量时，才把两结点和双亲分隔关键字合并，双亲因此可能继续不足。

</div>

<div class="study-unit" id="u-01-c8271ff7c502">

#### B+树

<div class="study-unit" id="u-01-b17ef6d19c7a">

B+ 树的记录全在叶层，叶通常按关键字链接；非叶仅作索引，查记录必须到叶。适合范围查询与顺序扫描。

</div>

<div class="study-unit" id="u-01-4df0044533a5">

408 常用 m 阶约定中每结点最多 m 个关键字 / 非叶孩子；除根外关键字至少 ⌈m/2⌉ 个，非叶根至少 2 个孩子、根叶可更少。非叶有 k 孩子时有 k 索引关键字（B 树是 k−1），常取孩子子树最大关键字；采用其他阶数定义时按题设。上层索引会在叶层重复，分裂上移是索引副本，不删掉叶层记录。

</div>

<div class="study-unit" id="u-01-f12783b94a0b">

相比 B 树，扇出通常更大、层数较少，范围检索方便，单点路径较稳定；不能在非叶发现相同索引就结束记录查找。

</div>

<div class="study-unit" id="u-01-explain-4c4a4dd341">

范围查询 [20,50] 时，先沿索引找到 20 应在的叶结点，再沿叶层链接读取后续记录，直到超过 50。上层只帮你定位入口，所以即使在上层看到关键字 20，仍要到叶层取得记录。

</div>

### 散列查找

<div class="study-unit" id="u-01-463a5a66fde0">

散列表用 H(key) 定位。**α=记录数/表长**，越大通常冲突越多；不同关键字得到相同地址称冲突，同义词不等于重复关键字。

</div>

<div class="study-unit" id="u-01-d2f7ecf66f4c">

| 处理 | 执行 / 考点 |
| --- | --- |
| 线性探测 | H、H+1、H+2…取模，可能聚集；直到命中或从未用过的空槽 |
| 平方探测 / 双散列 | 按题设增量探测；是否覆盖全表依参数，不能假定必访每槽 |
| 拉链 | 同散列地址记录放同一链表，插删方便，需额外指针 |

</div>

<div class="study-unit" id="u-01-5601658f9b6c">

除留余数 H(key)=key mod p，p 常取不超过表长的合适素数。开放定址删除留“已删除”标志，直接置空可能截断查找链。

</div>

<div class="study-unit" id="u-01-0716167bb9a1">

成功 ASL：从每个关键字初始地址模拟到命中求平均。失败 ASL：从各可能初始地址探测到真空槽，计入空槽检查，按初始地址概率平均；分母是初始散列地址的可能取值数，不一定为表长。

</div>

<div class="study-unit" id="u-01-explain-8b58001d05">

例：表长 7，H(k)=k mod 7，插入 10、17 时，10 放在槽 3，17 冲突后放槽 4。查 17 要检查槽 3、4，共 2 次；若删除 10，槽 3 应留“已删除”标志，否则查 17 会在槽 3 误判失败。

</div>

## 第八章 排序

<span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="s-37"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-244"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-245"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-246"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-247"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-248"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-249"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-250"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-251"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-252"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-253"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-254"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-255"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="p-256"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="u-01-9abbc11240d1"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="u-01-4f377c8778ad"></span><span class="legacy-anchor" data-target="s-01-e2d3b81989aa" id="u-01-b48ba6821b46"></span>
<a id="s-01-e2d3b81989aa"></a>

### 内部排序

<div class="study-unit" id="u-01-56815e3f714d">

稳定排序保持相等关键字记录的原相对顺序；“一趟确定最终位置”不同于“局部有序”。

</div>

<div class="study-unit" id="u-01-25b480c8fe30">

| 算法 | 一趟怎么执行 | 时间：最好 / 平均 / 最坏 | 辅助空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 直接插入 | 下一元素插入有序前缀，比它大者后移 | n / n² / n² | O(1) | 是 |
| 折半插入 | 折半找插入点，再移动元素；相等插在已有相等者后 | 比较 O(n log n)，移动最坏 O(n²) | O(1) | 是 |
| 希尔 | 按增量分组插排，逐步减小增量至 1 | 依增量序列，不固定为 n^1.3 | O(1) | 否 |
| 冒泡 | 邻接逆序交换，一趟极值归位，无交换提前结束 | n / n² / n² | O(1) | 是 |
| 快排 | 枢轴划分两侧，递归子区间 | n log n / n log n / n² | 栈平均 O(log n)、最坏 O(n) | 否 |
| 选择 | 未排序区选最小，与该区首位交换 | n² / n² / n² | O(1) | 否 |
| 堆 | 升序大根堆，堆顶与末项换，缩小堆、向下调整 | n log n / n log n / n log n | O(1) | 否 |
| 二路归并 | 两有序段用双指针取较小者，合并为新段 | n log n / n log n / n log n | O(n) | 是 |
| 基数 LSD（最低位优先，Least Significant Digit） | 从低位到高位，按桶稳定分配、收集 | O(d(n+r))，d 位数、r 基数 | 链式桶常 O(r)，数组可 O(n+r) | 是 |

</div>

<div class="study-unit" id="u-01-efb2703d2ba9">

表内 n 等简写表示 O(·)。堆是完全二叉树，升序用大根堆，父≥孩子；自最后非叶向上建堆 O(n)，逐个插入建堆通常 O(n log n)。

</div>

<div class="study-unit" id="u-01-16e8b2d816f3">

冒泡、选择、堆一趟至少固定一元素；常用枢轴归位快排固定枢轴。插入只保证前缀有序，归并只保证段内有序，不表示最终位置。

</div>

<div class="study-unit" id="u-01-1a3ba63dc705">

插入、提前终止冒泡已有序时最好；快排关键看划分是否均衡，首 / 尾枢轴遇有序才易最坏，不是所有快排有序就最坏。比较排序最坏下界 Ω(n log n)，基数不属于比较排序。

</div>

<div class="study-unit" id="u-01-explain-ba0a77104d">

“稳定”看相同关键字的记录是否换了先后：2甲、1、2乙 排序后若为 1、2甲、2乙 就保持稳定。快排的一趟是围绕枢轴划分左右区间，不是把整个区间排好；归并的一趟则把若干有序小段合成更大的有序段。

</div>

<span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="s-38"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-270"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-271"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-272"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-273"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-286"></span><span class="legacy-anchor" data-target="s-01-b63777b18aa0" id="p-287"></span>
<a id="s-01-b63777b18aa0"></a>

### 外部排序

<div class="study-unit" id="u-01-1cca7812c604">

外部排序用于数据大于内存，重点减少磁盘 I/O：① 分批读入、内排序形成初始段；② 多路归并逐趟合并至一段。

</div>

<div class="study-unit" id="u-01-a25c82a2d3dd">

r 个初始段，k 路归并趟数约 ⌈logₖr⌉；每趟通常读、写全体记录。增大 k 可减趟数，但需 k 输入缓冲及输出缓冲；败者树选最小段头，更新 O(log k)。

</div>

<div class="study-unit" id="u-01-2122da15da93">

置换选择：维护工作区，输出可参加本段的最小记录；新读记录小于刚输出关键字则冻结到下一段；全冻结时结束本段并解冻。初始段平均可长于工作区，不保证总是恰两倍。

</div>

<div class="study-unit" id="u-01-cb615efae309">

最佳归并树：不同长度段用 k 叉哈夫曼树减少加权读写量；(r−1) mod (k−1)≠0 时补权 0 虚段。

</div>

<div class="study-unit" id="u-01-explain-4c1b0f7de5">

例：8 个初始有序段做二路归并，段数依次 8→4→2→1，共 3 趟；四路归并则 8→2→1，共 2 趟。败者树只维护每个输入段当前最小的“段头”，输出一个段头后，仅更新该段的新段头。

</div>

# 数据结构

<span class="content-anchor" id="p-1"></span>按“核心结论、适用条件、易错点”复习；复杂度默认指常见实现，题目指定存储结构或操作条件时，以题设为准。

<a id="s-2"></a>
## 第一章 绪论

<span class="content-anchor" id="p-2"></span>逻辑结构包括集合、线性、树形和图结构；存储结构包括顺序、链式、索引和散列。算法应有有穷性、确定性、可行性、输入和输出，评价时关注正确性、可读性、健壮性及效率。

<span class="content-anchor" id="p-3"></span>时间复杂度看基本操作次数的增长阶，忽略常数和低阶项；并列程序段相加，嵌套循环按实际执行次数求和，不能一律把循环上界相乘。常见量级：$1<\log n<n<n\log n<n^2<2^n<n!$。

<span class="content-anchor" id="p-4"></span>

~~~c
for (int i = 1; i <= n; i *= 2) { /* 对数级，忽略整数溢出 */ }
for (int i = 0; i < n; ++i)
    for (int j = 0; j < i; ++j) { /* n(n-1)/2 次，平方级 */ }
~~~

<span class="content-anchor" id="p-5"></span>最坏、平均和最好复杂度是不同指标；平均复杂度需要概率假设。辅助空间不计输入本身，递归要计最大同时存活的调用栈；普通递归 Fibonacci 时间为指数级，栈深度为 $O(n)$。

## 第二章 线性表

<span class="content-anchor" id="p-16"></span>线性表的元素在逻辑上存在唯一前驱和后继（首尾除外），逻辑相邻不等于物理地址相邻。

<a id="s-4"></a>
### 顺序表

<span class="content-anchor" id="p-17"></span>按序号访问 $O(1)$，按值顺序查找 $O(n)$；有序且支持随机访问时，折半查找才是 $O(\log n)$。插入、删除的瓶颈通常是移动元素。

<span class="content-anchor" id="p-18"></span>采用序号 $1\ldots n$：在第 $i$ 个位置插入移动 $n-i+1$ 个元素，删除第 $i$ 个移动 $n-i$ 个。插入位置在 $1\ldots n+1$ 上等概率时，平均移动 $n/2$ 个；等概率删除时为 $(n-1)/2$ 个。尾部插入在容量足够时为 $O(1)$，动态扩容另计。

### 链表

<span class="content-anchor" id="p-22"></span>查找第 $i$ 个结点或按值查找通常为 $O(n)$；已知正确前驱或双向结点时，局部插入、删除为 $O(1)$，不能漏掉定位成本。带头结点和不带头结点的边界处理不同。

|<span class="content-anchor" id="p-23"></span> 操作与条件 | 单链表 | 双链表 |
| --- | --- | --- |

## 第三章 栈、队列和矩阵

<a id="s-7"></a>
### 卡特兰数

<span class="content-anchor" id="p-35"></span>$C_n=\dfrac{1}{n+1}\binom{2n}{n}$。固定 $n$ 个不同元素的入栈顺序，其合法出栈排列数为 $C_n$；含 $n$ 个结点的二叉树形态数也为 $C_n$。形态数与任意标号后的树数不同。

<a id="s-8"></a>
### 栈

<span class="content-anchor" id="p-36"></span>栈后进先出，只在栈顶操作，适用于递归、括号匹配、表达式求值和 DFS。

<span class="content-anchor" id="p-37"></span>中缀转后缀：操作数直接输出；左括号入栈；右括号弹出至左括号并丢弃括号；遇运算符先弹出优先级更高的栈顶运算符，当前运算符左结合时还要弹出同优先级运算符，再将它入栈；结束后弹出剩余运算符。后缀求值时，先弹出的数是右操作数。

### 队列

<span class="content-anchor" id="p-45"></span>队列先进先出。循环队列须先确认指针约定；下面采用 front 指向队头、rear 指向下一入队位置，数组长 $M$，牺牲一个单元。

|<span class="content-anchor" id="p-46"></span> 判断或操作 | 公式 |
| --- | --- |
|<span class="content-anchor" id="p-47"></span> 空 | $front=rear$ |
|<span class="content-anchor" id="p-48"></span> 满 | $(rear+1)\bmod M=front$ |
|<span class="content-anchor" id="p-49"></span> 元素数 | $(rear-front+M)\bmod M$ |
|<span class="content-anchor" id="p-50"></span> 入队后 | $rear=(rear+1)\bmod M$ |
|<span class="content-anchor" id="p-51"></span> 出队后 | $front=(front+1)\bmod M$ |

<span class="content-anchor" id="p-52"></span>可用容量为 $M-1$；另设计数器或标志位时公式会变。链队列删除最后一个元素后，要同步修正尾指针。

### 矩阵

<span class="content-anchor" id="p-62"></span>二维数组行优先偏移：$((i-i_0)N+(j-j_0))L$，$N$ 为列数，$L$ 为元素字节数，$i_0,j_0$ 为下标起点；列优先互换行列角色。

<span class="content-anchor" id="p-63"></span>矩阵从 1、压缩数组从 0 编号：对称矩阵只存下三角时，$i\ge j$ 的下标 $k=i(i-1)/2+j-1$，上三角先交换 $i,j$。下三角矩阵非零部分同式，上三角常数另存；上三角按行存储时 $k=(i-1)(2n-i+2)/2+j-i$。

<span class="content-anchor" id="p-64"></span>三对角矩阵按行压缩时 $k=2i+j-3$，前提 $|i-j|\le1$；共存 $3n-2$ 个元素（$n\ge2$）。稀疏矩阵三元组保存行、列和值，十字链表支持沿行列访问；三元组排序和下标起点按题设。

## 第四章 串

<span class="content-anchor" id="p-74"></span>串是字符序列，空串长度为 0，空格串不是空串。朴素匹配最坏 $O(nm)$；KMP 用模式串前后缀关系避免主串回退，预处理与匹配共 $O(n+m)$。

<span class="content-anchor" id="p-75"></span>求 next 先统一下标。模式串从 1 开始、next[1]=0 的教材版本中，next[j] 由 $P[1\ldots j-1]$ 的最长相等真前缀、真后缀长度 $k$ 决定，通常为 $k+1$；无匹配时为 1。失配只回退模式串指针，跳到 0 后两指针一起前进。

<span class="content-anchor" id="p-76"></span>nextval 跳过回退后仍拿同一字符比较的位置：若 $P[j]=P[next[j]]$，令 nextval[j]=nextval[next[j]]，否则保留 next[j]。从 0 开始、首项为 -1 或使用前缀函数的版本也正确，数值不能混用。例如模式串 abaabc 在上述 1 起始约定下，next 为 0、1、1、2、2、3。

## 第五章 树

<a id="s-13"></a>
### 树和二叉树

<span class="content-anchor" id="p-83"></span>非空树 $n$ 个结点有 $n-1$ 条边。二叉树区分左右子树，度最多为 2；非空二叉树恒有 $n_0=n_2+1$，可由总结点数和总边数推得。

<span class="content-anchor" id="p-84"></span>根为第 1 层、树高为层数时，第 $i$ 层最多 $2^{i-1}$ 个结点，高 $h$ 时最多 $2^h-1$ 个。完全二叉树含 $n$ 个结点时高为 $\lfloor\log_2 n\rfloor+1$；满二叉树层层填满，完全二叉树最后一层从左连续。

<span class="content-anchor" id="p-85"></span>完全二叉树从 1 编号：父结点 $\lfloor i/2\rfloor$，左孩子 $2i$，右孩子 $2i+1$，超过 $n$ 则不存在；从 0 编号公式改变。

<span class="content-anchor" id="p-86"></span>先序“根左右”、中序“左根右”、后序“左右根”，层序用队列。标识互异时，“中序＋先序”或“中序＋后序”唯一确定二叉树；仅先序和后序通常不能。固定左右顺序的三种深度优先遍历保持叶子相对次序，层序不一定。

|<span class="content-anchor" id="p-246"></span> 直接插入 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
|<span class="content-anchor" id="p-247"></span> 折半插入 | $O(n\log n)$ 比较 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |

<span class="content-anchor" id="p-255"></span>折半插入只减少比较，移动仍可能平方级；希尔不能无条件记作 $O(n^{1.3})$。快速排序一趟只保证枢轴归位和两侧分区；有序输入是否最坏取决于枢轴选择。建堆 $O(n)$，完整堆排序上界 $O(n\log n)$，比较次数并非所有输入都固定。

<span class="content-anchor" id="p-256"></span>基数排序 $d$ 为位数、$r$ 为基数，每趟须稳定；链式桶可只额外使用 $O(r)$ 个队列指针，原记录结点仍占空间。只求前 $k$ 个最小值可用大小为 $k$ 的堆。基于比较的一般排序最坏需要 $\Omega(n\log n)$ 次比较，计数/基数排序利用额外键值结构，因此不受同一比较模型下界约束。

<a id="s-38"></a>
### 外部排序

<span class="content-anchor" id="p-270"></span>数据放不进内存时，先生成有序初始段，再多路归并，主要成本为外存读写。初始 $r$ 段，每轮最多 $k$ 路，理想均衡归并趟数 $\lceil\log_k r\rceil$。

<span class="content-anchor" id="p-271"></span>共有 $N$ 个数据块，忽略缓存和最后输出优化时，初始段生成约 $2N$ 次块 I/O，每趟归并再约 $2N$ 次。增大归并路数需留出每路输入及输出缓冲；比较成本与磁盘 I/O 分开算。

<span class="content-anchor" id="p-272"></span>败者树保存锦标赛中的败者，更换当前归并元素后沿路径调整，单次选取约 $O(\log k)$。置换选择生成变长初始段；随机输入常见期望段长约为工作区记录数的两倍，不是任意输入都如此。

<span class="content-anchor" id="p-273"></span>初始段长度不等时，用 $k$ 叉 Huffman 思想优先合并短段；必要时补长度为 0 的虚段，使 $(r-1)\bmod(k-1)=0$，再算读写量。

# 计算机组成原理

<span class="content-anchor" id="p-1"></span>计算题先确认字长、编址单位和硬件时序；下文区分通用结论与 408 常用简化模型。

<a id="s-2"></a>
## 第一章 计算机系统概述

<a id="s-3"></a>
### 冯诺依曼机的特点

<span class="content-anchor" id="p-2"></span>存储程序：指令与数据存入存储器，通常以二进制表示；基本部件为运算器、控制器、存储器、输入和输出设备。现代结构可用分离的指令与数据 Cache，并不因此取消存储程序思想。

<span class="content-anchor" id="p-3"></span>ISA 规定程序可见的指令、寄存器、数据类型和寻址行为；Cache、流水线级数等属于具体微体系结构。同一 ISA 可有不同实现。

<a id="s-4"></a>
### 三种翻译程序

<span class="content-anchor" id="p-4"></span>编译器把源程序转换为目标程序，汇编器把汇编代码转换为机器代码，解释器在运行时解释执行程序或中间表示。解释执行不必等同于“每条源语句现场翻译成一条机器指令”；汇编伪指令也可能展开成多条指令。

<a id="s-5"></a>
### 三种常见字长

<span class="content-anchor" id="p-5"></span>机器字长是 CPU 自然处理的数据位数；指令字长是指令编码位数；存储字长是一次存储字的数据位数。三者不必相等，机器字长也不必等于总线宽度。

<span class="content-anchor" id="p-6"></span>按字节编址只说明相邻地址对应 1 B，不代表存储字长为 8 bit。地址空间容量＝可寻址单元数 × 每单元字节数；MAR、MDR 位数分别结合地址和数据组织判断。

<a id="s-6"></a>
### 计算机性能指标

<span class="content-anchor" id="p-7"></span>$T_{\mathrm{CPU}}=IC\times CPI\times T_{\mathrm{clock}}=IC\times CPI/f$，平均 CPI 按各类指令动态执行比例加权。MIPS＝$f/(CPI\times10^6)$，不能脱离指令集和程序比较；MFLOPS 是每秒百万次浮点运算。

<span class="content-anchor" id="p-8"></span>主频更高不保证程序更快，指令数、CPI、访存与 I/O 都可能改变。性能加速比＝旧时间/新时间；比例 $p$ 的部分加速 $s$ 倍，总加速比为 $1/((1-p)+p/s)$。

<a id="s-7"></a>
## 第二章 数据的表示和运算

<a id="s-8"></a>
### 定点数的机器数转换

<span class="content-anchor" id="p-9"></span>原码＝符号位＋绝对值；负数反码为原码数值位取反；负数补码为反码加 1；正数三者相同。补码取负可全位取反加 1，但最小负数的相反数超出同字长有符号范围。

<span class="content-anchor" id="p-10"></span>移码常用“真值加偏置”；偏置为 $2^{n-1}$ 时，$n$ 位移码与补码只差最高位。IEEE 阶码偏置是 127 或 1023，不能直接套这个特殊关系。

<a id="s-9"></a>
### 定点数的表示范围

|<span class="content-anchor" id="p-11"></span> 编码 | $n$ 位整数（含符号位） | $n+1$ 位纯小数（1 位符号、$n$ 位小数） |
| --- | --- | --- |
|<span class="content-anchor" id="p-12"></span> 无符号 | $0\sim2^n-1$ | 无符号 $n$ 位小数为 $0\sim1-2^{-n}$ |
|<span class="content-anchor" id="p-13"></span> 原码、反码 | $-(2^{n-1}-1)\sim2^{n-1}-1$ | $-(1-2^{-n})\sim1-2^{-n}$ |
|<span class="content-anchor" id="p-14"></span> 补码 | $-2^{n-1}\sim2^{n-1}-1$ | $-1\sim1-2^{-n}$ |

<span class="content-anchor" id="p-15"></span>原码和反码各有两个零，补码只有一个零。补码全 1 对整数是 -1，对 $n$ 位小数是 $-2^{-n}$，必须看二进制小数点的位置。

<a id="s-10"></a>
### 定点数的格式转换

<span class="content-anchor" id="p-16"></span>同位宽有符号、无符号解释可共享机器位；扩宽时看源类型，负有符号数符号扩展，无符号数零扩展。截断通常保留低位，再按目标类型解释；C 的窄有符号转换结果可能由实现规定，机器数题按明确题设。

<span class="content-anchor" id="p-17"></span>C 表达式先考虑整数提升，再考虑通常算术转换。例如 32 位 int 能容纳 unsigned short 全部值时，后者也先提升为 int。

<a id="s-11"></a>
### 定点数的加减法

<span class="content-anchor" id="p-18"></span>补码加法在固定位宽下按模 $2^n$ 运算，丢弃最高位外的进位；减法 $A-B=A+\overline B+1$。相同电路可执行有符号或无符号运算，是否溢出取决于解释方式。

<span class="content-anchor" id="p-19"></span>串行进位逐级传播，先行进位提前计算进位以缩短延迟；一位全加器 $S=A\oplus B\oplus C_{in}$，$C_{out}=AB+(A\oplus B)C_{in}$，这里乘积表示逻辑与、加号表示逻辑或；位数、延迟和标志位按题目电路计算。

<a id="s-12"></a>
### 定点数的溢出判断

<span class="content-anchor" id="p-20"></span>有符号加法同号相加得异号才溢出；减法异号相减且结果符号不同于被减数才溢出。OF 可由符号位的输入、输出进位异或判断；无符号加法 CF 为最高位进位，减法借位标志极性依 ISA 或题设。

<span class="content-anchor" id="p-21"></span>SF 是结果最高位；有溢出时，SF 不代表真实数学结果的正负。ZF 表示机器结果是否全零。

<a id="s-13"></a>
#### 双符号位溢出判断

<span class="content-anchor" id="p-22"></span>双符号位结果 00 为正常正数、11 为正常负数；01 为正溢出、10 为负溢出。额外符号位用于运算判溢出，不代表存储中的每个数都必须占两位符号。

<a id="s-14"></a>
### 定点数的移位乘除法

<span class="content-anchor" id="p-23"></span>逻辑移位移出位丢弃，空位补 0；补码算术右移高位补符号位，负奇数通常向负无穷取整。左移若丢失有效符号信息会溢出，不能无条件认为乘 2 后仍正确。

<span class="content-anchor" id="p-24"></span>两个 $n$ 位整数的完整乘积可用 $2n$ 位容纳；截成 $n$ 位时，无符号要求高半全零，有符号要求高半是低半符号位的扩展。典型 Booth 一位乘法根据相邻乘数位加、减或不操作，组合寄存器算术右移；典型恢复余数除法组合左移、试减，失败再恢复，步骤依算法约定。

<a id="s-15"></a>
### 一般浮点数

<span class="content-anchor" id="p-25"></span>浮点数写成 $(-1)^s M2^E$；阶码决定范围，尾数有效位决定精度。规格化形式及阶码、尾数编码由题设决定，不能把所有浮点格式都按 IEEE 754 解读。

<a id="s-16"></a>
### IEEE754浮点数

|<span class="content-anchor" id="p-26"></span> 格式 | 符号 | 阶码 | 尾数字段 | 偏置 | 正规数有效精度 |
| --- | --- | --- | --- | --- | --- |
|<span class="content-anchor" id="p-27"></span> 单精度 | 1 | 8 | 23 | 127 | 24 位 |
|<span class="content-anchor" id="p-28"></span> 双精度 | 1 | 11 | 52 | 1023 | 53 位 |

<span class="content-anchor" id="p-29"></span>正规数 $(-1)^s(1.f)2^{e-bias}$；阶码全 0 时用 $(-1)^s(0.f)2^{1-bias}$，包括零和非正规数；阶码全 1、尾数全 0 为无穷，尾数非零为 NaN。

<a id="s-17"></a>
### 浮点数的表示范围

<span class="content-anchor" id="p-30"></span>单精度最小正正规数 $2^{-126}$，最小正非正规数 $2^{-149}$，最大有限数 $(2-2^{-23})2^{127}$；双精度对应 $2^{-1022}$、$2^{-1074}$、$(2-2^{-52})2^{1023}$。正负零都存在；范围与相邻可表示数的间距不同。

<a id="s-18"></a>
### 浮点数的精度问题

<span class="content-anchor" id="p-31"></span>单精度能精确表示所有绝对值不超过 $2^{24}$ 的整数，双精度界为 $2^{53}$；更大的整数仍可能精确表示，例如 $2^{25}$。单精度不能精确表示 $2^{24}+1$，双精度能精确表示所有 32 位 int。

<span class="content-anchor" id="p-32"></span>多数十进制小数在二进制中无限循环。阶差很大时，小操作数可能在舍入中被吸收，但需结合尾数、保护位和舍入方式，不能只按一个固定阶差判断。

<a id="s-19"></a>
### 浮点数的加减法

<span class="content-anchor" id="p-33"></span>对阶（小阶向大阶靠拢）→尾数加减→规格化→舍入→检查结果。对阶右移丢失的位可能影响舍入；尾数溢出可能右规，抵消后可能多次左规。默认常见舍入为最接近、遇中点取偶数，题设可指定其他方式。

<a id="s-20"></a>
### 浮点数的溢出判断

<span class="content-anchor" id="p-34"></span>IEEE 754 支持渐进下溢：很小的结果可成为非正规数，继续变小才可能舍入到零；溢出结果依舍入方式可能为无穷或最大有限数。浮点异常可设状态标志，是否产生陷阱取决于配置，不能说必然触发操作系统中断。

<a id="s-21"></a>
### 大小端存储

<span class="content-anchor" id="p-35"></span>大端把最高有效字节放低地址，小端把最低有效字节放低地址。两者改变多字节对象的字节顺序，不改变一个字节内部的位序；先按地址从低到高列出各字节再还原数值。

<a id="s-22"></a>
### 边界对齐

<span class="content-anchor" id="p-36"></span>自然对齐通常要求对象首地址是其对齐单位的倍数，结构体可能有内部和尾部填充。实际规则依 ISA、ABI 和题设；不能从对象大小直接推断任何平台都必须按同样边界对齐。

<a id="s-23"></a>
## 第三章 存储系统

<a id="s-24"></a>
### 存储器分类

<a id="s-25"></a>
#### 三级存储系统

<span class="content-anchor" id="p-37"></span>Cache、主存、外存逐层容量增大、平均访问变慢；利用时间局部性和空间局部性取得接近较快层的访问速度。寄存器位于更靠近 CPU 的层次。

<a id="s-26"></a>
#### 按存储介质分类

<span class="content-anchor" id="p-38"></span>半导体、磁性介质和光学介质；易失性描述断电后是否保留数据，与是否允许随机访问是不同维度。

<a id="s-27"></a>
#### 按存取方式分类

<span class="content-anchor" id="p-39"></span>RAM 支持按地址随机访问；磁盘属于直接访问（先定位再访问）；磁带是顺序访问；相联存储按内容匹配。ROM 的“只读”与随机访问并不矛盾。

<a id="s-28"></a>
### 存储器性能指标

<span class="content-anchor" id="p-40"></span>容量＝字数×字长；存取时间是一次读写的延迟，存储周期是允许连续两次操作的最小间隔，可能大于存取时间；带宽是单位时间可传输的数据量。

<a id="s-29"></a>
### 随机存储器 SRAM/DRAM

<a id="s-30"></a>
#### 静态随机存储器 SRAM

<span class="content-anchor" id="p-41"></span>典型 SRAM 用双稳态电路存位，不需刷新，但断电丢失；速度快、集成度较低，常用于 Cache。

<a id="s-31"></a>
#### 动态随机存储器 DRAM

<span class="content-anchor" id="p-42"></span>典型 DRAM 用电容存位，需刷新，读出后需恢复，常用于主存。刷新通常按行组织；刷新所有行的保持时限与刷新单行时间不同。

<span class="content-anchor" id="p-43"></span>集中刷新会造成连续暂停；分散刷新将开销插入各周期；异步刷新分散到保持时限内。分散方式没有长暂停，不代表刷新不占时间。

<a id="s-32"></a>
#### SRAM和DRAM对比

<span class="content-anchor" id="p-44"></span>SRAM 快、成本高、密度低、无刷新；DRAM 密度高、成本低、需刷新。双译码把地址分为行、列；若行列分时复用引脚，地址引脚数为 $\max(r,c)$，可寻址单元数为 $2^{r+c}$。

<a id="s-33"></a>
### 存储芯片的扩展

<span class="content-anchor" id="p-45"></span>位扩展增加每个地址的数据宽度，字扩展增加地址单元数；总芯片数＝位扩展倍数×字扩展倍数。低位地址送芯片，高位用于片选；最后检查地址区间、编址单位和端点是否包含。

<a id="s-34"></a>
### 多模块存储器

<span class="content-anchor" id="p-46"></span>高位交叉把连续地址放同一模块较长区间，低位交叉把连续地址分散到不同模块。模块恢复周期 $T$、发起间隔 $t$ 时，理想无冲突需要模块数 $m\ge\lceil T/t\rceil$。

<span class="content-anchor" id="p-47"></span>连续 $n$ 次访问，在“首个访问完成需 $T$，之后每隔 $t$ 完成一个”的理想模型中，总时间为 $T+(n-1)t$；若题设另计总线传输，按给定时间线计算。

<a id="s-35"></a>
### 只读存储器 ROM

<span class="content-anchor" id="p-48"></span>掩膜 ROM 出厂固化；PROM 可一次编程；EPROM 用紫外线擦除；EEPROM 电擦除重写。具体擦除粒度、访问延迟依器件，不能把所有 ROM 都当不可修改。

<a id="s-36"></a>
### 闪存 Flash

<span class="content-anchor" id="p-49"></span>Flash 非易失，通常按页读写、按块擦除，覆盖旧数据前涉及擦除或另写新页；因此 SSD 控制器要做地址映射、垃圾回收和磨损均衡。

<a id="s-37"></a>
### 机械硬盘 HDD

<a id="s-38"></a>
#### 磁盘物理结构

<span class="content-anchor" id="p-50"></span>盘面由磁道和扇区组成，同半径磁道构成柱面。题目可给固定每道扇区数；真实硬盘组织不必遵循这个简化模型。

<a id="s-39"></a>
#### 磁盘地址结构

<span class="content-anchor" id="p-51"></span>传统 CHS 地址包含柱面、磁头和扇区；现代常用 LBA 逻辑块地址。容量按盘面数×每面磁道数×每道扇区数×扇区字节数计算，注意是否有保留区域。

<a id="s-40"></a>
#### 性能指标

<span class="content-anchor" id="p-52"></span>访问时间＝寻道＋旋转等待＋传输。转速 $r$ 转/分，均匀随机位置下平均旋转等待为 $30/r$ 秒；传输时间另按数据量和传输率计算。

<a id="s-41"></a>
#### 独立磁盘冗余阵列 RAID

<span class="content-anchor" id="p-53"></span>RAID 0 条带化、无冗余；RAID 1 镜像；RAID 5 分布式单校验，可容忍一个盘失效；RAID 6 双校验，可容忍两个盘失效。等容量 $n$ 盘的 RAID 5、6 可用容量约为 $(n-1)C$、$(n-2)C$，阵列冗余不替代备份。

<a id="s-42"></a>
### 固态硬盘 SSD

<a id="s-43"></a>
#### 固态内部结构

<span class="content-anchor" id="p-54"></span>闪存页组成擦除块，FTL 把逻辑地址映射到物理页；随机访问没有机械寻道，但延迟仍受擦除、垃圾回收和并行度影响。

<a id="s-44"></a>
#### 磨损均衡技术

<span class="content-anchor" id="p-55"></span>动态均衡分散新写入；静态均衡还移动长期不变的冷数据，使较少擦除的块有机会承担后续写入。判断移动方向应看擦除次数和未来用途，不能简单记作“搬到最空闲处”。

<a id="s-45"></a>
### 高速缓存 Cache

<a id="s-46"></a>
#### Cache的基本原理

<span class="content-anchor" id="p-56"></span>主存与 Cache 按块交换；时间局部性利用近期访问，空间局部性利用相邻访问。Cache 命中需有效位为 1 且 Tag 匹配。

<span class="content-anchor" id="p-57"></span>令 $t_c$ 为 Cache 查询时间、$t_m$ 为未命中后额外访问下层的时间、$h$ 为命中率；串行查询平均时间 $t_c+(1-h)t_m$；若题目规定并行查询或不同未命中代价，要改用对应模型。

<a id="s-47"></a>
#### Cache的映射方式

<span class="content-anchor" id="p-58"></span>设数据区 $C$ B，块 $B$ B，$k$ 路组相联：行数 $C/B$，组数 $C/(Bk)$。按字节编址时，块内偏移 $\log_2 B$ 位，组号 $\log_2(C/(Bk))$ 位，其余为 Tag，相关参数须为 2 的幂才能直接按位拆分。

<span class="content-anchor" id="p-59"></span>直接映射有一个候选行；全相联无组号；组相联只在目标组内比较和替换。主存块号对组数取模得到目标组。

<a id="s-48"></a>
#### Cache的比较器

<span class="content-anchor" id="p-60"></span>直接映射比较一个候选行，全相联比较所有行，$k$ 路组相联比较目标组内 $k$ 个 Tag；比较器位宽为 Tag 位数，还需检查有效位。

<a id="s-49"></a>
#### Cache块的替换算法

<span class="content-anchor" id="p-61"></span>FIFO 按进入顺序，LRU 淘汰最近最久未使用的行，随机法随机选择。命中可更新 LRU 次序，一般不更新 FIFO 插入次序；直接映射无需选择替换行。

<span class="content-anchor" id="p-62"></span>替换状态位取决于编码：FIFO 可每组设循环指针，精确 LRU 可用计数或次序结构，不能无条件按“每行 $\log_2 n$ 位”计算。

<a id="s-50"></a>
#### Cache的写策略

<span class="content-anchor" id="p-63"></span>写直达：命中同时写 Cache 与下层，可配写缓冲；写回：命中只改 Cache 并置脏，脏块替换时回写。写分配：写缺失先调块；非写分配：写缺失直接写下层。

<span class="content-anchor" id="p-64"></span>写回常配写分配，写直达常配非写分配，但命中策略和缺失策略是独立选择，不只有这两种合法组合。

<a id="s-51"></a>
#### Cache的容量

<span class="content-anchor" id="p-65"></span>硬件总容量＝数据位＋每行 Tag、有效位、必要脏位＋替换状态等。题目给的 Cache 容量通常指数据区，求“总位数”时不能只算数据。

<a id="s-52"></a>
### 虚拟存储器

<span class="content-anchor" id="p-66"></span>虚拟地址由 MMU 根据页表转换；普通成功转换主要靠硬件，缺页由 OS 处理。虚拟地址空间可以大于物理内存，页面未必全部驻留；TLB 未命中不等于缺页。

<a id="s-53"></a>
#### CPU访存全过程

<span class="content-anchor" id="p-67"></span>先检查地址转换与访问权限，再根据 Cache 组织访问数据；TLB 命中直接得到页框信息，未命中查页表；页不在内存或权限违规会触发相应异常。数据 Cache 命中和 TLB 命中是不同事件。

<a id="s-54"></a>
#### 段式/段页式虚拟存储器

<span class="content-anchor" id="p-68"></span>分段用段号、段内偏移，检查偏移是否小于段长；段页式先查段表获得该段页表，再查页表得到页框。分段仍可能有外部碎片，分页存在页内碎片。

<a id="s-55"></a>
### 页表 Page

<span class="content-anchor" id="p-69"></span>页表项保存页框号及有效/在内存、权限、访问、修改等控制信息，字段依体系结构。物理地址＝页框号×页大小＋页内偏移；页表项地址＝页表基址＋页号×页表项大小。

<a id="s-56"></a>
### 快表 TLB

<span class="content-anchor" id="p-70"></span>TLB 缓存近期虚拟页到物理页框的转换及权限信息；可采用全相联或组相联等组织。切换进程时需切换转换上下文，可刷新或用地址空间标识隔离。

<a id="s-57"></a>
### 访存命中分析

<span class="content-anchor" id="p-71"></span>单级页表驻内存、不考虑 Cache 时：TLB 命中通常访问一次目标主存；TLB 未命中但页在内存，先读页表再读数据，共两次；多级页表要逐级计数。缺页时间包含异常处理、可能的换出/调入和重启，不能固定写成“磁盘访问两次”。

<a id="s-58"></a>
## 第四章 指令系统

<a id="s-59"></a>
### 指令的概念

<span class="content-anchor" id="p-72"></span>指令通常含操作码及操作数/地址字段；指令执行涉及源操作数、目的位置和下一条指令地址。程序计数器递增量取决于指令长度和编址单位。

<a id="s-60"></a>
### 指令的格式

<span class="content-anchor" id="p-73"></span>三地址、二地址、一地址、零地址描述显式地址字段数量；一地址可隐含累加器，零地址可隐含栈顶。访存次数需看操作数在寄存器还是内存，不能单凭“二地址”固定为四次。

<a id="s-61"></a>
#### 操作码扩展

<span class="content-anchor" id="p-74"></span>保留某些短操作码前缀给长操作码，可在固定指令字长下兼容不同地址字段数量。逐层扣除已占前缀，再计算可扩展编码，不能各格式独立取 $2^k$ 后相加。

<a id="s-62"></a>
### 指令的寻址方式

<span class="content-anchor" id="p-75"></span>顺序寻址按指令长度推进 PC，跳转寻址按指令计算目标。相对寻址的 PC 基准可为当前或下一条指令，必须依 ISA/题设确定。

<a id="s-63"></a>
### 数据的寻址方式

|<span class="content-anchor" id="p-76"></span> 方式 | 有效地址或操作数 |
| --- | --- |
|<span class="content-anchor" id="p-77"></span> 立即 | 指令字段就是操作数 |
|<span class="content-anchor" id="p-78"></span> 直接 | $EA=A$ |
|<span class="content-anchor" id="p-79"></span> 间接 | $EA=M[A]$，可有多级 |
|<span class="content-anchor" id="p-80"></span> 寄存器 | 指定寄存器中的值 |
|<span class="content-anchor" id="p-81"></span> 寄存器间接 | $EA=R$ |
|<span class="content-anchor" id="p-82"></span> 基址 | $EA=BR+A$ |
|<span class="content-anchor" id="p-83"></span> 变址 | $EA=IX+A$ |
|<span class="content-anchor" id="p-84"></span> 相对 | $EA=PC+A$，A 通常符号扩展 |
|<span class="content-anchor" id="p-85"></span> 堆栈 | 由栈指针隐含定位 |

<span class="content-anchor" id="p-86"></span>区分“求 EA 的访问”与“读取操作数的访问”；寄存器访问不等于主存访问。基址常用于程序定位，变址常用于数组索引，功能仍依指令定义。

<a id="s-64"></a>
### 复杂精简指令集 CISC/RISC

<span class="content-anchor" id="p-87"></span>典型 RISC 倾向 load/store、较规则编码和较多寄存器；典型 CISC 指令形式较多，可支持存储器操作数。它们是设计取向，不以固定指令数量或 CPI 划界；RISC 也可有压缩变长指令，现代 CISC 也可流水、乱序、超标量执行。

<a id="s-65"></a>
### 程序的机器级表示

<a id="s-66"></a>
#### 常用汇编指令

<span class="content-anchor" id="p-88"></span>以 x86 为例，MOV 传送、ADD/SUB 加减、CMP 比较并设置标志而不保存差、NOT 按位取反、NEG 算术取负。MUL 通常有一个显式操作数并隐含累加器，IMUL 有不同操作数格式，不能混写。

<span class="content-anchor" id="p-89"></span>条件跳转区分有符号和无符号比较；JZ/JE 检查 ZF=1，JNZ/JNE 检查 ZF=0。汇编源/目的顺序依 Intel 或 AT&T 语法，先看题目约定。

<a id="s-67"></a>
#### 选择结构的机器级表示

<span class="content-anchor" id="p-90"></span>比较产生标志，条件跳转选择分支；还原条件时结合跳转方向、标签位置和有符号/无符号解释，避免把“跳出循环条件”当“继续条件”。

<a id="s-68"></a>
#### 循环结构的机器级表示

<span class="content-anchor" id="p-91"></span>识别初始化、条件判断、循环体、更新及回跳；do-while 先执行再判断，while/for 通常先判断。访存次数按实际执行路径计。

<a id="s-69"></a>
#### 过程调用的机器级表示

<span class="content-anchor" id="p-92"></span>CALL 保存返回地址并跳转，RET 恢复返回地址；参数、返回值、栈增长方向及保存寄存器规则由调用约定确定。调用者保存与被调用者保存分开判断，递归调用有独立栈帧。

<a id="s-70"></a>
## 第五章 中央处理器

<a id="s-71"></a>
### CPU的功能和结构

<a id="s-72"></a>
#### CPU的组成

<span class="content-anchor" id="p-93"></span>CPU 负责取指、译码、执行和处理中断，典型包含运算部件、寄存器及控制部件。PC 指向指令，IR 保存当前指令，MAR 保存访存地址，MDR 保存交换数据；实际 CPU 可采用其他内部结构。

<a id="s-73"></a>
#### PC的位数问题

<span class="content-anchor" id="p-94"></span>PC 表示程序可见的指令地址，MAR 对应具体访存地址组织；虚拟与物理地址位数可不同。指令对齐只使部分低位恒零，不自动意味着架构规定的 PC 缩短这些位。

<a id="s-74"></a>
#### 可见或透明的寄存器

<span class="content-anchor" id="p-95"></span>通用寄存器、PC、状态寄存器等通常由 ISA 定义；IR、MAR、MDR 等通常属于实现内部。透明性看程序是否能通过 ISA 观察或操作，而不是看寄存器是否真实存在。

<a id="s-75"></a>
### 指令周期的数据流向

<a id="s-76"></a>
#### 取指周期

<span class="content-anchor" id="p-96"></span>基本动作是 PC 给出地址、读存储器获得指令、更新 PC；单总线教材模型可写 PC→MAR，存储器→MDR，MDR→IR。是否需要中间寄存器和时钟数依数据通路。

<a id="s-77"></a>
#### 间址周期

<span class="content-anchor" id="p-97"></span>存在存储器间接寻址时，先读取间接地址，再得到有效地址；没有这种寻址方式的指令不经历该阶段。

<a id="s-78"></a>
#### 执行周期

<span class="content-anchor" id="p-98"></span>按操作码完成运算、访存或控制转移；结果和状态在指定时刻写入目的位置。

<a id="s-79"></a>
#### 各周期访存对比

<span class="content-anchor" id="p-99"></span>取指读指令，间址读地址，执行阶段可能读写操作数；中断入口可能保存返回信息。访问次数按图中实际读写动作统计，不能把所有指令都套同一表。

<a id="s-80"></a>
### 数据通路的概念

<a id="s-81"></a>
#### 数据通路的定义

<span class="content-anchor" id="p-100"></span>数据通路是数据流动和处理的部件及连接；控制信号决定来源、去向、运算和写入时机。

<a id="s-82"></a>
#### 数据通路的组成

<span class="content-anchor" id="p-101"></span>寄存器、ALU、移位器、总线、多路选择器和必要暂存器。组合逻辑产生结果，时序部件在时钟边沿保存状态。

<a id="s-83"></a>
### 数据通路的结构

<a id="s-84"></a>
#### 单总线结构

<span class="content-anchor" id="p-102"></span>同一时刻通常只能一个部件驱动共享总线，可由多个部件接收；双操作数运算常需暂存器保存其中一个操作数。不能同时输出两个不同值到同一总线。

<a id="s-85"></a>
#### 取指间址的信号序列

<span class="content-anchor" id="p-103"></span>微操作写成 PC→MAR 等数据动作；控制信号写成 PCout、MARin、Read 等。先找数据路径，再给出使路径成立的信号；寄存器同步写入时序依题设。

<a id="s-86"></a>
#### 单周期和多周期CPU

<span class="content-anchor" id="p-104"></span>单周期 CPU 每条指令在一个长时钟周期完成，时钟受最慢指令路径约束，状态在周期边沿更新；多周期把一条指令分成多个短周期并复用部件。多周期不自动等于流水线；流水线需要不同指令阶段重叠。

<a id="s-87"></a>
### 控制器的概念

<a id="s-88"></a>
#### 控制器的输入输出

<span class="content-anchor" id="p-105"></span>根据操作码、状态、节拍及异常信号，产生寄存器读写、ALU 功能、存储器读写及选择信号。

<a id="s-89"></a>
#### 控制器的分类

<span class="content-anchor" id="p-106"></span>硬布线控制由逻辑电路形成控制，通常快但复杂指令修改较难；微程序控制通过读取微指令生成控制，通常更灵活，但需控制存储器访问。性能结论结合实现。

<a id="s-90"></a>
### 微程序控制器

<a id="s-91"></a>
#### 微程序控制的概念

<span class="content-anchor" id="p-107"></span>一条机器指令通常对应一段微程序；一条微指令可发出多条兼容微命令，完成多个微操作。微命令是控制信号，微操作是部件动作，机器指令与微指令不在同一层次。

<a id="s-92"></a>
#### 微程序控制器的组成

<span class="content-anchor" id="p-108"></span>控制存储器存微程序，微地址寄存器定位微指令，微指令寄存器保存读出内容，下地址逻辑选择后继。控制存储器常用 ROM，也可以是可写控制存储器。

<a id="s-93"></a>
#### 微程序控制器的工作过程

<span class="content-anchor" id="p-109"></span>读当前微指令→发出控制信号→完成微操作→按顺序、测试或转移生成下一微地址，直至转回公共取指微程序。

<a id="s-94"></a>
#### 微指令地址的生成方式

<span class="content-anchor" id="p-110"></span>可顺序递增、按机器操作码映射入口、由微指令下地址字段给出，或根据状态条件分支。

<a id="s-95"></a>
#### 微指令的格式和编码方式

<span class="content-anchor" id="p-111"></span>水平型可并行发出多个微命令，字长通常较长；垂直型编码更紧凑、译码较多、并行程度较低。

<span class="content-anchor" id="p-112"></span>##### 微指令的编码方式

<span class="content-anchor" id="p-113"></span>直接编码每位对应控制信号；字段直接编码把互斥命令放同一字段；字段间接编码由其他字段参与解释。能同时执行的命令不能放进同一个互斥字段。

<span class="content-anchor" id="p-114"></span>##### 微指令的格式

<span class="content-anchor" id="p-115"></span>控制字段决定本拍动作，顺序控制字段决定下一地址；含多少条微命令不等于能任意同时执行，仍受资源冲突和先后依赖约束。

<a id="s-96"></a>
### 异常和中断机制

<a id="s-97"></a>
#### 异常和中断的概念

<span class="content-anchor" id="p-116"></span>异常由当前指令执行引发，中断通常来自处理器外部异步事件。典型分类：fault 修复后重试，trap 执行后报告，abort 为严重错误；具体返回地址依体系结构。

<span class="content-anchor" id="p-117"></span>中断响应进入内核不等于切换到另一个进程；硬件保存返回状态的一部分，软件再保存需要保护的寄存器。

<a id="s-98"></a>
#### 异常和中断的响应流程

<span class="content-anchor" id="p-118"></span>在允许响应的位置检查请求与屏蔽状态，保存必要返回信息、改变执行特权及入口地址，开始处理；可屏蔽中断和 NMI 的响应条件不同。

<a id="s-99"></a>
#### 异常和中断的处理流程

<span class="content-anchor" id="p-119"></span>保存现场→处理事件→恢复现场→异常/中断返回；若需要调度，返回时可能运行其他进程。不能把每次中断都写成完整进程上下文切换。

<a id="s-100"></a>
#### 中断向量和中断向量表

<span class="content-anchor" id="p-120"></span>向量用于定位处理入口或描述符，向量表组织相关信息；“向量值就是处理程序地址”仅适用于相应题目模型。

<a id="s-101"></a>
#### 多重中断和中断屏蔽

<span class="content-anchor" id="p-121"></span>中断嵌套需允许相应请求进入；屏蔽字决定可打断当前处理的请求。响应优先级与处理优先级可不同，位 0/1 含义按题设；不存在跨所有机器通用的“DMA>NMI>其他中断”顺序。

<a id="s-102"></a>
### 指令流水线

<a id="s-103"></a>
#### 指令流水线的概念

<span class="content-anchor" id="p-122"></span>把指令划分为阶段，使不同指令的不同阶段重叠，提高吞吐率；单条指令延迟未必降低。

<a id="s-104"></a>
#### 流水线的逻辑结构

<span class="content-anchor" id="p-123"></span>典型五级为 IF 取指、ID 译码/读寄存器、EX 运算、MEM 访存、WB 写回。不同指令可能某阶段无有效动作，仍经过对应流水位置；分支何时确定必须看具体设计。

<a id="s-105"></a>
#### 流水线的指令要求

<span class="content-anchor" id="p-124"></span>规则编码、较简单寻址和 load/store 设计有利于流水，但不意味着只有 RISC 能流水。

<a id="s-106"></a>
#### 流水线的性能指标

<span class="content-anchor" id="p-125"></span>$k$ 段等长、每段周期 $\tau$、无停顿时，$n$ 条指令时间 $(k+n-1)\tau$；吞吐率 $n/((k+n-1)\tau)$，相对不重叠执行的加速比 $nk/(k+n-1)$。不等长阶段、寄存器延迟和冒险要另计。

<a id="s-107"></a>
### 流水线冒险和处理

<span class="content-anchor" id="p-126"></span>结构冒险来自资源冲突，可分离资源或停顿；数据冒险来自依赖，可转发、停顿或调度；控制冒险来自分支，可预测、延迟或冲刷流水。

<span class="content-anchor" id="p-127"></span>基本顺序五级重点是 RAW；WAR、WAW 常涉及乱序或多周期完成。ALU 结果通常 EX 结束可转发；load 数据到 MEM 结束才得到，紧随 load 的指令下一周期 EX 要使用时，典型仍停顿 1 周期。没有转发时停顿数还取决于寄存器读写同周期规则，不能固定记成 3。

<a id="s-108"></a>
### 高级流水线

<span class="content-anchor" id="p-128"></span>超标量每周期可发射多条指令，平均 CPI 可以小于 1；超流水细分阶段；动态调度、寄存器重命名和推测执行分别处理依赖、假相关和控制等待。多发射宽度只是上界，实际并行度受依赖与资源限制。

<a id="s-109"></a>
### 多处理器

<a id="s-110"></a>
#### 计算架构的概念

<span class="content-anchor" id="p-129"></span>Flynn 分类：SISD 单指令单数据、SIMD 单指令多数据、MISD 多指令单数据、MIMD 多指令多数据。SISD 仍可采用流水；MISD 少见，不应等同于绝不存在。

<a id="s-111"></a>
#### 多处理器的概念

<span class="content-anchor" id="p-130"></span>共享内存系统可分 UMA 与 NUMA，NUMA 的访问延迟与内存所在位置有关；多核不意味着程序自动加速，需要可并行工作并付出同步通信成本。

<a id="s-112"></a>
#### 硬件多线程

<span class="content-anchor" id="p-131"></span>线程保留独立架构状态，共享部分执行资源。粗粒度多线程在长延迟事件切换，细粒度可按周期交替，SMT 可在同周期从多个线程发射指令；SMT 不等同增加物理核。

<a id="s-113"></a>
## 第六章 总线

<a id="s-114"></a>
### 总线分类

<span class="content-anchor" id="p-132"></span>按位置可分片内、系统、外部总线；按角色可分数据、地址、控制线；串行/并行、同步/异步是不同分类维度。

<a id="s-115"></a>
### 系统总线

<span class="content-anchor" id="p-133"></span>数据线搬运数据，地址线选择目标，控制线表达读写、请求、应答等。地址线数量结合编址单位决定可寻址容量。

<a id="s-116"></a>
### 总线的性能指标

<span class="content-anchor" id="p-134"></span>带宽＝每秒传输次数×每次传输字节数。若时钟频率 $f$、每次传输占 $c$ 个时钟，则传输频率 $f/c$；若每周期传 $q$ 次，则为 $qf$。已给 MT/s 时不要重复乘 DDR 倍数，bit/s 转 B/s 要除 8。

<a id="s-117"></a>
### 总线事务

<span class="content-anchor" id="p-135"></span>一次事务可包含请求、仲裁、地址/命令、数据、响应及释放阶段；突发传输共用部分开销，分离事务允许请求与响应之间释放总线，不能把它与 DMA 周期窃取混同。

<a id="s-118"></a>
### 总线定时

<span class="content-anchor" id="p-136"></span>同步用公共时钟，异步用请求/应答握手，半同步允许在同步时序中插入等待。WAIT 通常表示尚未就绪，具体有效电平和时序由题设确定。

<a id="s-119"></a>
## 第七章 输入输出系统

<a id="s-120"></a>
### IO接口

<a id="s-121"></a>
#### IO接口和系统总线的连接

<span class="content-anchor" id="p-137"></span>接口提供数据缓冲、状态、控制、地址译码及设备适配；端口是 CPU 可访问的相关寄存器，接口是包含这些端口的部件。

<a id="s-122"></a>
#### IO端口的编址

<span class="content-anchor" id="p-138"></span>统一编址占用统一地址空间并用访存类指令；独立编址有独立端口空间并用专用 I/O 指令。相同数值地址不必代表相同对象。

<a id="s-123"></a>
### IO方式

<a id="s-124"></a>
#### 程序查询方式

<span class="content-anchor" id="p-139"></span>CPU 检查设备状态并搬运数据；忙等会占用 CPU，定期轮询则可在间隔中做其他工作。查询周期需保证不丢数据，并计查询与传输指令开销。

<a id="s-125"></a>
#### 程序中断方式

<span class="content-anchor" id="p-140"></span>设备就绪通知 CPU，数据仍由中断服务程序搬运，CPU 与设备工作可重叠；中断开销按次数×每次服务时间计算，中断入口与现场保护见本章前面的异常和中断机制。

<a id="s-126"></a>
#### DMA方式

<span class="content-anchor" id="p-141"></span>CPU 配置起始地址、方向和长度，DMA 控制器经总线搬运数据块，完成后通常中断通知。512 B 数据、每次传 4 B 仍需 128 次基本传输，不能当一次总线事务。

<span class="content-anchor" id="p-142"></span>##### DMA访问主存

<span class="content-anchor" id="p-143"></span>可独占一段总线时间、周期窃取或与 CPU 交替访问；CPU 是否暂停、暂停多久要看访存冲突和仲裁。计数器可减到 0 或按其他方式标记结束，不固定为“不断加直到溢出”。

<a id="s-127"></a>
#### IO方式的比较

|<span class="content-anchor" id="p-144"></span> 方式 | 谁搬运数据 | CPU 的主要工作 |
| --- | --- | --- |
|<span class="content-anchor" id="p-145"></span> 查询 | CPU | 检查状态和逐次搬运 |
|<span class="content-anchor" id="p-146"></span> 中断 | CPU | 就绪后运行服务程序 |
|<span class="content-anchor" id="p-147"></span> DMA | DMA 控制器 | 配置、处理完成事件 |

<span class="content-anchor" id="p-148"></span>DMA 降低逐字搬运开销，不取消 CPU 的设置与收尾工作；中断、DMA、总线仲裁的优先级只按给定系统判断。

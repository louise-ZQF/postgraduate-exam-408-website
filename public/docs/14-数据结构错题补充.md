# 数据结构错题补充

<span class="content-anchor" id="p-1"></span>这份补充整理自数据结构两版错题笔记，集中放置原知识体系页未展开或容易误判的条件、操作步骤和计算边界；基础定义仍可回到“数据结构”知识体系查阅。

<a id="s-2"></a>
## 栈、队列与递归

<a id="s-3"></a>
### 顺序栈和共享栈的边界

<span class="content-anchor" id="p-2"></span>顺序栈的 `top` 既可以约定为“当前栈顶下标”，也可以约定为“下一个空位置”，判断 `top++`、`++top` 和栈空条件之前必须先读题目约定。两个栈共享长度为 $n$ 的数组时，可从两端向中间生长：若初值为 `top1=-1`、`top2=n`，栈满条件是 `top2-top1==1`，两个栈顶相邻而不是重合。共享栈提高空间利用率并降低上溢概率，不能消除栈空时继续出栈造成的下溢。

<a id="s-4"></a>
### 合法出栈序列与调用次数

<span class="content-anchor" id="p-3"></span>判断固定输入顺序的出栈序列，要逐步记录已输入元素、当前栈顶和目标输出；开始出栈后仍允许继续入栈，栈内剩余元素也不能任意重排。三个不同元素在固定入栈顺序下只有五种合法出栈序列，并非 $3!$ 种。递归题则要分清返回值、调用次数和最大深度：`2*F(n/2)` 只有一次递归调用，`F(n/2)+F(n/2)` 才有两次；计算总调用次数时，递归调用树中的当前结点也要计一次。

<a id="s-5"></a>
### 双端队列与两个队列重排

<span class="content-anchor" id="p-4"></span>输入受限双端队列只允许从指定一端入队，但两端都可出队；输出受限双端队列允许两端入队，但只能从指定一端出队，新元素始终只能放在端点。用两个普通队列重排固定输入时，每个队列内部必须保留输入的相对顺序；对递增输入，目标输出能否实现可转化为它能否拆成两个递增子序列。若每条铁路调车轨道相当于一个队列、最终按编号递增输出，所需最少轨道数等于输入序列的最长下降子序列长度；证明最少数量时还应构造可行的轨道分配。

<a id="s-6"></a>
### 表达式与括号栈

<span class="content-anchor" id="p-5"></span>后缀表达式求值时，若依次弹出 `a`、`b`，题目规定的二元运算通常应计算 `b op a`，减法和除法尤其不能交换次序。括号匹配需要的最大栈容量等于扫描过程中尚未匹配的左括号数的最大值，也就是最大嵌套深度，而非整串括号总数。

<a id="s-7"></a>
## 链表操作中的边界

<a id="s-8"></a>
### 查找位置与改指针分开计时

<span class="content-anchor" id="p-6"></span>已知结点位置后修改少量链接通常是 $O(1)$，但“在有序单链表中找到插入位置并插入”的完整操作仍可能是 $O(n)$。普通单链表即使持有尾指针，删除尾结点仍要寻找前驱，通常为 $O(n)$；若是双链表，尾结点的 `prior` 可直接定位前驱。静态链表虽然用数组保存结点，结点之间仍靠游标链接，插删不需要像顺序表那样移动大量数据元素。

<a id="s-9"></a>
### 删除循环链表首元与双链表插入

<span class="content-anchor" id="p-7"></span>带头结点的循环单链表删除首个数据结点时，应先保存旧首结点 `q=h->next`，再执行 `h->next=q->next`，最后释放 `q`；若删除后表空且同时维护尾指针，尾指针必须回到头结点。无头结点且只有头指针的循环单链表若删除首元，通常还需要遍历寻找尾结点并改写其 `next`。双链表插入时应先保存旧前驱、旧后继，再建立新结点两侧链接；过早覆盖 `p->prior` 或 `p->next`，可能丢失原来的邻接结点地址。

<a id="s-10"></a>
## 树、编码与并查集

<a id="s-11"></a>
### 特殊矩阵的压缩下标

<span class="content-anchor" id="p-8"></span>对称矩阵只存上三角或下三角时，先确认矩阵下标从 0 还是 1 开始、压缩数组下标从 0 还是 1 开始，以及按行还是按列存；目标落在未存储的半区，须先用 $a_{ij}=a_{ji}$ 交换行列。以下三角按行存储、两个下标都从 0 开始为例，$a_{ij}$（$i\ge j$）的压缩下标是 $i(i+1)/2+j$，其中 $i(i+1)/2$ 是第 $i$ 行之前已有的元素数。$n$ 阶三对角矩阵（$n\ge2$）最多有 $3n-2$ 个非零元，首尾两行各 2 个，其余行各 3 个。按行优先的二维数组地址差可由 $[(\Delta i)N+\Delta j]L$ 求出，$N$ 为每行元素数，$L$ 为每元素占用字节数。

<a id="s-12"></a>
### 完全二叉树的编号与形态

<span class="content-anchor" id="p-9"></span>完全二叉树按层从 1 编号时，结点 $i$ 的两个孩子候选编号是 $2i$ 与 $2i+1$，只有不超过总结点数 $n$ 才存在；最后一个非叶结点编号为 $\lfloor n/2\rfloor$，叶结点数为 $\lceil n/2\rceil$。因此若已知叶子数 $L$，总结点数只能是 $2L-1$ 或 $2L$。任意非空二叉树满足 $n_0=n_2+1$，不能只对完全二叉树使用；但完全二叉树至多只有一个度为 1 的结点，且只能有左孩子。只给先序或后序遍历通常无法唯一确定二叉树，需结合中序；固定入栈顺序的合法出栈序列数则为卡特兰数 $C_n=\binom{2n}{n}/(n+1)$。

<a id="s-13"></a>
### 树的度和叶结点数

<span class="content-anchor" id="p-10"></span>“树的度为 $m$”表示至少一个结点有 $m$ 个孩子，不表示每个结点都有 $m$ 个孩子。若 $n_i$ 是度为 $i$ 的结点数，则叶结点数满足 $n_0=1+\sum_{i=2}^{m}(i-1)n_i$；度为 1 的结点只延长路径，不增加叶结点数量。高度为 $h$ 的 $m$ 叉树最多有 $(m^h-1)/(m-1)$ 个结点（$m>1$）；讨论最少结点数时，还必须满足确实存在度为 $m$ 的结点。

<a id="s-14"></a>
### AVL 树最少结点递推

<span class="content-anchor" id="p-11"></span>以单个根结点高度为 1 计，高度为 $h$ 的 AVL 树最少结点数满足 $N_1=1$、$N_2=2$、$N_h=N_{h-1}+N_{h-2}+1$，前几项为 $1,2,4,7,12,20$。这是求“给定高度的最少结点数”或“给定结点数的最大可能高度”的边界，并不表示每棵高度为 $h$ 的 AVL 树都恰有 $N_h$ 个结点；若某个结点的左右子树高度相等，它在该处所需结点数会更多。

<a id="s-15"></a>
### 前缀码与哈夫曼编码

<span class="content-anchor" id="p-12"></span>前缀码只要求任一码字都不是另一码字的开头，不要求码字等长；等长编码必然满足前缀条件，但满足前缀条件的编码未必是给定频率下的最优哈夫曼编码。例如 `{0,10,110,111}` 是不等长前缀码，而 `{0,1,00,11}` 不是。判断新增码字是否可用时，应检查它与已有每个码字的前缀包含关系。

<a id="s-16"></a>
### 并查集的 `Find`、`Union` 与复杂度

<span class="content-anchor" id="p-13"></span>`Find(x)` 返回元素所属集合的代表元；根在数组中可能用负数保存集合大小，但那个负数不是 `Find` 的返回定义。`Union(x,y)` 合并的是两个完整集合，只有代表元原本不同、实际发生合并时，集合总数才减 1；重复合并同一集合不减少集合数。未优化的树可能退化为链，使 `Find` 最坏达到 $O(n)$；按规模合并可将树高限制在 $O(\log n)$，再配合路径压缩，均摊代价接近常数。Kruskal 算法处理边 $(u,v)$ 时，若两端代表元相同，加入该边会形成环。

<a id="s-17"></a>
### B 树与 B+ 树的高度

<span class="content-anchor" id="p-14"></span>按“根所在层为第 1 层”的定义，$m$ 阶 B 树的非根内部结点至少有 $d=\lceil m/2\rceil$ 个孩子，根若不是叶结点至少有 2 个孩子。高度为 $h$ 时，最少关键字数为 $2d^{h-1}-1$，最多为 $m^h-1$；求给定关键字数的最大高度，要让树尽量稀疏，求最小高度则让结点尽量满。某一层有 $T$ 个非叶结点、共 $K$ 个关键字时，下一层真实孩子数为 $K+T$。B 树可能在内部结点找到记录而提前成功，B+ 树内部结点仅供导航，成功查找通常都要走到叶结点。

<a id="s-18"></a>
## 图的可达性、存储与遍历

<a id="s-19"></a>
### 路径、直接边与保证连通

<span class="content-anchor" id="p-15"></span>“从 $u$ 可到达 $v$”只说明存在一条经过零个或多个中间顶点的路径，不能推出两点直接相邻。对无自环、无重边且 $n\ge2$ 的 $n$ 顶点无向简单图，构造一个连通图至少需要 $n-1$ 条边；要保证不管边如何分布都连通，则至少需要 $\binom{n-1}{2}+1$ 条边，因为非连通图最多可由一个 $K_{n-1}$ 和一个孤立顶点构成。两种问法的量词不同，不能共用 $n-1$ 作为答案。

<a id="s-20"></a>
### 邻接矩阵的幂与特殊存储

<span class="content-anchor" id="p-16"></span>对无权图的普通邻接矩阵 $A$，$(A^k)[i][j]$ 表示从 $i$ 到 $j$ 长度**恰好为** $k$ 的游走数量，元素值是“条数”，指数才是“长度”；游走允许重复顶点，因此不能直接把它解释为简单路径数。无向图的邻接多重表让一条边只对应一个边结点；有向图的十字链表让一条弧同时进入弧尾的出边链和弧头的入边链。

<a id="s-21"></a>
### DFS、BFS 的约束

<span class="content-anchor" id="p-17"></span>DFS 在当前顶点仍有未访问邻接点时应继续深入，不能提前回溯去访问另一分支。BFS 按距离起点的边数逐层扩展，相邻输出的两个顶点不要求直接相邻；在无权图或所有边权相同且非负的图中，它得到的是最少边数路径，边权不同则不能据此断定总权值最小。有向图即使无环也要记录访问状态，因为不同路径可以汇合到同一顶点。

<a id="s-22"></a>
### 拓扑序列与关键路径

<span class="content-anchor" id="p-18"></span>拓扑序列中 $a$ 排在 $b$ 前，不代表一定有直接弧 $a\to b$；若按拓扑序排列 DAG 顶点，其邻接矩阵呈上三角形式。关键活动变长会使经过它的关键路径变长，但缩短某一条关键路径上的活动不一定缩短总工期，因为其他关键路径可能保持原长；要缩短工期，必须让所有当前关键路径都受到有效缩短。

<a id="s-23"></a>
## 查找、散列与排序

<a id="s-24"></a>
### 折半查找与散列失败查找

<span class="content-anchor" id="p-19"></span>折半查找同时需要关键字有序和按逻辑次序随机存取；有序链表与按游标链接的静态链表都不能直接套用普通数组的二分下标。开放定址法计算失败查找长度时，从每个可能的初始散列地址出发，探测到第一个空位置并把这次探测计入长度；题设中各初始散列地址等概率时，失败 ASL 的分母是散列函数可能产生的初始地址数，不一定等于物理表长。例如 `H(key)=key mod 7` 只有七个可能初始地址，即使表长为 11，分母仍取 7。线性探测可能形成主聚集；平方探测的探测序列未必覆盖全表，所以“表未满”不总能保证在该序列中找到空位。

<a id="s-25"></a>
### 堆查找与快速排序的“趟”

<span class="content-anchor" id="p-20"></span>堆只保证父结点与孩子的偏序，不保证左、右子树像二叉搜索树那样分隔关键字；查找普通关键字最坏仍需检查 $O(n)$ 个结点。快速排序的一次划分只保证枢轴到达最终位置，左右子表内部尚未有序；题目若把“一趟”定义为处理当前全部待排子表，则第二趟可能需要分别处理第一趟产生的两个子表，不能只划分其中一个。

<a id="s-26"></a>
### 插入、希尔和建堆的过程

<span class="content-anchor" id="p-21"></span>折半插入排序仅减少确定插入位置所需的关键字比较，腾出位置时仍要移动元素，总时间通常仍为 $O(n^2)$。希尔排序某个增量 $d$ 的一趟，是分别对下标相差 $d$ 的各组做插入排序；只保证各组内部有序，最后增量必须为 1。逐个插入建堆与对完整数组自底向上建堆，可能产生不同但都合法的堆；模拟题须按指定过程作答。堆的调整比较次数也包含最后发现无需继续交换的比较，不能只数交换次数。

<a id="s-27"></a>
### 外部排序的三种工具

<span class="content-anchor" id="p-22"></span>普通方法在内存工作区可容纳 $M$ 条记录时，$n$ 条记录约形成 $r=\lceil n/M\rceil$ 个初始归并段，$k$ 路归并的归并趟数为 $\lceil\log_k r\rceil$；题目只问“归并趟数”时，生成初始段通常不算一趟。置换选择排序用于产生长度可变的初始段，不能独立完成外部排序；随机输入模型下，段长平均值可能接近工作区大小的两倍，但不是每段必然如此。败者树用于高效选出多路归并的当前最小记录，每输出一条后的调整为 $O(\log k)$；最佳归并树负责安排不同长度段的合并顺序，使总读写代价最小，两者用途不同。构造 $k$ 路最佳归并树时可补零权虚段，使叶子总数满足 $(n-1)\bmod(k-1)=0$，虚段不增加实际读写量。

## 栈、队列与递归

<div class="study-unit" id="u-14-rewrite-793d42dce21a">

这一组问题都在追踪有限空间中“谁已经进入、谁还能离开、下一个位置在哪里”。栈按逆序交付，队列按原序交付，递归则用调用栈保留未完成工作。

</div>

<div class="study-unit" id="u-14-rewrite-ba959281597b">

**先明确指针代表已有元素还是空位，再看边界。** 出栈序列、双端重排和调用次数还需要记录实际操作过程，不能只根据元素数量或函数返回值判断。

</div>

<span class="legacy-anchor" data-target="s-14-5def76e34247" id="s-3"></span><span class="legacy-anchor" data-target="s-14-5def76e34247" id="p-2"></span><span class="legacy-anchor" data-target="s-14-5def76e34247" id="u-14-2e8826edd629"></span>
<a id="s-14-5def76e34247"></a>

### 顺序栈和共享栈的边界

<div class="study-unit" id="u-14-rewrite-56a84242be59">

本节统一数组容量为 $n$、有效下标为 `0～n-1`。同一个 `top` 名称可能代表已有栈顶，也可能代表下一空位，因此空栈初值和满栈上界会相差 1。

</div>

<div class="study-unit" id="u-14-rewrite-44e29de2c95c">

**判断表达式之前，先写指针含义与元素数。** 元素数若是 `top+1`，对应已有栈顶；若是 `top`，对应下一空位。共享栈还要同时看左右两个生长方向，下面分别列出，避免互套。

</div>

<span class="legacy-anchor" data-target="s-14-d3b6a48b0a5e" id="u-14-49b5ecc6c574"></span><span class="legacy-anchor" data-target="s-14-d3b6a48b0a5e" id="u-14-d8939acab723"></span>
<a id="s-14-d3b6a48b0a5e"></a>

#### 顺序栈：top 指向当前栈顶

<div class="study-unit" id="u-14-rewrite-8da4160adaba">

这里 `top` 总指向已经存在的最后一个元素。**空：`top==-1`；满：`top==n-1`；个数：`top+1`。** 空时没有可读栈顶，满时正好用到最后一个合法下标。

</div>

<div class="study-unit" id="u-14-rewrite-b4a337cf4ec1">

入栈需先移到新位置再写，即 `a[++top]=x`；出栈先读旧栈顶再回退，即 `x=a[top--]`。例如容量 3，连续入栈后 top 依次为 0、1、2，到 2 就满，不应等到 3。

</div>

<div class="study-unit" id="u-14-f45470593db5">

| 要看什么 | 表达式 / 操作 |
| --- | --- |
| 初值 | `top = -1` |
| 元素个数 | `top+1` |
| 入栈（先判满） | `a[++top] = x`，先把 top 移到新位置，再写入 |
| 出栈（先判空） | `x = a[top--]`，先读取当前栈顶，再后退 |

</div>

<span class="legacy-anchor" data-target="s-14-77e66fe2a111" id="u-14-dfa812993dfb"></span><span class="legacy-anchor" data-target="s-14-77e66fe2a111" id="u-14-ac578ad974e2"></span>
<a id="s-14-77e66fe2a111"></a>

#### 顺序栈：top 指向下一空位

<div class="study-unit" id="u-14-rewrite-da5d3b67c015">

这里已有元素占 `0～top-1`，真正栈顶在 `top-1`。**空：`top==0`；满：`top==n`；个数：`top`。** 满时 top 是数组末尾外的边界位置，不能解引用。

</div>

<div class="study-unit" id="u-14-rewrite-fe2c05b52cb1">

入栈在当前空位写后前进，即 `a[top++]=x`；出栈先退回已有元素，即 `x=a[--top]`。容量 3 存满时 top 为 3，而数据在下标 0、1、2，区别正是“下一空位”这层约定。

</div>

<div class="study-unit" id="u-14-91db1b589c69">

| 要看什么 | 表达式 / 操作 |
| --- | --- |
| 初值 | `top = 0` |
| 元素个数 | `top` |
| 入栈（先判满） | `a[top++] = x`，先写当前空格，再让 top 后移 |
| 出栈（先判空） | `x = a[--top]`，先退回已有元素，再读取 |

</div>

<span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-113783e23d65"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-1dae2b962eeb"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-7b3845ada061"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-35588ee3f245"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-a540cf777a10"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-cc308165cee4"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-1b4d43aa8519"></span><span class="legacy-anchor" data-target="s-14-71aaa4827251" id="u-14-4f3d24eb97b7"></span>
<a id="s-14-71aaa4827251"></a>

#### 共享栈：两端向中间生长

<div class="study-unit" id="u-14-rewrite-5e08aa779e6b">

约定两指针都指当前栈顶，左栈从 −1 向右长，右栈从 $n$ 向左长。**左空 `top1==-1`，右空 `top2==n`，整体满 `top2-top1==1`**，某一个为空不影响另一个是否有数据。

</div>

<div class="study-unit" id="u-14-rewrite-0d7febc6911f">

中间剩余格数为 **`top2-top1-1`**。$n=6$、两栈顶分别为 2 和 3 时，两侧恰好占满，没有空格；等指针相等才判满会覆盖已有值。左入 `++top1`、右入 `--top2`，不需固定各占一半；共享减少闲置，却不能阻止对某个空栈误出栈。

</div>

<div class="study-unit" id="u-14-71af0e9c57d2">

| 要看什么 | 表达式 / 操作 |
| --- | --- |
| 两栈都空 | `top1 == -1 && top2 == n` |
| 中间剩余空位 | `top2-top1-1` |
| 已存元素总数 | `(top1+1)+(n-top2)` |
| 左栈入 / 出 | `a[++top1]=x` / `x=a[top1--]` |
| 右栈入 / 出 | `a[--top2]=x` / `x=a[top2++]` |

</div>

<span class="legacy-anchor" data-target="s-14-ed1e8426fddf" id="u-14-a518b98853b3"></span><span class="legacy-anchor" data-target="s-14-ed1e8426fddf" id="u-14-5adb59d3e048"></span><span class="legacy-anchor" data-target="s-14-ed1e8426fddf" id="u-14-c3715c09027f"></span><span class="legacy-anchor" data-target="s-14-ed1e8426fddf" id="u-14-7a7d158ab8c0"></span><span class="legacy-anchor" data-target="s-14-ed1e8426fddf" id="u-14-e80417f88959"></span>

### 循环队列的判空与判满

<div class="study-unit" id="u-14-rewrite-a9a6050de040">

约定容量为 $M$，front 指当前队头，rear 指下一写入位置，牺牲一格来区分状态。**空 `front==rear`；满 `(rear+1)%M==front`；数量 `(rear-front+M)%M`；最多 $M-1$ 个。**

</div>

<div class="study-unit" id="u-14-rewrite-61220c276181">

入队先写 rear 再取模前进，出队先读 front 再取模前进。$M=4$、front=3、rear=1 时，元素占 3、0 两格；取模把跨越数组末尾的距离接起来，不能直接 rear−front。下表与本段使用同一约定。

</div>

<div class="study-unit" id="u-14-5326613dc93c">

| 要看什么 | 表达式 / 操作 |
| --- | --- |
| 初值 | `front = rear = 0` |
| 元素个数 | `(rear-front+M)%M` |
| 最多存放 | `M-1` 个元素 |
| 入队（先判满） | 先 `a[rear]=x`，再 `rear=(rear+1)%M` |
| 出队（先判空） | 先 `x=a[front]`，再 `front=(front+1)%M` |

</div>

<span class="legacy-anchor" data-target="s-14-2ea413f13425" id="u-14-d7d81ec814eb"></span><span class="legacy-anchor" data-target="s-14-2ea413f13425" id="u-14-5c4a092da5b6"></span><span class="legacy-anchor" data-target="s-14-2ea413f13425" id="u-14-6b63dc2a6854"></span>
<a id="s-14-2ea413f13425"></a>

#### 另一种实现：额外维护 size

<div class="study-unit" id="u-14-rewrite-e932c3b9e213">

增加 size 后，用它明确保存实际元素数，**空为 `size==0`，满为 `size==M`**，全部 $M$ 格都能使用。每次成功入队后加一、出队后减一，移动下标仍要取模。

</div>

<div class="study-unit" id="u-14-rewrite-2a9f43bbe946">

这时 front==rear 可以既表示空也表示满，要结合 size 区分。**牺牲一格的判满式不再适用**；若改用 tag，也应先看 tag 表示上一次入队还是出队，不能仅凭变量名猜真假含义。

</div>

### 合法出栈序列与调用次数

<div class="study-unit" id="u-14-rewrite-1a57fcdbe759">

验证出栈序列时，从尚未输入的元素中依次压入，直到栈顶等于当前目标，再弹出；如果所需元素已经压在别的元素下面，就无法跳过去。开始弹出后仍可继续输入，不能假设必须先全部入栈。

</div>

<div class="study-unit" id="u-14-rewrite-849a54c4c28f">

例如固定输入 1、2、3，目标 312 要先压满以弹 3，此时 2 挡住 1，失败。**固定输入顺序与任意排列不同，三元素只有五种合法输出。** 递归调用则另按调用树计数，返回数值不能代替调用次数。

</div>

<span class="legacy-anchor" data-target="s-14-edc75e521657" id="u-14-5cdc3a41cbdd"></span><span class="legacy-anchor" data-target="s-14-edc75e521657" id="u-14-5ead5a276b26"></span>
<a id="s-14-edc75e521657"></a>

#### 递归调用次数

<div class="study-unit" id="u-14-rewrite-cfb1d5ce0297">

每次进入函数都对应调用树的一个结点，包含初始调用和最终边界调用。`2*F(n/2)` 只调用一次 F，返回值再乘 2；`F(n/2)+F(n/2)` 在未做缓存等优化的模型中调用两次。

</div>

<div class="study-unit" id="u-14-rewrite-77615393028d">

**总调用数、最大深度和返回值分别计算。** 二分递归可以有很多调用而只有对数深度，空间按同时未返回的最大链长统计，时间则看全部调用中的操作总和。

</div>

<span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="s-5"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="p-4"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="u-14-84283e05ed0c"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="u-14-7f85308ce937"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="u-14-bf929a76f6d6"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="u-14-20240dbeebd4"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="u-14-613d7f7d8363"></span><span class="legacy-anchor" data-target="s-14-044d96a4ebf3" id="u-14-b12fd45d31b3"></span>
<a id="s-14-044d96a4ebf3"></a>

### 双端队列与两个队列重排

<div class="study-unit" id="u-14-rewrite-729964c37366">

输入受限双端队列只能从指定一端加入、两端都能取，输出受限则两端可加、只能一端取。每一步都只能操作端点，不能从中间拿走目标元素。

</div>

<div class="study-unit" id="u-14-rewrite-c448997eea3c">

两个普通队列各自保留内部相对次序，所以递增输入的可行目标需能拆成两个递增子序列。**多轨道调车还要区分输入次序与最终输出要求**：若各轨道是队列、最终递增，最少轨道数等于输入最长下降子序列长度，既要给下界，也要能构造分配。

</div>

<span class="legacy-anchor" data-target="s-14-b18737fea4d4" id="s-6"></span><span class="legacy-anchor" data-target="s-14-b18737fea4d4" id="p-5"></span><span class="legacy-anchor" data-target="s-14-b18737fea4d4" id="u-14-137a138631a4"></span><span class="legacy-anchor" data-target="s-14-b18737fea4d4" id="u-14-660c7fbd1676"></span><span class="legacy-anchor" data-target="s-14-b18737fea4d4" id="u-14-4425fefeb5ea"></span>
<a id="s-14-b18737fea4d4"></a>

### 表达式与括号栈

<div class="study-unit" id="u-14-rewrite-2614fca05f9f">

后缀表达式扫描到数字就压栈，遇二元运算符先弹右操作数、再弹左操作数，计算后把结果压回。若先后弹出 a、b，应做 **`b op a`**，例如 `8 2 -` 得 6，不能写成 −6。

</div>

<div class="study-unit" id="u-14-rewrite-66eca81ce38a">

括号匹配的栈只保存尚未配对的左括号，遇对应右括号才弹出。**所需最大容量是扫描过程中未匹配左括号数的最大值**，即最大嵌套深度，连续平放许多对括号并不会要求同样大的栈。

</div>

## 链表操作中的边界

<div class="study-unit" id="u-14-rewrite-4ce3cb0bf11e">

链表位置由链接表达，首尾与空表取决于有没有头结点、是否循环及是否维护尾指针。先画出空表和单结点两种状态，往往就能发现公式混用和悬空尾指针问题。

</div>

<div class="study-unit" id="u-14-rewrite-c8c547bd1ed7">

**定位目标与修改链接分开计时，普通终点与循环回到起点分开判断。** 下面针对每种结构给出具体关系，不能用一个所谓通用判空式覆盖全部链表。

</div>

<span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="s-8"></span><span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="p-6"></span><span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="u-14-6103ad7eeec8"></span><span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="u-14-433c8c26066c"></span><span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="u-14-c055cfa51ae2"></span><span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="u-14-7792e27e38be"></span><span class="legacy-anchor" data-target="s-14-a4813d9ba1ee" id="u-14-f5013e04e450"></span>
<a id="s-14-a4813d9ba1ee"></a>

### 查找位置与改指针分开计时

<div class="study-unit" id="u-14-rewrite-4d9ddc4a83b3">

单链表找到前驱后，只改常数条链接即可插删，局部为 $O(1)$；但在有序链中先找插入位置，最坏还需走完整条链，完整操作为 $O(n)$。

</div>

<div class="study-unit" id="u-14-rewrite-0c632d410114">

**尾指针保存尾结点，不保存它的前驱。** 因而单链删尾通常仍为 $O(n)$，双链可由 prior 直接回退。静态链表用数组保存结点，却仍按游标连接，插删不必像顺序表搬移后面元素。

</div>

<span class="legacy-anchor" data-target="s-14-c4ca603802f3" id="s-9"></span><span class="legacy-anchor" data-target="s-14-c4ca603802f3" id="p-7"></span><span class="legacy-anchor" data-target="s-14-c4ca603802f3" id="u-14-7b92eb0abf21"></span>
<a id="s-14-c4ca603802f3"></a>

### 删除循环链表首元与双链表插入

<div class="study-unit" id="u-14-rewrite-941714f0f80a">

先确认 h 是指向头结点还是首元，r 是否由实现维护。头结点是辅助哨兵，首元才存第一份数据；同一个 `h->next==h` 在不同结构下可能表达空表，也可能表达一个数据结点。

</div>

<div class="study-unit" id="u-14-rewrite-532ca8940227">

**删最后一个数据结点是必须单独核对的边界。** 除跳过旧结点、释放内存，还需恢复头尾关系；双链插入则要保存旧后继并补齐前后两组链接，下面分结构解释。

</div>

<span class="legacy-anchor" data-target="s-14-017c186e863d" id="u-14-ad0d37571815"></span><span class="legacy-anchor" data-target="s-14-017c186e863d" id="u-14-2174597ea4b9"></span><span class="legacy-anchor" data-target="s-14-017c186e863d" id="u-14-3712699e12e0"></span><span class="legacy-anchor" data-target="s-14-017c186e863d" id="u-14-a3ed549c390b"></span>
<a id="s-14-017c186e863d"></a>

#### 循环单链表：带头结点 H

<div class="study-unit" id="u-14-rewrite-b2a5912a0053">

头结点 H 始终存在，h 指向它。**空 `h->next==h`；非空首元 `h->next`；尾部 `r->next==h`；空表尾指针 `r==h`。** 遍历从首元开始，以再次到达 h 结束，而非等待 NULL。

</div>

<div class="study-unit" id="u-14-rewrite-60d0f6d0313c">

删除首元先保存 `q=h->next`，令头结点跳过 q；若 q 也是尾结点，须将 r 改回 h，最后释放 q。**删除唯一数据结点后仍留下 H→H**，不能将它误处理成无头链表的空指针状态。

</div>

<div class="study-unit" id="u-14-6004d0881a30">

| 考察点 | 明确写法 |
| --- | --- |
| 只有一个数据结点 | `h->next != h && h->next->next == h` |
| 遍历结束 | 从 `p=h->next` 开始，循环条件 `p != h` |
| 删除首元（先判非空） | `q=h->next; h->next=q->next; if(r==q) r=h; free(q);`，其中更新 r 的语句只在维护尾指针时需要 |

</div>

<span class="legacy-anchor" data-target="s-14-91dfdbd39541" id="u-14-152d60ae8f76"></span><span class="legacy-anchor" data-target="s-14-91dfdbd39541" id="u-14-48e93a5cb84f"></span><span class="legacy-anchor" data-target="s-14-91dfdbd39541" id="u-14-3e2b65c2ad9b"></span>
<a id="s-14-91dfdbd39541"></a>

#### 循环单链表：不带头结点

<div class="study-unit" id="u-14-rewrite-1a4ab215fa65">

这里 h 直接指首元，并约定空表用 `h==NULL`。**非空且 `h->next==h` 表示一个数据结点，尾部满足 `r->next==h`**；与带头结点的空表关系含义相反。

</div>

<div class="study-unit" id="u-14-rewrite-24f51082da7d">

删除唯一结点后令 h、维护的 r 都为 NULL；多结点删首元时先保留旧 h，前移 h，再令尾结点指向新 h，最后释放旧首元。若无尾指针，找尾还需遍历；非空遍历可用 do-while，处理后前进，回到起点时停止。

</div>

<div class="study-unit" id="u-14-72f54a565ad0">

| 考察点 | 明确写法 |
| --- | --- |
| 只有一个数据结点 | `h != NULL && h->next == h` |
| 遍历结束 | 先判断 h 非空，从 h 开始用 do-while；处理当前结点后前进，再判断 `p != h` |
| 删除唯一结点 | 保存旧 h，令 `h=NULL`；若维护 r，同步 `r=NULL`，再释放旧结点 |
| 删除多结点表首元 | 保存旧 h，令 `h=h->next`，再令 `r->next=h`，最后释放旧首元；若没有尾指针，需先遍历找到尾结点 |

</div>

<span class="legacy-anchor" data-target="s-14-03694c96b05b" id="u-14-2098ef222a60"></span><span class="legacy-anchor" data-target="s-14-03694c96b05b" id="u-14-800db8bedb68"></span>
<a id="s-14-03694c96b05b"></a>

#### 循环双链表：带头结点 H

<div class="study-unit" id="u-14-rewrite-c85f880ac6a6">

空头结点的两个方向都回到自己，**`h->next==h && h->prior==h`**；非空时首元是 h->next，尾是 h->prior，首元 prior 和尾 next 都指向 h。

</div>

<div class="study-unit" id="u-14-rewrite-8bb3d7b80789">

删除结点 q 时让其前驱 next 接后继、后继 prior 接前驱，再释放 q。单数据结点删除后两条链接自然恢复到 H；**不可只更新 next 而遗留 prior**，反向遍历会因此经过已释放结点。

</div>

<span class="legacy-anchor" data-target="s-14-52082e07eea7" id="u-14-1da9b000eecc"></span><span class="legacy-anchor" data-target="s-14-52082e07eea7" id="u-14-8dca21b7af07"></span><span class="legacy-anchor" data-target="s-14-52082e07eea7" id="u-14-8e0f34e381d5"></span>
<a id="s-14-52082e07eea7"></a>

#### 链队列：带头结点

<div class="study-unit" id="u-14-rewrite-cfeaff5715f3">

front 始终指头结点，rear 指最后数据结点，空时两者都指头结点。**判空 `front==rear`**；入队接到 rear 后并更新 rear，出队删除 front 的后继。

</div>

<div class="study-unit" id="u-14-rewrite-ae15d1dffbd5">

若删除的正是 rear，必须执行 **`rear=front`**，否则尾指针悬空。无头队列常以 front==NULL 判空，不能互套；动态链队列通常没有固定数组式判满条件，是否能继续入队取决于结点分配或题设容量限制。

</div>

<span class="legacy-anchor" data-target="s-14-9b7756bc59b0" id="u-14-8ddf5c745433"></span><span class="legacy-anchor" data-target="s-14-9b7756bc59b0" id="u-14-84ba2e90c337"></span><span class="legacy-anchor" data-target="s-14-9b7756bc59b0" id="u-14-39ecd2939b2b"></span>
<a id="s-14-9b7756bc59b0"></a>

#### 双链表：在 p 与旧后继 q 之间插入 s

<div class="study-unit" id="u-14-rewrite-68e695c49a4c">

先保存 `q=p->next`，再让 `s->prior=p`、`s->next=q`，随后令 q 的 prior 和 p 的 next 指向 s。**先保存旧地址，再把新结点两边接完整**，避免先覆盖 p->next 后找不到原后继。

</div>

<div class="study-unit" id="u-14-rewrite-82190f11d6ed">

循环带头结构中 q 可以是头结点，照常更新其 prior；普通非循环表中 q 可能为 NULL，此时不可访问 q->prior，还需更新维护的尾指针。下标或位置变化不重要，四条双向链接的一致性才是检查对象。

</div>

## 树、编码与并查集

<div class="study-unit" id="u-14-rewrite-d1d55a4a03c6">

本组把几类看似不同的问题统一到结构约束：矩阵数前置元素，树数孩子和边，前缀码看路径包含，查找树看分支容量，并查集看代表元。

### 特殊矩阵的压缩下标

<div class="study-unit" id="u-14-rewrite-8c79ca8e4d39">

压缩定位先看存上半还是下半、按行还是按列，以及矩阵和压缩数组各从几编号。对称矩阵若目标在未存半区，先交换 i、j，再数已存元素，不能直接代错半区公式。

</div>

<div class="study-unit" id="u-14-rewrite-3a072675a67a">

例如下三角行优先、全部从 0 起，**$k=i(i+1)/2+j$**，前项数此前各行，后项数本行之前位置。三对角共有 $3n-2$ 个有效位置；行优先二维普通数组地址差为 $[(\Delta i)N+\Delta j]L$，须统一列数和元素宽度。

</div>

### 完全二叉树的编号与形态

<div class="study-unit" id="u-14-rewrite-d0765c307d16">

按层从 1 编号的完全二叉树没有中间空缺，孩子候选为 $2i$ 和 $2i+1$，必须不大于 n 才存在。最后非叶编号为 $\lfloor n/2\rfloor$，叶数为 $\lceil n/2\rceil$。

</div>

<div class="study-unit" id="u-14-rewrite-b09d954017cb">

**已知叶数 L，只能推出总结点为 $2L-1$ 或 $2L$**，再靠其他条件选定。$n_0=n_2+1$ 对任意非空二叉树成立，至多一个度 1 结点且只能有左孩子则是完全形态的额外性质；仅一种深度遍历通常不能唯一还原一般二叉树。

</div>

<span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="s-13"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="p-10"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="u-14-b30307bb01ce"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="u-14-5e5909dce89c"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="u-14-ddaa714bdc51"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="u-14-c26d733f8e7b"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="u-14-d13d31ee53a7"></span><span class="legacy-anchor" data-target="s-14-4e2be59f4d38" id="u-14-9a48a2f7650c"></span>
<a id="s-14-4e2be59f4d38"></a>

### 树的度和叶结点数

<div class="study-unit" id="u-14-rewrite-17e6c4966f11">

树的度为 m 表示最大孩子数恰为 m，至少有一个结点达到它，其他结点可以更少。每条边对应一个孩子，结合 $n-1=\sum i n_i$ 可得 **$n_0=1+\sum_{i=2}^m(i-1)n_i$**。

</div>

<div class="study-unit" id="u-14-rewrite-d954e2d878a3">

度 1 结点只延长路径，不增加叶数。根在第 1 层、$m>1$ 的 m 叉树高 h 时最多 $(m^h-1)/(m-1)$ 个结点；求“度恰为 m”的最少结点还需满足确有一个 m 孩子结点，不能只构造一条链。

</div>

<span class="legacy-anchor" data-target="s-14-ad99f867a6ea" id="s-14"></span><span class="legacy-anchor" data-target="s-14-ad99f867a6ea" id="p-11"></span><span class="legacy-anchor" data-target="s-14-ad99f867a6ea" id="u-14-ad20b3828276"></span><span class="legacy-anchor" data-target="s-14-ad99f867a6ea" id="u-14-dbd937b18cfb"></span><span class="legacy-anchor" data-target="s-14-ad99f867a6ea" id="u-14-f2aa91e7dced"></span><span class="legacy-anchor" data-target="s-14-ad99f867a6ea" id="u-14-62e2a3df82ca"></span>

### AVL 树最少结点递推

<div class="study-unit" id="u-14-rewrite-fc1bb13f5383">

高度按根为 1 计，最稀疏 AVL 的两子树应尽量取高度 h−1 与 h−2，否则不是更矮就是能删得更少。因而 **$N_h=N_{h-1}+N_{h-2}+1$**，初值 $N_0=0,N_1=1$，得到 0、1、2、4、7、12、20。

</div>

<div class="study-unit" id="u-14-rewrite-80ab4fca6189">

这是给定高度的最少节点数，不是所有 AVL 的固定大小。**给定 n 求最大高度，要找最大的 h 使 $N_h\le n$**，再检查更高一层下限超过 n，避免把递推结果直接当实际树形。

</div>

<span class="legacy-anchor" data-target="s-14-275838c83433" id="s-15"></span><span class="legacy-anchor" data-target="s-14-275838c83433" id="p-12"></span><span class="legacy-anchor" data-target="s-14-275838c83433" id="u-14-b3f186ebcdeb"></span><span class="legacy-anchor" data-target="s-14-275838c83433" id="u-14-0f01587a2ee0"></span><span class="legacy-anchor" data-target="s-14-275838c83433" id="u-14-f9211cddd382"></span><span class="legacy-anchor" data-target="s-14-275838c83433" id="u-14-1affdba24420"></span><span class="legacy-anchor" data-target="s-14-275838c83433" id="u-14-9b8eb59161e1"></span>

### 前缀码与哈夫曼编码

<div class="study-unit" id="u-14-rewrite-d2a7a9aa3ec8">

前缀码要求任一码字都不是另一码字的开头，保证逐位读到叶就能立即判断一个符号。等长码满足前缀条件，不等长也可满足，例如 `{0,10,110,111}`。

</div>

<div class="study-unit" id="u-14-rewrite-73c5b8ca9f42">

新增码字要双向检查：它不能是旧码的前缀，旧码也不能是它的前缀。**前缀条件保证可即时区分，不保证给定频率下平均码长最小**；哈夫曼构造另以频率和带权路径长度为优化目标。

</div>

### 并查集的 `Find`、`Union` 与复杂度

<div class="study-unit" id="u-14-rewrite-be2622a3a1b1">

Find(x) 沿双亲到根，返回所属集合代表；Union 先 Find 两端，只在根不同的时候合并完整集合。**一次有效合并才使集合数减 1**，反复合并同组不会重复减少。

</div>

<div class="study-unit" id="u-14-rewrite-43de9b171059">

根的负值可以记录规模，但不是 Find 的定义返回值。无优化可能退化为长链，按规模合并控制树高，配合路径压缩可得很低均摊代价；Kruskal 遇同根端点说明已有通路，加入该边才会成环。

</div>

<a id="s-14-12689f1ef707"></a>

### B 树与 B+ 树的高度

<div class="study-unit" id="u-14-rewrite-cd772148d0dc">

采用根为第 1 层、只计含关键字层的 m 阶 B 树，令 $d=\lceil m/2\rceil$，高 h 的关键字数满足 **$2d^{h-1}-1\le n\le m^h-1$**。最稀疏形态给最大高度，最满形态给最小高度，别把两端倒用。

</div>

<div class="study-unit" id="u-14-rewrite-2113b2e5106c">

同层 T 个内部结点共有 K 个关键字时，下一层孩子数为 K+T，因为每结点孩子多一个。**B 树可在内部找到记录，B+ 树内部只导航、需到叶取记录**，高度约定和阶数定义还应先与题设统一。

</div>

## 图的可达性、存储与遍历

<div class="study-unit" id="u-14-rewrite-04939bb20a18">

图题常把“有直接边”“存在路径”“按某次序访问”和“所有点满足连通约束”放在一起考察，几种命题强弱不同。先标明有向或无向、简单图以及是否允许重复顶点。

</div>

<div class="study-unit" id="u-14-rewrite-90558261bc61">

**存在一种构造与任意分布都保证，是不同问法。** 遍历输出相邻也不一定有边，矩阵幂中的数量也不等于简单路径数，下面分别拆开。

</div>

<span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="s-19"></span><span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="p-15"></span><span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="u-14-841a992f6c86"></span><span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="u-14-9d779cbd4224"></span><span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="u-14-b478b9594ea1"></span><span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="u-14-c33097943e64"></span><span class="legacy-anchor" data-target="s-14-56204cf9ae44" id="u-14-be43a27ba81a"></span>
<a id="s-14-56204cf9ae44"></a>

### 路径、直接边与保证连通

<div class="study-unit" id="u-14-rewrite-34e986c0ad47">

u 可达 v 表示存在一路走过去，不要求直接相邻。简单无向 n 点图能构造连通至少需 n−1 边，但同样边数也可能集中在部分顶点，留下孤点。

</div>

<div class="study-unit" id="u-14-rewrite-71c99dbb2d27">

**保证无论怎样分边都连通，要超过非连通图的最大边数。** 后者可由 $K_{n-1}$ 加一个孤点达到 $\binom{n-1}{2}$，所以 n≥2 时保证界为再加 1；先辨“可以连通”与“必定连通”，再选表达式。

</div>

<span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="s-20"></span><span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="p-16"></span><span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="u-14-49256ebfbbe2"></span><span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="u-14-685147134f49"></span><span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="u-14-7db4cf46eb80"></span><span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="u-14-2897d3a8f12c"></span><span class="legacy-anchor" data-target="s-14-ce818fe3c804" id="u-14-c7e881daf6ba"></span>
<a id="s-14-ce818fe3c804"></a>

### 邻接矩阵的幂与特殊存储

<div class="study-unit" id="u-14-rewrite-d823ed287375">

普通无权邻接矩阵的 $(A^k)[i][j]$ 数从 i 到 j、长度恰为 k 的游走，矩阵乘法把经过不同中间点的情况累加。**指数是长度，元素值是条数，游走允许重复顶点**，不能直接解释成简单路径数。

</div>

<div class="study-unit" id="u-14-rewrite-598d9be8747e">

无向邻接多重表让一个边结点挂入两端链，有向十字链表让一条弧同时挂入出边链与入边链。它们改变同一关系怎样登记，不改变原图的方向和可达性。

</div>

<span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="s-21"></span><span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="p-17"></span><span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="u-14-20cee4048768"></span><span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="u-14-51335058137f"></span><span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="u-14-c99dbd20e0ea"></span><span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="u-14-2e71ef43ceff"></span><span class="legacy-anchor" data-target="s-14-ea1d0ef38db3" id="u-14-97c452d308c1"></span>
<a id="s-14-ea1d0ef38db3"></a>

### DFS、BFS 的约束

<div class="study-unit" id="u-14-rewrite-60f5d0182110">

DFS 在当前点还有未访问邻居时必须继续深入，不能随意提前回退；BFS 则按到起点的最少边数分层，层内次序可因邻接扫描顺序而不同。

</div>

<div class="study-unit" id="u-14-rewrite-e58c0e550d2e">

**BFS 相邻输出点不必直接相邻，最少边数也不自动是任意权图的最小总权。** 有向无环图仍可能多路汇合到同一点，仍需访问标记；DFS 判有向环还要区分当前路径与已结束的点。

</div>

<span class="legacy-anchor" data-target="s-14-20f3a07d6f01" id="s-22"></span><span class="legacy-anchor" data-target="s-14-20f3a07d6f01" id="p-18"></span><span class="legacy-anchor" data-target="s-14-20f3a07d6f01" id="u-14-221dfb7a9d1e"></span><span class="legacy-anchor" data-target="s-14-20f3a07d6f01" id="u-14-d113b57d5e4a"></span><span class="legacy-anchor" data-target="s-14-20f3a07d6f01" id="u-14-e27e6cc541fa"></span><span class="legacy-anchor" data-target="s-14-20f3a07d6f01" id="u-14-0175dc8469a1"></span>
<a id="s-14-20f3a07d6f01"></a>

### 拓扑序列与关键路径

<div class="study-unit" id="u-14-rewrite-26a0d92babd0">

拓扑序只要求每条前驱弧的起点在终点之前，a 排在 b 前不推出存在直接弧。将 DAG 按某个拓扑序重排顶点，边只从前指后，邻接矩阵相应为严格上三角位置的非零项。

</div>

<div class="study-unit" id="u-14-rewrite-7290ffb33ef5">

**工期受全部最长路径约束。** 延长关键活动会延长所在关键路径，缩短只覆盖某一条的活动却可能被另一条原长路径限制；要缩短总工期，必须让所有当前关键路径都得到有效缩短，并重新检查新路径。

</div>

<span class="legacy-anchor" data-target="s-14-ca3f54d23c60" id="s-23"></span>
<a id="s-14-ca3f54d23c60"></a>

## 查找、散列与排序

<div class="study-unit" id="u-14-rewrite-b7529bf599cb">

查找的关键是结构允许排除多少候选，排序的关键是每趟建立什么不变量。数组二分依赖逻辑有序与随机访问，散列依探测链，堆只保证父子偏序，不能混用结构假设。

</div>

<div class="study-unit" id="u-14-rewrite-56a1afc0c610">

**过程题按指定算法逐步模拟，比较次数与移动次数分开数。** 外部排序还需区分生成初始段、选择段头和安排合并次序，各工具解决不同成本。

</div>

<span class="legacy-anchor" data-target="s-14-6adacc9289df" id="s-24"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="p-19"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-ec3dfcb716ba"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-128f0434fa20"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-224712117aa6"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-874b3cf90c17"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-17a99cb84437"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-a0df0051b8ab"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-6cc950b925e0"></span><span class="legacy-anchor" data-target="s-14-6adacc9289df" id="u-14-6bcecd5fb4f4"></span>
<a id="s-14-6adacc9289df"></a>

### 折半查找与散列失败查找

<div class="study-unit" id="u-14-rewrite-e970f7720995">

普通二分通过中间下标缩小有序区间，所以要求逻辑有序且能随机取位，有序单链表或游标链不能仅凭数组外壳直接套用。成功与失败 ASL 也各有不同概率样本。

</div>

<div class="study-unit" id="u-14-rewrite-c8248ea4408a">

**散列失败从每个可能初始地址探测到真空槽，并计这次空槽检查。** `H=key mod 7` 即使物理表长 11，等概率起点仍只有七个；线性探测可能聚集，平方探测未必遍历全表，表未满也不保证当前序列能找到空位。

</div>

<span class="legacy-anchor" data-target="s-14-6cdbc7be3b49" id="s-25"></span><span class="legacy-anchor" data-target="s-14-6cdbc7be3b49" id="p-20"></span><span class="legacy-anchor" data-target="s-14-6cdbc7be3b49" id="u-14-6a26b011d948"></span><span class="legacy-anchor" data-target="s-14-6cdbc7be3b49" id="u-14-e23ff8de6357"></span><span class="legacy-anchor" data-target="s-14-6cdbc7be3b49" id="u-14-24131376bea0"></span><span class="legacy-anchor" data-target="s-14-6cdbc7be3b49" id="u-14-362906958816"></span>
<a id="s-14-6cdbc7be3b49"></a>

### 堆查找与快速排序的“趟”

<div class="study-unit" id="u-14-rewrite-073fe6ab2940">

堆只限制父不小于孩子或相反，左右子树关键字范围可重叠，找任意关键字最坏仍要检查 $O(n)$ 个结点。**堆顶能快速取极值，不等于能像 BST 二分查任意值。**

</div>

<div class="study-unit" id="u-14-rewrite-2b818e114f53">

快排一次划分通常只固定枢轴，左右内部仍未排好。“第二趟”若题目定义为处理全部待排子表，就应分别划分第一趟产生的两个区间；先读清趟的口径，不能默认等于只调用一次 partition。

</div>

<span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="s-26"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="p-21"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="u-14-e4aa7da95219"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="u-14-8287c8cfe489"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="u-14-056bafe61cd3"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="u-14-09f64c5571ce"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="u-14-ef3e7e3c6c6e"></span><span class="legacy-anchor" data-target="s-14-60c55809e2ef" id="u-14-ea09abfc98fa"></span>
<a id="s-14-60c55809e2ef"></a>

### 插入、希尔和建堆的过程

<div class="study-unit" id="u-14-rewrite-220e7687ade4">

折半插入减少找位置的比较，移动后缀仍可能是平方量级；希尔一趟对相差增量 d 的各组分别插入，只保证组内有序，最后必须以 d=1 收尾。

</div>

<div class="study-unit" id="u-14-rewrite-cbcfd1b51213">

**逐个插入建堆与自底向上建堆可能得到不同合法结果。** 模拟要沿题设流程，不能只交任意一个堆；比较次数还应计发现无需继续交换的末次检查，不应仅数实际交换。

</div>

<a id="s-14-762d3a1316df"></a>

### 外部排序的三种工具

<div class="study-unit" id="u-14-rewrite-96934defc457">

内存容纳 M 记录，普通分批排序约产生 $r=\lceil n/M\rceil$ 段，k 路归并约需 $\lceil\log_k r\rceil$ 趟，题目只问归并趟数时通常不含初始段生成。

</div>

<div class="study-unit" id="u-14-rewrite-a91e6be010ff">

**置换选择延长初始段，败者树选择当前最小段头，最佳归并树安排不同长度段的合并次序。** 随机输入下段长平均可接近工作区两倍，不是每段定长；k 叉最佳树必要时补零权虚段，使叶数满足 $(r-1)\bmod(k-1)=0$，虚段不产生实际数据读写。

</div>

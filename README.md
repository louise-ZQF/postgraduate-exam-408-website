# 408 知识库

参照数学二公式知识库的搜索与阅读体验制作的 408 专题网站。内容来自 [yyx-dev/yyx-dev.github.io](https://github.com/yyx-dev/yyx-dev.github.io/tree/325bdaa/docs/408)，保留原文来源入口；本项目不声明原始资料的版权或许可。

运行 `npm install` 后执行 `npm run dev`，构建执行 `npm run build`。源 Markdown 保存在 `source/408/`，站内内容与搜索索引保存在 `public/`；更新 Markdown 后运行 `npm run prepare:content`。构建后的 `dist/` 是可部署的静态网站。
